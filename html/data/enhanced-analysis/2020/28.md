## 答案
选 **D**。请求分页系统的有效（平均）访存时间受缺页率、磁盘读写时间、内存访问时间和缺页处理程序的 CPU 时间共同影响。

## 解析
有效（平均）访存时间，指访问一个逻辑地址最终平均要花费的时间。请求分页系统下，CPU 访问逻辑地址时通常要经历以下过程：

- 先查页表，页表查找本身需要访存；
- 再根据页表得到物理地址，访问目标数据也需要访存；
- 若对应页面未调入内存，还会发生缺页中断，进入缺页处理程序；
- 缺页处理时需要从磁盘将页面调入内存，这一步还要消耗磁盘 I/O 时间；
- 缺页处理程序本身也要占用 CPU 时间。

因此，本题四个因素都与平均访存时间有关：

- 缺页率越高，发生缺页中断越频繁，平均访存时间越长。
- 磁盘读写时间越长，缺页后把页面调入内存越慢，平均访存时间越长。
- 内存访问时间越长，查页表和访问目标数据都更慢，平均访存时间越长。
- 执行缺页处理程序的 CPU 时间越长，缺页恢复过程越慢，平均访存时间越长。

## 选项分析
- A. 仅Ⅱ、Ⅲ：错误，缺页率和缺页处理程序 CPU 时间也会影响平均访存时间。
- B. 仅Ⅰ、Ⅳ：错误，磁盘读写时间和内存访问时间同样重要。
- C. 仅Ⅰ、Ⅲ、Ⅳ：错误，漏掉了磁盘读写时间。
- D. Ⅰ、Ⅱ、Ⅲ和Ⅳ：正确，四项都影响请求分页系统的有效访存时间。

## 易错点
- 容易把“平均访存时间”只理解成内存本身的访问速度，实际上请求分页系统里还包含缺页后的磁盘调页和处理开销。
- 题干里的“有效访存时间”与“平均访存时间”本质上是同一类考点，判断时要把缺页代价一起算进去。
