## 答案

本题应在经典生产者-消费者模型基础上，增加一个信号量来控制“同一消费者连续取出 10 件产品”这一过程。可设置以下信号量及初值：

- `special = 1`：控制某个消费者连续取 10 件产品期间，其他消费者不能进入取产品过程
- `mutex = 1`：实现对环形缓冲区的互斥访问
- `empty = 1000`：表示缓冲区中的空位数
- `full = 0`：表示缓冲区中的产品数

相应进程描述如下：

```c
semaphore special = 1;
semaphore mutex = 1;
semaphore empty = 1000;
semaphore full = 0;

Producer() {
    while (1) {
        P(empty);
        生产一件产品;
        P(mutex);
        将产品放入缓冲区;
        V(mutex);
        V(full);
    }
}

Consumer() {
    while (1) {
        P(special);
        for (int i = 0; i < 10; i++) {
            P(full);
            P(mutex);
            从缓冲区取出一件产品;
            V(mutex);
            V(empty);
            消费该产品;
        }
        V(special);
    }
}
```

## 解析

### 信号量设置

题目本质上仍是经典生产者-消费者问题，但增加了一个特殊约束：某个消费者一旦开始取产品，就必须连续取出 10 件，在这 10 次取操作完成之前，其他消费者不能取产品。

因此需要设置两类信号量：

- `empty` 和 `full`：分别实现生产者与消费者之间关于“缓冲区空”和“缓冲区满”的同步
- `mutex`：保证多个进程对环形缓冲区的单次访问互斥
- `special`：保证某一消费者获得取产品资格后，能连续完成 10 次取操作

各信号量初值为：

- `special = 1`
- `mutex = 1`
- `empty = 1000`
- `full = 0`

其中，`empty = 1000` 是因为缓冲区初始为空，空位数为 1000；`full = 0` 是因为初始时没有产品。

### 生产者与消费者过程

生产者过程与经典模型一致：只有在缓冲区未满时才能放入产品，因此先执行 `P(empty)`；放入缓冲区时需要互斥访问，因此在临界区前后执行 `P(mutex)` 和 `V(mutex)`；成功放入后执行 `V(full)`，表示产品数加 1。

消费者过程需要体现“连续取 10 件”的要求。做法是：消费者在进入取产品过程前，先执行 `P(special)`，获得本轮连续取 10 件产品的资格；然后循环 10 次，每次先执行 `P(full)` 等待缓冲区中有产品，再进入缓冲区临界区取出一件产品，取出后执行 `V(empty)`；当 10 次都完成后，再执行 `V(special)`，允许其他消费者开始下一轮取产品。

对应伪代码如下：

```c
semaphore special = 1;
semaphore mutex = 1;
semaphore empty = 1000;
semaphore full = 0;

Producer() {
    while (1) {
        P(empty);
        生产一件产品;
        P(mutex);
        将产品放入缓冲区;
        V(mutex);
        V(full);
    }
}

Consumer() {
    while (1) {
        P(special);
        for (int i = 0; i < 10; i++) {
            P(full);
            P(mutex);
            从缓冲区取出一件产品;
            V(mutex);
            V(empty);
            消费该产品;
        }
        V(special);
    }
}
```

这里要注意，`special` 控制的是“连续取 10 件”这一整段操作，`mutex` 控制的是对缓冲区的一次具体访问，二者作用不同，不能混用。

## 易错点

- 只写经典生产者-消费者模型中的 `mutex`、`empty`、`full`，会遗漏“同一消费者必须连续取 10 件”的约束。
- `special` 不是用来保护缓冲区临界区的，而是用来限制消费者之间对“10 次连续取操作资格”的竞争。
- `empty` 的初值应为 `1000`，`full` 的初值应为 `0`，两者不能写反。
