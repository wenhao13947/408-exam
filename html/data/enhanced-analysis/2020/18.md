## 答案

A。因为自陷（Trap）属于**内部异常（Exception）**，不是“外部中断事件”，A 对自陷性质的表述错误。

## 解析

题干要求判断“关于自陷的叙述中错误的是哪一个”。解题关键是先分清**中断/异常的类别**，再判断自陷的处理特点。

自陷是程序执行过程中，由**陷阱指令**或某些受控条件触发的**预先安排好的异常事件**。它的本质不是来自 CPU 外部的随机中断请求，而是与当前指令执行过程直接相关，因此应归入**内部异常**。教材中通常将异常分为三类：**Fault、Trap、Abort**，自陷就是其中之一。

据此，A 项前半句“通过陷阱指令预先设定”这一点基本符合自陷的触发方式，但后半句把它说成“外部中断事件”，类别判断错误，因此 A 项整体错误。

其余选项可结合自陷的典型用途和返回方式判断：

- 自陷常用于**断点设置**、**单步跟踪**等调试功能，这是处理器体系结构中的典型应用。
- 自陷发生后，CPU 会保存现场并转去执行相应的**操作系统内核处理程序**，这一点符合异常处理流程。
- 自陷处理结束后，通常返回到**陷阱指令的下一条指令**继续执行，这也是 Trap 与 Fault 的常见区别之一。Fault 往往返回到引起异常的当前指令，而 Trap 通常在指令执行后报告，所以返回位置是下一条指令。

因此，错误项只能是 A。

## 选项分析

A. 自陷是通过陷阱指令预先设定的一类外部中断事件  
错误。错误点在“**外部中断事件**”。自陷属于**内部异常**，不是外部中断。虽然它可以由陷阱指令预先设置或人为安排，但类别上仍属于异常。

B. 自陷可用于实现程序调试时的断点设置和单步跟踪  
正确。断点和单步跟踪正是自陷的典型应用，尤其是调试机制中常通过 Trap 实现控制权回到调试程序或内核。

C. 自陷发生后 CPU 将转去执行操作系统内核相应程序  
正确。自陷发生后，CPU 会按照异常向量机制转入对应的异常处理程序，通常由操作系统内核负责处理。

D. 自陷处理完成后返回到陷阱指令的下一条指令执行  
正确。自陷属于“执行后报告”的异常，处理完成后继续执行后继指令，而不是回到陷阱指令本身重新执行。

## 易错点

- 容易把“**预先设置**”误认为“**外部中断**”。是否预先设置，与它属于内部还是外部事件不是一回事；分类标准看事件来源是否来自当前指令执行过程。
- 容易混淆 **Fault** 与 **Trap** 的返回位置：
  - **Fault**：通常返回到当前出错指令，修正后可重执行。
  - **Trap**：通常返回到下一条指令。
- “用于调试”是判断 Trap 的高频特征，见到**断点、单步跟踪**，一般优先联想到自陷。
