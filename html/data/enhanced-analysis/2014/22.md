## 答案

选 **B. 25%**。

## 解析

题干已知：

- 每次中断的**响应和处理时间**为 $100\text{ ns}$
- 中断请求每隔 $400\text{ ns}$ 发出一次
- 中断响应允许的**最长延迟时间**为 $50\text{ ns}$

本题问的是：在设备持续工作过程中，**CPU 用于该设备 I/O 的时间占整个 CPU 时间的百分比至少是多少**。

在中断方式下，CPU 真正被该设备占用的时间，是每次中断的**响应和处理时间**。题目已经直接给出这部分时间为 $100\text{ ns}$。而中断请求是每 $400\text{ ns}$ 来一次，因此可把这 $400\text{ ns}$ 看作一个重复周期：

- 其中 CPU 有 $100\text{ ns}$ 在为该设备进行中断响应和处理
- 其余时间 CPU 可做别的工作

所以 CPU 用于该设备 I/O 的时间占比为

$$
\frac{100}{400}=0.25=25\%
$$

题中的“允许的最长延迟时间为 $50\text{ ns}$”只说明中断响应可以适当推迟，但这不会改变**每个 400ns 周期内仍需花费 100ns 处理中断**这一事实，因此不影响所求比例。

## 选项分析

**A. 12.5%**

错误。若占比为 $12.5\%$，对应每个 $400\text{ ns}$ 周期内只用了 $50\text{ ns}$ 进行 I/O 处理，这与题目给出的“响应和处理时间为 $100\text{ ns}$”不符。

**B. 25%**

正确。每个中断周期为 $400\text{ ns}$，其中 CPU 用于该设备中断响应和处理的时间为 $100\text{ ns}$，故占比为

$$
\frac{100}{400}=25\%
$$

**C. 37.5%**

错误。若把最长延迟时间 $50\text{ ns}$ 也计入 I/O 占用时间，会得到

$$
\frac{100+50}{400}=37.5\%
$$

但这不符合题意。$50\text{ ns}$ 是“允许的最长延迟时间”，不是 CPU 必然用于该设备处理的时间，不能计入该设备的 I/O 服务时间。

**D. 50%**

错误。$50\%$ 对应每个 $400\text{ ns}$ 周期内 CPU 有 $200\text{ ns}$ 用于该设备，但题目只给出每次中断的响应和处理时间为 $100\text{ ns}$，没有依据得到 $200\text{ ns}$。

## 易错点

1. **把“最长延迟时间 50ns”误算进 I/O 占用时间**  
   延迟时间表示“最晚可以在多久后开始响应”，它影响响应是否来得及，但不等于 CPU 已经在为该设备做 I/O 处理。

2. **混淆“中断周期”和“中断处理时间”**  
   本题中：
   - 中断请求周期：$400\text{ ns}$
   - CPU 实际处理该设备的时间：$100\text{ ns}$
   
   所求占比就是二者之比，而不是把多个时间量机械相加。

3. **忽略“至少”二字的含义**  
   这里“至少”并不会改变计算结果。因为每个周期内 CPU 至少要拿出这 $100\text{ ns}$ 来完成该设备的中断响应和处理，所以最少占比就是 $25\%$。
