## 答案
A. 间接寻址

## 解析
题干给出的定义是：**偏移寻址**是将“某个寄存器内容”与“形式地址”相加，生成有效地址 `$EA$`。

因此，凡是满足
$$EA = A + \text{寄存器内容}$$
的寻址方式，都属于偏移寻址。

对应关系如下：

- **相对寻址**：用 `PC` 与形式地址相加  
  $$EA = A + PC$$
- **基址寻址**：用基址寄存器 `BR` 与形式地址相加  
  $$EA = A + BR$$
- **变址寻址**：用变址寄存器 `IX` 与形式地址相加  
  $$EA = A + IX$$

这三种都符合“形式地址 + 某个寄存器内容”的结构。

而**间接寻址**不是这种形式。它取有效地址的方式是先由地址字段给出一个地址，再到该地址中取出真正的有效地址，典型形式为：
$$EA = (A)$$
它不属于“形式地址与寄存器内容相加”的偏移寻址。

## 选项分析
- **A. 间接寻址**：不属于偏移寻址，正确。
- **B. 基址寻址**：属于偏移寻址，错误。
- **C. 相对寻址**：属于偏移寻址，错误。
- **D. 变址寻址**：属于偏移寻址，错误。

## 易错点
本题关键是区分“是否有寄存器参与相加”。  
只要是 `形式地址 + PC/BR/IX` 这类形式，就是偏移寻址；**间接寻址**则是从地址单元中再取地址，不是偏移寻址。
