## 答案

D. `3,1,4,2,6,5`

## 解析

本题考查拓扑排序的基本判定。结论先给出：可能的拓扑序列是 `3,1,4,2,6,5`，因此选 `D`。

拓扑排序的规则是：每一步选取一个当前入度为 `0` 的顶点输出，并删除该顶点及其所有出边。结合题图可知，读图时重点关注各结点的前驱关系：

1. 初始时只有结点 `3` 的入度为 `0`，所以第一个只能是 `3`。
2. 删除 `3` 后，只有结点 `1` 的入度为 `0`，所以第二个只能是 `1`。
3. 删除 `1` 后，只有结点 `4` 的入度为 `0`，所以第三个只能是 `4`。
4. 删除 `4` 后，结点 `2` 和结点 `6` 的入度都变为 `0`，说明这一步可以先选 `2`，也可以先选 `6`。
5. 但由图中的有向边关系可知，`6` 必须排在 `5` 前，因此最后 `5` 不能先于 `6`。

于是，所有可能的拓扑序都必须以 `3,1,4` 开头，之后在 `2`、`6` 中任选一个，再安排另一个，最后是 `5`。因此可能的合法形式只有：

- `3,1,4,2,6,5`
- `3,1,4,6,2,5`

四个选项中，只有 `D` 符合。

## 选项分析

A. `3,1,2,4,5,6``

不可能。该序列把 `2` 排在了 `4` 前面，但由题图关系可知，`4` 必须在 `2` 前，因此违反拓扑序要求。

B. `3,1,2,4,6,5`

不可能。该项同样把 `2` 排在 `4` 前，仍然违背了 `4` 必须先于 `2` 的先后约束，因此错误。

C. `3,1,4,2,5,6`

不可能。前面的 `3,1,4,2` 可以成立，但后面把 `5` 排在了 `6` 前。由于图中要求 `6` 必须在 `5` 前，所以该项错误。

D. `3,1,4,2,6,5`

可能。它满足以下全部约束：

- `3` 最先输出；
- `1` 在 `3` 之后；
- `4` 在 `1` 之后；
- `4` 在 `2` 之前；
- `6` 在 `5` 之前。

并且在删除 `4` 后，`2` 和 `6` 同时可作为入度为 `0` 的候选结点，所以先 `2` 后 `6` 是允许的。故该项正确。

## 易错点

1. 只看数字顺序，不看边的方向  
拓扑序是否合法，关键不在于数字大小，而在于是否满足每条有向边的先后关系。

2. 忽略“当前入度为 0”这一动态过程  
某个结点是否能输出，不是固定不变的，而是随着前驱结点删除后才可能变成入度为 `0`。

3. 误以为拓扑序唯一  
本题前缀 `3,1,4` 是唯一确定的，但删去 `4` 后，`2` 和 `6` 都可选，所以拓扑序不唯一。这正是本题设置干扰项的关键。
