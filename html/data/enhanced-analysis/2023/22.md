## 解析
本题考查 I/O 控制方式的基本概念。题干要求选出“错误”的叙述。

- 查询方式：CPU 通过程序定时或持续查询接口状态，外设数据准备好后，再执行查询程序完成 I/O 操作，因此 A 正确。
- 中断方式：CPU 通过执行与中断源相匹配的中断处理程序，也称中断服务程序，完成 I/O 操作，因此 B 正确。
- DMA 方式：数据传送由 DMA 控制器直接完成，CPU 不直接执行 DMA 传送程序来完成数据搬运，因此 C 的说法错误。
- 对于 SSD、网络适配器等高速设备，通常采用 DMA 方式进行输入/输出，因此 D 正确。

## 选项分析
A. 正确。查询方式下，CPU 通过查询程序轮询设备状态并完成 I/O。

B. 正确。中断方式下，由中断服务程序处理 I/O 相关操作。

C. 错误。DMA 的核心特点是由 DMA 控制器负责数据传送，不是由 CPU 直接执行 DMA 传送程序来进行数据搬运。

D. 正确。SSD、网络适配器等高速设备一般适合采用 DMA 方式。

## 易错点
- “DMA 方式”不等于“CPU 执行 DMA 程序传数据”，关键在于数据传送不由 CPU 直接参与。
- 查询方式与中断方式都可能涉及 CPU 处理控制逻辑，但真正的数据搬运机制不同，不能混淆。
