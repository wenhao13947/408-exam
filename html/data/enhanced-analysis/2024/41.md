## 答案

### （1）
算法思想：按照拓扑排序的过程逐步删除顶点。先统计各顶点当前入度；之后重复执行“选取入度为 $0$ 的顶点并删除”的操作。若在某一轮中，入度为 $0$ 的顶点个数不是 $1$，则拓扑序列不唯一，返回 `0`；若 $n$ 轮中每一轮都恰好只有一个入度为 $0$ 的顶点，并且最终全部顶点都被处理完，则该有向图存在唯一拓扑序列，返回 `1`。

### （2）
可先用邻接矩阵按列统计各顶点入度，再进行 $n$ 轮“唯一入度为 $0$ 顶点”的检查与删除。对应算法如下：若每轮都唯一，则返回 `1`；否则返回 `0`。

## 解析

### 解法一：暴力法

枚举所有可能的顶点排列，逐个检查每个排列是否满足所有有向边的先后约束，再统计合法拓扑序列数量是否恰为 1。最坏需要检查 $n!$ 个排列，时间复杂度为阶乘级，只适合极小规模图。

### 解法二：优化解法

执行拓扑排序，并在每一轮检查当前入度为 0 的顶点是否恰好只有一个；出现多个说明序列不唯一，出现 0 个说明存在环。邻接矩阵实现的时间复杂度为 $O(n^2)$。

> **考场建议：** 暴力枚举能帮助明确“唯一”的含义，但正式作答要利用拓扑排序过程中的唯一选择性判定，不能真的生成全部排列。

### （1）算法基本设计思想
拓扑排序的基本过程是：每次从当前图中选取一个入度为 $0$ 的顶点输出，然后删除该顶点及其发出的边。

要使拓扑序列唯一，关键条件是：在拓扑排序的每一步，当前图中都只能有一个入度为 $0$ 的顶点。

因此可按如下思路判断：

1. 先求出所有顶点的入度。
2. 重复进行 $n$ 轮检查：
   - 扫描所有顶点，统计当前入度为 $0$ 的顶点个数；
   - 若个数不等于 $1$，则说明：
     - 若为 $0$，图中剩余部分存在回路，无法继续拓扑排序；
     - 若大于 $1$，当前至少有两种选择，拓扑序列不唯一。
     此时都应返回 `0`。
   - 若恰好为 $1$，则删除该顶点，并将其所有后继顶点的入度减 $1$。
3. 若 $n$ 轮都能顺利完成，说明每一步选择都唯一，故拓扑序列唯一，返回 `1`。

这里后一轮的判断建立在前一轮“删除顶点并更新入度”的结果之上，因此各轮之间是逐步承接的。

### （2）算法描述
邻接矩阵存储下，顶点 $v$ 的入度可通过统计第 $v$ 列中非零元素得到。之后模拟拓扑排序过程即可。

```c
int uniquely(MGraph G)
{
    int n = G.numVertices;
    int inDegrees[MAXV];

    /* 计算所有顶点的入度 */
    for (int v = 0; v < n; v++) {
        inDegrees[v] = 0;
        for (int i = 0; i < n; i++) {
            if (G.Edge[i][v] != 0)
                inDegrees[v] += G.Edge[i][v];
        }
    }

    /* 进行 n 轮拓扑删除 */
    for (int k = 0; k < n; k++) {
        int count0 = 0;   // 入度为 0 的顶点个数
        int v0 = -1;      // 本轮唯一可选的顶点

        /* 查找当前所有入度为 0 的顶点 */
        for (int i = 0; i < n; i++) {
            if (inDegrees[i] == 0) {
                count0++;
                v0 = i;
            }
        }

        /* 若本轮不是唯一一个入度为 0 的顶点，则不唯一 */
        if (count0 != 1) {
            return 0;
        }

        /* 删除该顶点，置为 -1 表示已处理 */
        inDegrees[v0] = -1;

        /* 其所有后继顶点入度减 1 */
        for (int j = 0; j < n; j++) {
            if (G.Edge[v0][j] != 0)
                inDegrees[j]--;
        }
    }

    /* 每一轮都唯一，则拓扑序列唯一 */
    return 1;
}
```

## 复杂度分析
设图有 $n$ 个顶点。

- 统计入度需要扫描整个邻接矩阵，时间复杂度为 $O(n^2)$。
- 拓扑删除共进行 $n$ 轮，每轮需要扫描全部顶点查找入度为 $0$ 的顶点，并扫描一行更新后继顶点入度，因此总时间复杂度仍为 $O(n^2)$。
- 额外使用一个入度数组，空间复杂度为 $O(n)$。

## 易错点
- 不能只判断“是否存在入度为 $0$ 的顶点”，而必须判断“是否恰好只有一个入度为 $0$ 的顶点”。
- 若某一轮不存在入度为 $0$ 的顶点，说明图中存在回路，也应返回 `0`。
- 邻接矩阵求入度时应按列统计，不是按行统计。
- 删除已选顶点时要做好标记，避免后续重复选取。
