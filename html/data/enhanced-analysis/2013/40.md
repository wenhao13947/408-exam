## 答案

A。正确的是 **I、II 和 III**，因为 SMTP 用于“发送”阶段，既支持用户代理向邮件服务器发送邮件，也支持邮件服务器之间转发邮件；而从邮件服务器到用户代理读取邮件通常使用 POP3，不属于 SMTP 的功能。

## 解析

判断本题的关键，是先分清 **SMTP** 和 **POP3** 在电子邮件系统中的职责。

电子邮件的典型传输过程可以分成三段：

- **用户代理（User Agent） -> 发送端邮件服务器**：使用 **SMTP**
- **发送端邮件服务器 -> 接收端邮件服务器**：使用 **SMTP**
- **接收端邮件服务器 -> 用户代理**：通常使用 **POP3**（也可能是 IMAP，但本题给定语境中对应的是 POP3）

因此，SMTP 的核心作用是完成邮件的**提交与转发**，属于发送链路上的协议，而不是用户收取邮件时使用的协议。

再看各断言：

- **I 正确**：传统 SMTP 只支持传输 **7 比特 ASCII** 内容。这也是为什么后来需要通过 **MIME** 对邮件内容进行扩展，使邮件能够表示非 ASCII 字符以及附件等更丰富的内容。
- **II 正确**：邮件服务器之间转发邮件，使用的正是 **SMTP**。
- **III 正确**：用户代理把邮件提交给邮件服务器时，也使用 **SMTP**。
- **IV 错误**：从邮件服务器到用户代理这一过程是“取信/收信”，不属于 SMTP 的发送功能，教材中对应的是 **POP3**。

所以正确组合为 **I、II、III**，选 **A**。

## 选项分析

- **I. 只支持传输 7 比特 ASCII 码内容**
  - 正确。传统 SMTP 的数据内容能力有限，只能直接处理 7 比特 ASCII。若要传中文、音频、图片、视频等内容，需要借助 **MIME** 扩展。

- **II. 支持在邮件服务器之间发送邮件**
  - 正确。服务器之间的邮件传递属于 SMTP 的典型应用场景。

- **III. 支持从用户代理向邮件服务器发送邮件**
  - 正确。用户写好邮件后提交到发件服务器，这一段使用 SMTP。

- **IV. 支持从邮件服务器向用户代理发送邮件**
  - 错误。用户从邮箱中读取邮件，不是 SMTP 的职责；按本题考点，应由 **POP3** 完成。

- **A. 仅 I、II 和 III**
  - 正确，对应本题答案。

- **B. 仅 I、II 和 IV**
  - 错误，IV 错。

- **C. 仅 I、III 和 IV**
  - 错误，IV 错，且遗漏 II。

- **D. 仅 II、III 和 IV**
  - 错误，IV 错，且遗漏 I。

## 易错点

- 容易把“邮件到达用户邮箱”误认为“服务器主动发给用户代理”，从而误选 IV。考试里要区分：
  - **发送/转发**：SMTP
  - **读取/接收**：POP3

- “SMTP 只支持 7 比特 ASCII”说的是**传统 SMTP 本身的原始能力**，并不意味着现实中电子邮件不能发中文或附件；这类扩展通常依赖 **MIME**。
