## 答案
（1）该指令系统最多有 `16` 条指令，最多有 `8` 个通用寄存器；`MAR` 至少为 `16` 位，`MDR` 至少为 `16` 位。  

（2）转移指令的目标地址范围为 `0000H ~ FFFFH`，即 `0 ~ 2^{16}-1`。  

（3）`add (R4), (R5)+` 对应的机器码为 `2315H`。执行后发生改变的是 `R5` 和存储单元 `M[5678H]`：  
`R5 = 5679H`，`M[5678H] = 68ACH`。

## 解析
### （1）指令条数、寄存器个数以及 MAR、MDR 位数
由题给指令格式可知，操作码 `OP` 占 `4` 位，因此该指令系统最多可有
$$2^4=16$$
条指令。

每个操作数部分共占 `6` 位，其中寻址方式占 `3` 位，寄存器编号占 `3` 位，因此通用寄存器编号最多可表示
$$2^3=8$$
个通用寄存器。

主存地址空间大小为 `128KB`，按字编址，字长为 `16` 位，即每个字占 `2B`，所以主存中共有
$$128KB / 2B = 2^{16}$$
个存储单元。要唯一标识这 `2^{16}` 个字地址，`MAR` 至少需要 `16` 位。

`MDR` 用来存放一个存储字的数据。题目中机器字长为 `16` 位，因此 `MDR` 至少需要 `16` 位。

### （2）转移指令的目标地址范围
题目说明转移指令采用相对寻址方式，目标地址为
$$（PC）+（Rn）$$
其中相对偏移量用补码表示。

由第（1）问可知，主存按字编址后共有 `2^{16}` 个地址，因此可用地址范围为
$$0 \sim 2^{16}-1$$
即
$$0000H \sim FFFFH$$

因此，转移指令的目标地址范围就是整个主存地址范围：
$$0000H \sim FFFFH$$

### （3）机器码及执行结果
先根据题目给出的字段定义编码。

- `OP = 0010`，表示 `add`
- 源操作数为 `(R4)`，故 `Ms = 001`，`Rs = 100`
- 目的操作数为 `(R5)+`，故 `Md = 010`，`Rd = 101`

拼接后得到机器码：
$$0010\ 001\ 100\ 010\ 101$$
即
$$0010\ 0011\ 0001\ 0101_2 = 2315H$$

再分析指令执行过程。

已知：
- `(R4)=1234H`，故源操作数为
  $$M[1234H]=5678H$$
- `(R5)=5678H`，故目的操作数原值为
  $$M[5678H]=1234H$$

执行加法：
$$5678H + 1234H = 68ACH$$

由于目的操作数采用寄存器间接自增寻址 `(R5)+`，其含义是先按 `R5` 当前内容访问存储单元，再执行
$$R5 \leftarrow R5 + 1$$

因此：
- 运算结果写回目的存储单元 `M[5678H]`
- `R5` 在取操作数后自增 1

故执行后改变的内容为：
- $R5: 5678H \rightarrow 5679H$
- $M[5678H]: 1234H \rightarrow 68ACH$

## 易错点
- 通用寄存器个数只看寄存器编号字段的位数，不把两个操作数字段中的寄存器位数相加。
- `(R5)+` 是先取数、后自增，写回位置仍是原来 `R5` 所指向的存储单元。
- 本题第（2）问虽然是相对寻址，但最终目标地址仍受主存地址空间限制。
