## 答案
选 **D**。CPU 速度提高 50% 后，CPU 部分耗时按 $1.5$ 倍性能折算为原来的 $\frac{1}{1.5}$，总运行时间为 $70\text{s}$。

## 解析
题干给出基准程序 A 的运行时间为 $100\text{s}$，其中：

- CPU 时间：$90\text{s}$
- I/O 时间：$100-90=10\text{s}$

CPU 速度提高 50%，表示处理能力变为原来的 $1.5$ 倍，因此 CPU 执行同样工作量所需时间变为原来的 $\frac{1}{1.5}$：

$$
90 \div 1.5 = 60\text{s}
$$

I/O 速度不变，所以 I/O 时间仍为 $10\text{s}$。因此总运行时间为：

$$
60 + 10 = 70\text{s}
$$

所以正确答案是 **D**。

## 选项分析
- **A. 55s**：把 CPU 速度提高 50% 误理解成 CPU 时间减少一半，属于常见错误。
- **B. 60s**：只计算了 CPU 时间变化，漏掉了不变的 I/O 时间。
- **C. 65s**：没有对应正确的速度-时间换算关系。
- **D. 70s**：CPU 时间变为 $60\text{s}$，加上不变的 I/O 时间 $10\text{s}$，结果正确。

## 易错点
- “速度提高 50%”不是“时间减少 50%”，而是性能变为原来的 $1.5$ 倍。
- 时间应按比例缩短为原来的 $\frac{1}{1.5}$，不是直接减半。
- 题目中 I/O 速度不变，I/O 时间必须保留。
