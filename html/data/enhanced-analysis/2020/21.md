## 答案
错误选项是 **B**。理由是：可屏蔽中断不是“请求有效就立即响应”，CPU 只有在**开中断**且**当前指令执行完毕**后才会响应。

## 解析
题干考查外部中断的基本特性。外部中断分为两类：

- **NMI（不可屏蔽中断）**：不受中断允许位影响，CPU 即使处于关中断状态也能响应。
- **可屏蔽中断**：是否响应受中断允许状态影响，且要等当前指令执行结束后再处理。

因此逐项判断：

- **A 正确**：CPU 关中断时仍能响应 NMI。
- **B 错误**：可屏蔽中断不是“有效就立即响应”，还要满足中断响应条件。
- **C 正确**：不可屏蔽中断的优先级高于可屏蔽中断，通常与异常同级。
- **D 正确**：可通过**中断屏蔽字**改变可屏蔽中断的处理优先级。

CPU 响应中断通常要满足三点：  
1. 中断源提出请求；  
2. CPU 允许中断；  
3. 当前指令执行完毕。  

B 违背了第 2、3 点，所以是错误项。

## 选项分析
**A. 正确**  
NMI 不受关中断影响，CPU 处于关中断状态时仍可响应。

**B. 错误**  
“立即响应”表述错误。可屏蔽中断必须等到一条指令执行结束，并且 CPU 处于开中断状态时才会响应。

**C. 正确**  
NMI 的优先级高于可屏蔽中断，属于更紧急的中断类型。

**D. 正确**  
中断屏蔽字可用于调整可屏蔽中断的处理优先级；与之相关的还有“中断响应优先级”，它由硬件排队电路决定。

## 易错点
- 把“中断请求有效”误认为“CPU 立刻响应”。对可屏蔽中断来说，这不成立。
- 混淆“处理优先级”和“响应优先级”：前者可受中断屏蔽字影响，后者由硬件决定。
- 记住：NMI 不受关中断影响，可屏蔽中断受影响。
