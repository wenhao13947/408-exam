## 答案

选 **C. 存在，可能不唯一**。

## 解析

由题意可知，这是一个**有向图的邻接矩阵**，且**主对角线以下的元素全为 0**。

设邻接矩阵为 $A=(a_{ij})$。在有向图的邻接矩阵中，若 $a_{ij}=1$，表示存在边 $v_i \to v_j$。  
现在主对角线以下元素全为 0，也就是当 $i>j$ 时，恒有 $a_{ij}=0$。这说明：

- 不存在从编号大的顶点指向编号小的顶点的边；
- 图中的边只可能是从小编号顶点指向大编号顶点。

于是，若按顶点编号顺序 $v_1,v_2,\dots,v_n$ 观察，所有边都满足“方向向后”。这样的图不可能形成有向环。

原因很直接：一旦存在有向环，沿环走一圈最终要回到起点，就不可能始终只从小编号走向大编号；中途必然出现某一步从大编号回到小编号，这与“主对角线以下全为 0”矛盾。

因此该图一定是一个 **DAG（有向无环图）**，所以**一定存在拓扑序列**。

但“存在拓扑序”并不意味着“拓扑序唯一”。拓扑序是否唯一，取决于在排序过程中是否会同时出现多个入度为 0 的顶点。题干只限制了边的方向，不保证任意两点之间都有先后约束，所以拓扑序**可能唯一，也可能不唯一**。

结合示意图，这里应当读图关注其作用：它不是用来证明“存在”，而是用来举例说明“在满足下三角全为 0 的条件下，拓扑序仍然可能有多种”。

所以正确结论是：**存在拓扑序列，但未必唯一**。

## 选项分析

**A. 存在，且唯一**

错误。  
题干条件只能推出图无环，从而推出**拓扑序存在**；但不能推出**唯一**。只要图中某一步有两个或以上入度为 0 的顶点可选，就会得到不同的拓扑序。因此“且唯一”过强。

**B. 存在，且不唯一**

错误。  
“存在”是对的，但“且不唯一”表示**一定不唯一**，这不成立。  
例如当边恰好把所有顶点串成严格先后关系时，拓扑序就可能唯一。所以“不唯一”不是题干必然推出的结论。

**C. 存在，可能不唯一**

正确。  
主对角线以下全为 0，说明边只能从小编号指向大编号，图中不可能有环，因此**一定存在拓扑序**；但题干没有保证唯一性，所以只能说**可能不唯一**。

**D. 无法确定是否存在**

错误。  
这道题是可以确定的。由“主对角线以下元素均为零”可直接推出图是 DAG，而 DAG 一定存在拓扑序，因此不是“无法确定”。

## 易错点

1. 把“存在拓扑序”误判成“拓扑序唯一”。  
无环只保证存在，不保证唯一。

2. 把 “B. 存在，且不唯一” 和 “C. 存在，可能不唯一” 混淆。  
这两个选项的区别在于：  
- “且不唯一”表示必然不唯一；  
- “可能不唯一”表示不保证唯一。  
本题只能推出后者。

3. 只凭“矩阵上三角”记结论，不理解原因。  
本质原因是：边只能从小编号指向大编号，因此不可能形成回路。只要抓住这一点，就能稳定作答。
