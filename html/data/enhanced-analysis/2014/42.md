## 答案

### （1）
本题中的网络可抽象为**无向图**。

### （2）
可采用“**路由器表头结点 + 邻接链表结点**”的链式存储结构保存链路状态信息。  
其中，邻接链表结点分为两类：

- 一类表示与其他路由器的链路信息；
- 一类表示与直连子网的连接信息。

可定义为：

$$
\text{Arc：}\langle id,\ ip,\ metric\rangle
$$

$$
\text{Net：}\langle prefix,\ mask,\ metric\rangle
$$

$$
\text{LNode：}\langle next,\ flag,\ (Arc\ 或\ Net)\rangle
$$

$$
\text{HNode：}\langle router\_id,\ next,\ next\_hnode\rangle
$$

写成 C 结构定义可表述为：

```c
struct Arc {
    uint32_t id;
    uint32_t ip;
    int metric;
};

struct Net {
    uint32_t prefix;
    uint32_t mask;
    int metric;
};

struct LNode {
    struct LNode *next;
    int flag;          // 1: 邻接路由器  2: 直连子网
    union {
        struct Arc arc;
        struct Net net;
    } info;
};

struct HNode {
    uint32_t router_id;
    struct LNode *next;
    struct HNode *next_hnode;
};
```

对应题 42 表，其链式结构示意图可写成：

- `H(R1)`：`R2 -> R3 -> 192.1.1.0/24`
- `H(R2)`：`R1 -> R4 -> 192.1.6.0/24`
- `H(R3)`：`R4 -> R1 -> 192.1.5.0/24`
- `H(R4)`：`R3 -> R2 -> 192.1.7.0/24`

其中每个表头结点再通过 `next_hnode` 串成一个表头链表。  
若只按题目要求“示意图中仅以 ID 标识结点”，则可把子网结点分别写成其网络前缀标识。

### （3）
按 Dijkstra 算法，从 R1 到各子网 `192.1.x.0/24` 的最短路径及费用依次为：

| 次序 | 目的子网 | 最短路径 | 费用 |
|---|---|---|---|
| 1 | `192.1.1.0/24` | `R1 -> 192.1.1.0/24` | 1 |
| 2 | `192.1.5.0/24` | `R1 -> R3 -> 192.1.5.0/24` | 3 |
| 3 | `192.1.6.0/24` | `R1 -> R2 -> 192.1.6.0/24` | 4 |
| 4 | `192.1.7.0/24` | `R1 -> R2 -> R4 -> 192.1.7.0/24` | 8 |

## 解析

### （1）
题目给出的是路由器之间的连接关系及链路费用。把路由器看成顶点，把链路看成边，把费用看成边权，就得到一个图结构。

又因为题表中链路是成对出现的，例如：

- `R1 <-> R2`，费用为 3；
- `R1 <-> R3`，费用为 2；
- `R2 <-> R4`，费用为 4；
- `R3 <-> R4`，费用为 6。

因此可抽象为**无向图**。

### （2）
本问要求保存的是各路由器的链路状态信息 LSI。题表中的信息有两类：

1. 与其他路由器相连的链路信息：包括对端路由器 ID、本地接口 IP、费用；
2. 与直连子网相连的信息：包括网络前缀、掩码或前缀长度、费用。

因此，用“表头结点表示路由器，链表结点表示该路由器的邻接信息”最合适，本质上属于邻接表式的链式存储。

可把各字段作用整理如下：

| 结点类型 | 主要字段 | 含义 |
|---|---|---|
| `HNode` | `router_id` | 当前路由器的 Router ID |
| `HNode` | `next` | 指向该路由器的邻接信息链 |
| `HNode` | `next_hnode` | 指向下一个路由器表头结点 |
| `LNode` | `flag` | 区分“邻接路由器”或“直连子网” |
| `Arc` | `id, ip, metric` | 邻接路由器 ID、本地接口 IP、链路费用 |
| `Net` | `prefix, mask, metric` | 直连网络前缀、掩码、到该网络费用 |

这样设计有两个直接好处：

1. 能完整保存题表中的全部 LSI；
2. 邻接信息长度不固定，用链式存储更自然。

根据题表，可写出 4 个表头结点：

- `R1(10.1.1.1)` 的邻接信息：  
  到 `R2`，费用 3；到 `R3`，费用 2；直连 `192.1.1.0/24`，费用 1。
- `R2(10.1.1.2)` 的邻接信息：  
  到 `R1`，费用 3；到 `R4`，费用 4；直连 `192.1.6.0/24`，费用 1。
- `R3(10.1.1.5)` 的邻接信息：  
  到 `R4`，费用 6；到 `R1`，费用 2；直连 `192.1.5.0/24`，费用 1。
- `R4(10.1.1.6)` 的邻接信息：  
  到 `R3`，费用 6；到 `R2`，费用 4；直连 `192.1.7.0/24`，费用 1。

如果结合题图来看，读图时把每个路由器看成一个表头结点、把与之直接相连的路由器和子网挂在同一条邻接链上，就能很自然地对应到上述结构。

### （3）
本问只依赖题图和题表给出的拓扑与费用，按 Dijkstra 的单源最短路径策略，从源点 `R1` 依次确定到各目的子网的最短路径。

先整理题目中的边权：

- 路由器之间：
  - `R1 -> R2 = 3`
  - `R1 -> R3 = 2`
  - `R2 -> R4 = 4`
  - `R3 -> R4 = 6`
- 路由器到本地子网：
  - `R1 -> 192.1.1.0/24 = 1`
  - `R2 -> 192.1.6.0/24 = 1`
  - `R3 -> 192.1.5.0/24 = 1`
  - `R4 -> 192.1.7.0/24 = 1`

下面依次计算。

#### 第一步：确定离 R1 最近的目的子网
`R1` 直连 `192.1.1.0/24`，费用为：

$$
1
$$

所以最先确定：

$$
R1 \to 192.1.1.0/24,\quad 费用=1
$$

#### 第二步：考察经相邻路由器到其他子网
从 `R1` 出发先到相邻路由器：

- 到 `R3` 的费用：`2`
- 到 `R2` 的费用：`3`

经 `R3` 到其直连子网 `192.1.5.0/24`：

$$
2+1=3
$$

故可得：

$$
R1 \to R3 \to 192.1.5.0/24,\quad 费用=3
$$

#### 第三步：继续确定下一最短子网
经 `R2` 到其直连子网 `192.1.6.0/24`：

$$
3+1=4
$$

故有：

$$
R1 \to R2 \to 192.1.6.0/24,\quad 费用=4
$$

#### 第四步：求到 `192.1.7.0/24` 的最短路径
到达 `R4` 有两条候选路径：

1. 经 `R2`：
$$
R1 \to R2 \to R4 = 3+4=7
$$

再到子网 `192.1.7.0/24`：
$$
7+1=8
$$

2. 经 `R3`：
$$
R1 \to R3 \to R4 = 2+6=8
$$

再到子网 `192.1.7.0/24`：
$$
8+1=9
$$

因此应取较小者：

$$
R1 \to R2 \to R4 \to 192.1.7.0/24,\quad 费用=8
$$

按题表给出的边权复核，

$$
3+4+1=8
$$

该路径费用应为 `8`，最短路径为：

$$
R1 \to R2 \to R4 \to 192.1.7.0/24,\quad 费用=8
$$

## 易错点

1. **第（1）问只答“图”可以得分，但更准确的是“无向图”。**  
题中链路是双向对应描述，不应写成有向图。

2. **第（2）问的关键不在唯一写法，而在是否能完整表达两类邻接信息。**  
必须同时表示：
- 路由器到路由器的链路；
- 路由器到直连子网的连接。

3. **第（3）问要按题表重新计算最后一项。**  
`192.1.7.0/24` 的最短路必须按题表重算，正确结果是：
$$
R1 \to R2 \to R4 \to 192.1.7.0/24,\quad 费用=8
$$

4. **注意题图中网络前缀有 `192.168.x.0/24` 与 `192.1.x.0/24` 的展示不一致。**  
但题目设问使用 `192.1.x.x`，作答时应按题目设问写成 `192.1.x.0/24`。
