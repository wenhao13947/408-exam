## 答案

(1) 采用表达式树的中序遍历输出中缀表达式。遍历时，叶结点直接输出操作数；非根且非叶结点在其子表达式外加一对括号，以反映该结点对应运算的计算次序；根结点外层不加括号。

(2) 可按中序递归遍历实现，先输出左子树，再输出当前结点，再输出右子树，并在非根非叶结点处输出括号。

## 解析

> **考场判断：** 按表达式树递归输出“左子树—根—右子树”，并只给非根运算结点补括号，就是本题最直接且最优的算法。每个结点必须访问一次，因此 $O(n)$ 已经达到下界，不需要额外编造暴力法和最优法。

表达式树的中序序列对应中缀表达式的基本顺序，但仅有遍历序列还不够，必须结合树结构补上必要括号，才能保证计算次序与原表达式树一致。

对每个结点分三类处理：

- 空结点：返回。
- 叶结点：它是操作数，直接输出，不加括号。
- 分支结点：先递归输出左子树，再输出当前结点，再递归输出右子树；若该结点不是根结点，则在这一子表达式左右分别加括号。

这样得到的就是等价的中缀表达式。题目给出的两个例子也说明了这一点，例如 `(a+b)*(c*(−d))` 和 `(a*b)+(−(c−d))` 都是按树结构用括号明确了运算次序。

代码实现如下：

```c
typedef struct node{
    char data[10];
    struct node *left, *right;
} BTree;

void inorder(BTree *root, int depth) {
    if (root == NULL) return;

    int isRoot = (depth == 1);
    int isLeaf = (root->left == NULL && root->right == NULL);

    if (!isRoot && !isLeaf) printf("(");

    inorder(root->left, depth + 1);
    printf("%s", root->data);
    inorder(root->right, depth + 1);

    if (!isRoot && !isLeaf) printf(")");
}

void solve(BTree *root) {
    inorder(root, 1);
}
```

这里 `depth == 1` 用来判断根结点，左右孩子都为空用来判断叶结点；函数使用 `inorder` 命名，以体现其执行的是中序遍历。
