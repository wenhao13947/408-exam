## 答案
选 **B. 500**。确认号表示“下一次期望收到的字节序号”，本题中主机乙正等待第 2 段，其首字节序号为 500。

## 解析
TCP 中，**序号**指的是该报文段数据部分**第一个字节**的编号；**确认号**是期望收到的对方**下一个报文段的第一个字节序号**。

题目给出：
- 3 个连续的 TCP 段；
- 第 2 段有效载荷为 400 字节；
- 第 3 段序号为 900；
- 主机乙只正确收到第 1 段和第 3 段。

因为 3 个报文段是连续的，而第 3 段的序号已知为 900，所以第 2 段的首字节序号应为：
$$900 - 400 = 500$$

主机乙既然已经收到第 1 段和第 3 段，但第 2 段没收到，按 TCP 累积确认的规则，它当前期望收到的仍是第 2 段，因此确认号就是第 2 段的首字节序号 **500**。

## 选项分析
- A. 300：与题目中已知的连续分段和第 3 段序号无法对应。
- B. 500：正确，正是乙方当前期望收到的下一个字节序号。
- C. 1200：不是本题的确认号含义，属于把已收到数据的末尾位置误当成确认号。
- D. 1400：同样不符合 TCP 确认号定义。

## 易错点
- 不要把“确认号”理解成“已收到的最后一个字节序号”，它表示的是**下一字节的序号**。
- 题目给出“第 3 段序号为 900”和“第 2 段长度为 400”，先反推第 2 段首字节序号，再确定确认号。
