## 答案

### （1）
先分别求出两个带头结点单链表的长度，设为 $m$ 和 $n$（长度均不包含头结点）。

然后让较长链表的工作指针先前进 $|m-n|$ 步，使两个指针到各自表尾的剩余距离相同。此后两指针同步后移，第一次指向同一结点时，该结点就是两个链表共同后缀的起始位置。

### （2）
可按以下 C 语言算法实现：

```c
typedef struct Node {
    char data;
    struct Node *next;
} Node;

/* 计算链表长度，长度不包含头结点 */
int getLength(Node *h) {
    int len = 0;
    Node *p = h->next;
    while (p != NULL) {
        len++;
        p = p->next;
    }
    return len;
}

/* 查找共同后缀的起始结点，若不存在则返回 NULL */
Node *findCommonSuffix(Node *str1, Node *str2) {
    int m = getLength(str1);
    int n = getLength(str2);

    /* 工作指针应从首元结点开始，而不是从头结点开始 */
    Node *p = str1->next;
    Node *q = str2->next;

    if (m > n) {
        for (int i = 0; i < m - n; i++) {
            p = p->next;
        }
    } else {
        for (int i = 0; i < n - m; i++) {
            q = q->next;
        }
    }

    while (p != NULL && q != NULL && p != q) {
        p = p->next;
        q = q->next;
    }

    return p;   /* 相交则返回共同后缀起点，否则返回 NULL */
}
```

### （3）
时间复杂度为 $O(m+n)$，也可写成 $O(\text{len}_1+\text{len}_2)$。

## 解析

### 解法一：暴力法

对第一个链表的每个结点，都从第二个链表表头开始查找是否存在地址相同的结点；找到的第一个公共结点就是公共后缀起点。最坏时间复杂度为 $O(mn)$，空间复杂度为 $O(1)$。注意比较的是结点地址，不是字符值。

### 解法二：优化解法

先求两条链表长度，让较长链表先走长度差，再同步前进，首次地址相同的位置就是公共后缀起点，时间复杂度为 $O(m+n)$。

> **考场建议：** 暴力法可以先保证“比较结点地址”这个关键得分点，随后再思考如何让两条链表尾部对齐，消除重复扫描。

### （1）
题目中的“共同后缀”不是“字符值相同”，而是“从某个结点开始，后面的结点被两个链表共同使用”。因此要判断的是两个指针是否指向同一结点地址，而不是结点中 `data` 是否相等。

若直接让两个链表从头同时后移，由于链表长度可能不同，它们通常不会同时进入公共后缀部分，所以需要先做“尾部对齐”。结合图示理解即可：先让较长的那个链表多走几步，把两条链表剩余的长度调成一样，之后再同步前进，首次重合的位置就是图中所示的结点 $p$。

**图解：尾部对齐示意**

看长链表先走若干步后，两指针如何在共同后缀起点首次重合。

![尾部对齐示意](/data/enhanced-analysis/assets/2012/42/original-analysis-1.svg)

设两个链表实际长度分别为 $m$、$n$。

- 若 $m>n$，则长链表先走 $m-n$ 步；
- 若 $n>m$，则另一条链表先走 $n-m$ 步；
- 若 $m=n$，则两者都不必先走。

这样处理后，两个指针到表尾的距离相同。由于共同后缀部分完全重合，所以它们一旦进入公共部分，就会在共同后缀的第一个结点处首次相遇。这个结点就是所求起始位置。

### （2）
代码实现分两步：

第一步，分别求长度。由于题目说明是“带头结点的单链表”，所以长度统计应从首元结点开始，头结点不计入长度，因此 `getLength` 从 `h->next` 开始遍历。

第二步，进行尾部对齐后同步移动：

1. 令 `p`、`q` 分别指向两链表的首元结点；
2. 较长链表先前进长度差步；
3. 然后 `p`、`q` 同时向后移动；
4. 当 `p == q` 时，说明两指针指向同一结点，该结点即共同后缀起点；
5. 若一直走到 `NULL` 仍未相遇，则说明两链表没有共同后缀，返回 `NULL`。

这里要特别注意：比较条件必须是“结点地址是否相同”，即 `p == q`，不能写成 `p->data == q->data`。因为后缀共享的本质是共享存储结点，不是字符恰好相同。

### （3）
设两链表长度分别为 $m$ 和 $n$。

- 求两个链表长度各需一次遍历，代价为 $O(m+n)$；
- 长链表先走长度差，最多走 $|m-n|$ 步；
- 之后同步前进，最多再走 $\min(m,n)$ 步。

总时间仍为线性数量级，即
$$
O(m+n)
$$

空间上只用了若干辅助指针和计数变量，空间复杂度为
$$
O(1)
$$

## 易错点

1. 指针移动时必须区分头结点和首元结点的编号。真正可执行的做法是：让较长链表的工作指针从首元结点出发，先前进 $|m-n|$ 步。实现时应严格采用这一可执行逻辑。

2. 实现代码中
   `Node *p1 = h1; Node *p2 = h2;`
   若题意中的 `h1`、`h2` 是头结点指针，这样写会把头结点也纳入对齐过程，与前面 `getLength`“不统计头结点”的口径不完全一致。更严谨的写法应当是：
   `Node *p = str1->next; Node *q = str2->next;`
   即从首元结点开始移动。这样与题目“带头结点单链表”的条件完全一致。

3. 若两链表没有共同后缀，循环结束时应返回 `NULL`。因此同步移动时最好写成同时判断 `p != NULL && q != NULL`，逻辑更完整。
