## 答案

A。进程时间片用完时，说明该进程已经连续占用 CPU 一段时间，此时适当降低其优先级，便于调度其他就绪进程执行，符合常见动态优先级调度策略。

## 解析

本题考查的是**进程优先级动态调整的合理时机**。

在操作系统中，优先级并不是一成不变的。为了兼顾系统响应性与公平性，调度程序常根据进程的运行行为动态调整优先级。判断是否应“降低”某个进程的优先级，核心看这个进程是否已经较多占用 CPU，是否需要把处理机机会让给别的进程。

进程**时间片用完**，通常意味着它属于较偏 **CPU-bound** 的进程，已经获得了一次完整的处理机使用机会。如果此时不降低其优先级，该进程可能在后续调度中继续较频繁地获得 CPU，不利于其他进程运行。因此，时间片耗尽后适当降低优先级，是合理且常见的做法。

其余几个时机都不适合“降低”优先级：

- 刚完成 I/O 的进程，往往是 **I/O-bound** 进程。这类进程此前多数时间在等待外设，真正占用 CPU 的时间较短。为了让它尽快处理 I/O 结果、提升交互响应，通常会维持或适当提高其优先级，而不是降低。
- 长期处于就绪队列的进程，说明它长时间没有得到 CPU，已经有发生**饥饿**的风险。此时若再降低优先级，只会更难被调度，正确思路应是适当提高优先级。
- 从就绪态转为运行态，只是说明它刚被调度上处理机，还没有表现出“占用 CPU 过多”的特征，此时直接降低优先级缺乏依据。

因此，合理的降低优先级时机是 **A：进程时间片用完**。

## 选项分析

A. 进程时间片用完  
正确。时间片用完说明该进程已经持续运行了一段时间，适当降低优先级有助于实现公平调度。

B. 进程刚完成 I/O 操作，进入就绪队列  
错误。此类进程通常应尽快获得 CPU 处理后续数据，常见做法是提高或保持较高优先级，而不是降低。

C. 进程长期处于就绪队列  
错误。长期等待意味着可能发生饥饿，应考虑提升优先级进行“老化（aging）”处理，而非降低。

D. 进程从就绪状态转为运行状态  
错误。此时只是刚开始运行，还没有出现应被“惩罚性下调”的条件；通常应在其时间片耗尽后再考虑降低优先级。

## 易错点

- 不要把“进入就绪队列”一概理解为应降低优先级。要区分原因：  
  刚完成 I/O 返回就绪队列，往往应优先照顾其响应性。
- 不要把“长期等待”理解成“优先级低所以继续降低”。恰恰相反，为防止饥饿，通常要通过 **aging** 提高其优先级。
- “从就绪到运行”只是调度结果，不是优先级下调依据；“时间片用完”才是更典型的下调触发点。
