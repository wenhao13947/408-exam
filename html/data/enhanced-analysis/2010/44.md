## 答案

（1）数据 Cache 的总容量为 **532B**。

（2）`a[0][31]` 所在主存块对应的 Cache 行号为 **6**，`a[1][1]` 所在主存块对应的 Cache 行号为 **5**。

（3）程序 A 的数据访问命中率为 **93.75%**，程序 B 的数据访问命中率为 **0**；因此 **程序 A 的执行时间更短**。

## 解析

### （1）数据 Cache 总容量

主存地址空间为 `256MB`，按字节编址，因此主存地址长度为 28 位：

$$256MB=2^{28}B$$

数据 Cache 有 8 个 Cache 行，所以行号字段需要 3 位：

$$\log_2 8=3$$

每个 Cache 行大小为 `64B`，所以块内地址需要 6 位：

$$\log_2 64=6$$

因此地址划分为：

- 标记位 `Tag`：$28-3-6=19$ 位
- 行号：3 位
- 块内地址：6 位

题目说明不考虑用于 Cache 一致性维护和替换算法的控制位，但仍需有有效位。故每个 Cache 行包含：

- 数据：`64B`
- 标记位：19 bit
- 有效位：1 bit

每行附加位共 20 bit，即：

**图解：Cache行结构示意**

图中可对应数据位、标记位与有效位的组成。

![Cache行结构示意](/data/enhanced-analysis/assets/2010/44/original-analysis-1.svg)

$$20\text{ bit}=\frac{20}{8}B=2.5B$$

所以数据 Cache 总容量为：

$$8\times(64+2.5)B=532B$$

### （2）指定数组元素对应的 Cache 行号

已知：

- `int` 型占 4B
- 数组 `a` 按行优先存放
- 首地址为 320
- 数据 Cache 采用直接映射
- 块大小为 `64B`
- Cache 共 8 行

数组元素地址公式为：

$$\text{Addr}(a[i][j])=320+(i\times256+j)\times4$$

直接映射下，Cache 行号为：

**图解：数组与Cache映射**

结合图看数组主存块如何按块号映射到各个 Cache 行。

![数组与Cache映射](/data/enhanced-analysis/assets/2010/44/original-analysis-2.svg)

$$\text{行号}=\left(\left\lfloor\frac{\text{主存地址}}{64}\right\rfloor\right)\bmod 8$$

#### `a[0][31]`

其地址为：

$$\text{Addr}(a[0][31])=320+(0\times256+31)\times4=444$$

对应主存块号为：

$$\left\lfloor\frac{444}{64}\right\rfloor=6$$

所以对应的 Cache 行号为：

$$6\bmod 8=6$$

#### `a[1][1]`

其地址为：

$$\text{Addr}(a[1][1])=320+(1\times256+1)\times4=1348$$

对应主存块号为：

$$\left\lfloor\frac{1348}{64}\right\rfloor=21$$

所以对应的 Cache 行号为：

$$21\bmod 8=5$$

### （3）程序 A 和 B 的命中率及执行时间比较

本问在前面块大小和映射关系的基础上继续分析。

数组 `a` 的总大小为：

$$256\times256\times4B=2^{18}B$$

每个主存块大小为 `64B`，每块可存放：

$$\frac{64}{4}=16$$

个 `int` 元素。

因此数组共占用主存块数为：

$$\frac{2^{18}}{64}=2^{12}$$

#### 程序 A

程序 A 按行访问，而数组本身按行优先存放，因此具有良好的空间局部性。

每个主存块中有 16 个 `int` 元素。访问某块中的第 1 个元素时不命中，装入 Cache 后，随后访问该块中的其余 15 个元素都命中。

数组总访问次数为：

$$256\times256=2^{16}$$

总不命中次数为数组占用的主存块数：

$$2^{12}$$

故命中率为：

$$\frac{2^{16}-2^{12}}{2^{16}}=1-\frac{1}{16}=\frac{15}{16}=93.75\%$$

#### 程序 B

程序 B 按列访问。相邻两行同一列元素的地址差为一整行大小：

$$256\times4B=1024B$$

而数据 Cache 的数据区总容量为：

$$8\times64B=512B$$

又因为：

$$1024B=16\times64B$$

所以相邻两次按列访问所对应的主存块号相差 16。由于 Cache 只有 8 行，直接映射时有：

$$16\bmod 8=0$$

这说明不同行同一列附近的数据会反复映射到同一 Cache 行，发生持续冲突。前一次装入的块会被后一次访问替换掉，因此再次用到该块中的其他元素时已经不在 Cache 中。

所以程序 B 的命中率为 **0**。

由此可知，程序 A 的命中率远高于程序 B，因此 **程序 A 的执行时间更短**。

## 易错点

- 题目问的是 Cache 总容量，不只是数据区容量。$8\times64\text{ B}=512\text{ B}$ 只是数据部分，还要计入标记位和有效位。
- 求数组元素地址时，要使用行优先地址公式：
  
  $$320+(i\times256+j)\times4$$

- 程序 B 命中率为 0，不仅因为“按列访问”，还因为数组按行存放、Cache 较小且采用直接映射，跨行访问会不断映射到同一 Cache 行。
