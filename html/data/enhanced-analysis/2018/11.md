## 答案

A。按大根堆的自底向上建堆过程，应从最后一个非叶结点开始依次向前调整，得到的中间状态依次为  
`6,1,7,9,8,4,5 → 6,9,7,1,8,4,5 → 9,6,7,1,8,4,5 → 9,8,7,1,6,4,5`，与 A 完全一致。

## 解析

原序列为 `(6,1,5,9,8,4,7)`。将其看作完全二叉树的顺序存储：

**图解：初始堆结构**

结合顺序存储与完全二叉树位置，观察后续建堆调整的起点。

![初始堆结构](/data/enhanced-analysis/assets/2018/11/original-analysis-1.svg)

- 根结点：`6`
- 第二层：`1, 5`
- 第三层：`9, 8, 4, 7`

建立大根堆采用“自底向上筛选”的方法，即从最后一个非叶结点开始调整。该序列共有 7 个元素，最后一个非叶结点是第 $\left\lfloor \dfrac{7}{2} \right\rfloor = 3$ 个元素，即 `5`。

### 第一步：从结点 `5` 开始堆化
结点 `5` 的两个孩子是 `4` 和 `7`。  
先在两个孩子中选较大的 `7`，再与父结点 `5` 比较：

- `7 > 5`，交换 `5` 与 `7`

得到：

`6,1,7,9,8,4,5`

这一步对应选项 A、D 的第一个状态。

### 第二步：从结点 `1` 开始堆化
结点 `1` 的两个孩子是 `9` 和 `8`。  
先选较大的孩子 `9`，再与 `1` 比较：

- `9 > 1`，交换 `1` 与 `9`

得到：

`6,9,7,1,8,4,5`

到这里，已经可以排除 D，因为 D 的第二步写成了 `7,1,6,9,8,4,5`，这不是按自底向上建堆得到的结果。

### 第三步：从根结点 `6` 开始堆化
根结点 `6` 的两个孩子是 `9` 和 `7`。  
先选较大的孩子 `9`，再与 `6` 比较：

- `9 > 6`，交换 `6` 与 `9`

得到：

`9,6,7,1,8,4,5`

这一步后，`6` 被换到第二层，但调整还没有结束，因为 `6` 所在子树可能仍不满足大根堆性质。

### 第四步：继续向下调整结点 `6`
此时结点 `6` 的孩子是 `1` 和 `8`。  
先选较大的孩子 `8`，再与 `6` 比较：

- `8 > 6`，交换 `6` 与 `8`

得到最终结果：

`9,8,7,1,6,4,5`

此时每个父结点都不小于其孩子，建堆完成。

## 选项分析

A：正确。  
完整反映了自底向上建大根堆的过程，四个状态分别对应：

- 从结点 `5` 堆化：`6,1,7,9,8,4,5`
- 从结点 `1` 堆化：`6,9,7,1,8,4,5`
- 从根结点 `6` 开始下滤：`9,6,7,1,8,4,5`
- 继续调整被下移的 `6`：`9,8,7,1,6,4,5`

B：错误。  
第一步就错了。建堆应先从最后一个非叶结点 `5` 开始调整，不可能一开始就把 `1` 与 `9` 交换成 `6,9,5,1,8,4,7`，因为这跳过了对结点 `5` 的堆化。

C：错误。  
与 B 一样，首步 `6,9,5,1,8,4,7` 就不符合自底向上建堆顺序；后续又直接变成 `9,6,5,1,8,4,7`，仍未先处理结点 `5` 与 `7` 的关系，因此整体过程错误。

D：错误。  
虽然第一步 `6,1,7,9,8,4,5` 是对的，但第二步写成 `7,1,6,9,8,4,5`，相当于直接调整了根结点，破坏了标准建堆顺序。正确做法应先处理结点 `1`，得到 `6,9,7,1,8,4,5`。

## 易错点

- 建堆顺序不是“从前往后”，而是“从最后一个非叶结点向前到根结点”。
- 每次调整时，必须先在左右孩子中选较大的那个，再与父结点比较交换。
- 根结点交换后，调整通常还没结束，必须继续对被下移的结点做向下筛选，直到其子树也满足大根堆性质。
