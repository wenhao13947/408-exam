## 答案
B. II、III

## 解析
DMA（Direct Memory Access，直接存储器访问）适合**外设与内存之间需要高速、大批量传输数据**的场景。其特点是数据传输过程中**不需要 CPU 逐字节参与**，通常只在传输开始和结束时由 CPU 做少量控制，因此更适合高带宽设备。

本题中：
- **键盘**：输入数据量小、速率低，通常采用中断方式，不适合 DMA。
- **网卡**：收发网络数据量通常较大，带宽要求高，适合 DMA。
- **固态硬盘**：读写数据量大，通常也采用 DMA。
- **针式打印机**：速度慢，属于较老式设备，通常用中断 I/O 或程序查询方式，不适合 DMA。

因此，适合采用 DMA 输入输出的设备是 **II 和 III**。

## 选项分析
- **A. I、II**：包含键盘。键盘速率低、数据量小，不适合 DMA。
- **B. II、III**：网卡和固态硬盘都属于高带宽、大批量数据传输设备，正确。
- **C. II、IV**：包含针式打印机。针式打印机速度慢，通常不用 DMA。
- **D. III、IV**：包含针式打印机，不符合 DMA 的适用条件。

## 易错点
- 不是所有外设都适合 DMA，判断关键看**数据量和传输速率**。
- **低速、小批量**设备常用中断方式或程序查询；**高速、大批量**设备才更常用 DMA。
