## 答案

**B**。

理由：按二叉排序树（BST）的插入规则，序列 `4, 5, 1, 2, 3` 在插入 `1` 时，`1 < 4`，必须直接成为 `4` 的左孩子，因此不可能生成题干所给的那棵二叉排序树。

## 解析

判断这类题的关键，不是看关键字集合是否相同，而是看**按给定顺序逐个插入**后，树的结构是否与题干完全一致。

二叉排序树的基本规则是：

- 若待插入关键字小于当前结点，则进入左子树；
- 若大于当前结点，则进入右子树；
- 直到遇到空位置再插入。

由题干图形及各选项的可行性可知，目标树结构应为：

- 根结点是 `4`
- `4` 的左孩子是 `2`
- `4` 的右孩子是 `5`
- `2` 的左孩子是 `1`
- `2` 的右孩子是 `3`

也就是如下结构：

$$
\begin{array}{c}
4 \
/ \ \backslash \
2 \qquad 5 \
/ \ \backslash \
1 \qquad 3
\end{array}
$$

下面检查各序列是否能按插入过程得到该结构。重点看 B。

对于 **B. `4, 5, 1, 2, 3`**：

1. 插入 `4`：`4` 成为根结点。
2. 插入 `5`：`5 > 4`，所以 `5` 成为 `4` 的右孩子。
3. 插入 `1`：`1 < 4`，因此 `1` 必须直接插入到 `4` 的左侧空位置，成为 `4` 的左孩子。

此时树已经变成：

- 根 `4`
- 左孩子 `1`
- 右孩子 `5`

这一步就已经与题干目标树不一致了，因为题干要求 `4` 的左孩子应是 `2`，而不是 `1`。后续再插入 `2`、`3` 也无法把已经作为 `4` 左孩子的 `1` 改成 `2`，所以 **B 不可能生成题干所示二叉排序树**。

## 选项分析

**A. `4, 5, 2, 1, 3`**

插入过程：

1. `4` 为根；
2. `5 > 4`，放到 `4` 的右边；
3. `2 < 4`，放到 `4` 的左边；
4. `1 < 4`，再比较 `2`，有 `1 < 2`，放到 `2` 的左边；
5. `3 < 4`，再比较 `2`，有 `3 > 2`，放到 `2` 的右边。

最终得到的正是题干所示结构，因此 **A 可以生成**。

**B. `4, 5, 1, 2, 3`**

插入到第三个关键字 `1` 时，`1 < 4`，必须成为 `4` 的左孩子，导致树结构立即偏离题干，因此 **B 不可以生成**。

**C. `4, 2, 5, 3, 1`**

插入过程：

1. `4` 为根；
2. `2 < 4`，作为 `4` 的左孩子；
3. `5 > 4`，作为 `4` 的右孩子；
4. `3 < 4`，再比较 `2`，有 `3 > 2`，作为 `2` 的右孩子；
5. `1 < 4`，再比较 `2`，有 `1 < 2`，作为 `2` 的左孩子。

最终结构仍为题干所示，因此 **C 可以生成**。

**D. `4, 2, 1, 3, 5`**

插入过程：

1. `4` 为根；
2. `2 < 4`，作为 `4` 的左孩子；
3. `1 < 4`，再比较 `2`，有 `1 < 2`，作为 `2` 的左孩子；
4. `3 < 4`，再比较 `2`，有 `3 > 2`，作为 `2` 的右孩子；
5. `5 > 4`，作为 `4` 的右孩子。

最终也能得到题干所示结构，因此 **D 可以生成**。

## 易错点

- 不要只看最终包含的关键字是否相同，**插入顺序会决定树形**。
- 判断“不能生成”时，通常只要在某一步发现某个结点**必然落在错误位置**，就可以直接排除该选项。
- 本题最关键的检查点是：题干目标树中，`4` 的左孩子必须是 `2`。因此凡是比 `4` 小且先于 `2` 插入的结点，都可能破坏该结构。B 中的 `1` 正是这种情况。
