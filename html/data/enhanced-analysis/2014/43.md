## 答案

### （1）
R1 的路由表应为 3 条，且将 `192.1.6.0/24` 与 `192.1.7.0/24` 聚合为 `192.1.6.0/23`：

| 目的网络 | 下一跳 | 接口 |
| --- | --- | --- |
| 192.1.1.0/24 | - | E0 |
| 192.1.6.0/23 | 10.1.1.2 | L0 |
| 192.1.5.0/24 | 10.1.1.10 | L1 |

### （2）
R1 通过 `L0` 接口转发该 IP 分组；主机 `192.1.7.211` 收到该分组时，`TTL=61`。

### （3）
R1 的 LSI 需要增加一条默认路由信息：`Prefix = 0.0.0.0/0`，`Metric = 10`。

## 解析

### （1）
题目要求两点：一是给出 R1 到题 42 所示各 `192.1.x.x` 子网的路由，二是“路由项尽可能少”。因此本问的关键不是把所有子网机械逐条列出，而是在不改变可达性的前提下做聚合。

根据已给出的标准结论，R1 的路由关系如下：

1. `192.1.1.0/24` 是 R1 的直连网络，因此：
   - 目的网络为 `192.1.1.0/24`
   - 无需下一跳
   - 从接口 `E0` 转发

2. 到 `192.1.5.0/24` 的分组，应交给下一跳 `10.1.1.10`，并从接口 `L1` 发出，因此这一条单独保留为：
   - `192.1.5.0/24 -> 10.1.1.10 -> L1`

3. `192.1.6.0/24` 与 `192.1.7.0/24` 的下一跳和出接口相同，且题目要求路由项尽可能少，所以应进行地址聚合。

先看这两个网络：

- `192.1.6.0/24`
- `192.1.7.0/24`

它们前 23 位相同，因此可聚合为：

$$192.1.6.0/23$$

聚合后，这一条路由可同时覆盖 `192.1.6.0/24` 和 `192.1.7.0/24`，并保持：
- 下一跳为 `10.1.1.2`
- 接口为 `L0`

所以，满足“路由项尽可能少”的最简路由表就是 3 条，而不是分别写成 4 条。

### （2）
本问直接承接第（1）问的路由表结果。

目的主机地址为 `192.1.7.211`，它属于网络：

$$192.1.7.0/24$$

而第（1）问中，`192.1.7.0/24` 已被聚合进路由项 `192.1.6.0/23`。因此，R1 查表后匹配到：

- 目的网络：`192.1.6.0/23`
- 下一跳：`10.1.1.2`
- 出接口：`L0`

所以，R1 通过 `L0` 接口转发该 IP 分组。

再看 TTL。题目给定初始 `TTL=64`。IP 分组每经过 1 个路由器转发，TTL 减 1。根据标准结论，该分组从源主机到目的主机共经过 3 个路由器：

- `R1`
- `R2`
- `R4`

因此主机 `192.1.7.211` 收到该分组时：

$$TTL = 64 - 3 = 61$$

所以收到时的 TTL 为 `61`。

### （3）
本问与前两问的路由计算过程无直接联动，单独依据题意作答即可。

题目说 R1 新增一条 `Metric=10` 的链路连接 Internet。对 OSPF 而言，这意味着 R1 需要在其链路状态信息中增加一条“到外部默认方向”的可达信息。默认路由的前缀写作：

$$0.0.0.0/0$$

因此，R1 的 LSI 需要增加的信息是：

- `Prefix = 0.0.0.0/0`
- `Metric = 10`

这里的 `0.0.0.0/0` 表示默认路由，即“其余所有未知目的网络都可按该方向转发”。

## 易错点

1. 第（1）问不能只求“能到”，还必须满足“路由项尽可能少”。  
   因此 `192.1.6.0/24` 与 `192.1.7.0/24` 应聚合为 `192.1.6.0/23`，否则路由项偏多。

2. 第（2）问查的是聚合后的路由。  
   `192.1.7.211` 虽不等于 `192.1.6.x`，但它仍落在 `192.1.6.0/23` 覆盖范围内，所以应从 `L0` 转发。

3. TTL 的减少发生在路由器转发时，不是在主机发送或接收时减少。  
   本题经过 3 个路由器，所以是 `64-3=61`。
