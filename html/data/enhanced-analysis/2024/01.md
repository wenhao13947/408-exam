## 答案
D。该四句代码的作用是将结点 `Q` 从原位置摘下后，插入到头结点 `H` 之后。

## 解析
题干中 `P` 指向链表 `L` 中非首非尾结点，按代码顺序分析即可：

```c
Q = P->next;
P->next = Q->next;
Q->next = H->next;
H->next = Q;
```

1. `Q = P->next`  
   令 `Q` 指向 `P` 的后继结点。

2. `P->next = Q->next`  
   让 `P` 直接跳过 `Q`，指向 `Q` 的后继结点。  
   这一步等价于把 `Q` 从原链表位置中删除。

3. `Q->next = H->next`  
   让 `Q` 的后继指向原来头结点后面的第一个有效结点。

4. `H->next = Q`  
   把 `Q` 接到头结点 `H` 后面。

因此，执行后链表效果是：`Q` 被移到 `H` 后，也就是插入到链表表头位置。题目所述功能与这一结果一致，故选 D。
