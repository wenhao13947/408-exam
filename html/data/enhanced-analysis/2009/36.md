## 答案
**A. 目的物理地址**

以太网交换机属于数据链路层设备，转发决策依据的是帧中的**目的 MAC 地址**，也就是**目的物理地址**。

## 解析
以太网交换机本质上是**多端口网桥**，工作在**数据链路层**。链路层处理的是**MAC 地址**，不是 IP 地址，所以题目中的 PDU 地址应从物理地址角度判断。

交换机转发时要做的是“把帧发往哪里”，因此判断依据是**目的地址**，不是源地址。交换机收到帧后会进行**自学习**，把**源物理地址**和进入端口记录到转发表中；但真正决定转发方向的，是帧里的**目的物理地址**。

从分层封装看，PDU 是协议数据单元，题目所说的 PDU 地址，本质上就是该层数据单元中用于转发判断的地址。在以太网场景下，这个地址就是**目的 MAC 地址**。

## 选项分析
- **A. 目的物理地址**：正确。交换机依据目的 MAC 地址进行转发决策。
- **B. 目的 IP 地址**：错误。IP 地址属于网络层，不是以太网交换机转发所依据的地址。
- **C. 源物理地址**：错误。源 MAC 地址主要用于交换机自学习和建立转发表，不用于决定转发方向。
- **D. 源 IP 地址**：错误。IP 地址不属于交换机此处的转发依据，且源地址本身也不是转发决策核心。

## 易错点
- 不要把“物理地址”误认为物理层地址；这里指的是**数据链路层的 MAC 地址**。
- 交换机学习的是**源地址**，转发判断看的是**目的地址**。
