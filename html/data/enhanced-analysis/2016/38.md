## 答案

**D。**  
R2 作为 `NAT` 路由器，在将 H3 发往公网 `Web` 服务器 S 的 `HTTP` 请求转发出去时，源 IP 应改写为 R2 的公网地址，目的 IP 仍为服务器的公网地址 `130.18.10.1`，因此应为 `201.1.3.10, 130.18.10.1`。

## 解析

题干关键信息有两点：

- H3 位于 `NAT` 路由器 R2 所连接的私有网络中；
- 连接相关路由器的点对点链路使用 `201.1.3.x/30` 地址。

先看目的 IP。  
H3 要访问的是公网中的 `Web` 服务器 S，因此封装 `HTTP` 请求报文的 IP 分组，其**目的 IP 地址**就是服务器 S 的公网地址 `130.18.10.1`。这一点不会因为经过 R2 转发而改变。

再看源 IP。  
H3 处于私有网络中，其私有地址不能直接作为发送到公网的源 IP 使用。经过 R2 这一 `NAT` 路由器转发时，源地址会被改写为 **R2 对外侧接口的公网地址**。所以本题实质是在问：R2 的公网地址是哪一个。

题干给出点对点链路地址块为：

$$201.1.3.x/30$$

`/30` 表示前 30 位是网络号，后 2 位是主机号，对应子网掩码：

$$255.255.255.252$$

因此一个 `/30` 子网共有 4 个地址，其中：

- 主机号为 `00`：网络地址，不能分配给主机
- 主机号为 `11`：广播地址，不能分配给主机
- 只有主机号为 `01` 和 `10` 的地址可作为接口地址

已知图中有一个接口地址是 `201.1.3.9`。将末尾字节写成二进制：

$$9 = 00001001_2$$

由于 `/30` 只看最后 2 位，`201.1.3.8/30` 这一子网的 4 个地址分别是：

- `201.1.3.8`，主机号 `00`，网络地址
- `201.1.3.9`，主机号 `01`，可用
- `201.1.3.10`，主机号 `10`，可用
- `201.1.3.11`，主机号 `11`，广播地址

既然 `201.1.3.9` 已被占用，则另一可用地址只能是 `201.1.3.10`。因此，R2 对外转发该请求时，源 IP 应为 `201.1.3.10`。

所以，R2 转发出去的 IP 分组地址对为：

- 源 IP：`201.1.3.10`
- 目的 IP：`130.18.10.1`

答案选 **D**。

## 选项分析

A. `192.168.3.251，130.18.10.1`  
错误。`192.168.3.251` 属于私有地址。H3 从内网访问公网服务器时，经过 R2 的 `NAT` 转换后，转发到公网的分组源地址不应仍是内网私有地址。

B. `192.168.3.251，201.1.3.9`  
错误。有两处问题：
- 源地址仍写成私有地址，不符合 `NAT` 转换后的结果；
- 目的地址应是公网 `Web` 服务器 S 的地址 `130.18.10.1`，不应写成链路上的路由器接口地址。

C. `201.1.3.8，130.18.10.1`  
错误。目的地址正确，但 `201.1.3.8` 在 `/30` 子网中主机号为 `00`，是网络地址，不能作为主机或路由器接口地址使用。

D. `201.1.3.10，130.18.10.1`  
正确。`201.1.3.10` 是该 `/30` 子网中另一可用主机地址，可作为 R2 的公网接口地址；目的地址 `130.18.10.1` 也是目标 `Web` 服务器地址。

## 易错点

- 不要把“经过路由器转发，IP 地址通常不变”和“经过 `NAT` 转发，源地址会被改写”混为一谈。普通路由转发通常不改源/目的 IP，但 `NAT` 是例外。
- `/30` 子网中只有 2 个可用主机地址，判断选项时要先排除网络地址和广播地址。
- 题目问的是 **R2 转发出去后的 IP 分组地址**，不是 H3 初始发送时的地址，因此不能直接选 H3 的私有 IP。
