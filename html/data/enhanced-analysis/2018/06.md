## 答案

**C**。因为二叉排序树进行中序遍历后得到的是递增序列，由题图对应的中序遍历结果可得：$x_1 < x_3 < x_5 < x_4 < x_2$，因此选项中只有 $x_3 < x_5 < x_4$ 正确。

## 解析

本题考查二叉排序树（Binary Search Tree, BST）的性质。

二叉排序树满足以下规则：

- 左子树上所有结点的关键字都小于根结点
- 右子树上所有结点的关键字都大于根结点
- 左右子树本身也分别是二叉排序树

因此，二叉排序树的一个直接结论是：

$$
\text{中序遍历序列}=\text{递增序列}
$$

所以本题不必逐个硬推每个结点与其他所有结点的关系，只需要对题图所示二叉排序树做一次中序遍历即可。

根据题图对应的遍历顺序，访问结点依次为：

$$
x_1,\ x_3,\ x_5,\ x_4,\ x_2
$$

于是可直接得到它们的大小关系：

$$
x_1 < x_3 < x_5 < x_4 < x_2
$$

题目要求判断哪个选项给出的大小关系成立，只需将各选项与上式对照即可。由该递增序列可知：

$$
x_3 < x_5 < x_4
$$

成立，因此正确答案为 **C**。

## 选项分析

**A. $x_1 < x_2 < x_3$**  
错误。由中序遍历结果可知 $x_2$ 是序列中最后一个，反而有 $x_3 < x_2$，因此该选项不成立。

**B. $x_1 < x_4 < x_5$**  
错误。由递增关系可知应为 $x_5 < x_4$，该选项把 $x_4$ 与 $x_5$ 的大小关系写反了。

**C. $x_3 < x_5 < x_4$**  
正确。这与中序遍历得到的递增序列完全一致。

**D. $x_4 < x_3 < x_5$**  
错误。由递增关系可知 $x_3 < x_5 < x_4$，该选项把三者顺序整体写错了。

## 易错点

- 不要把“二叉排序树”只理解为“左孩子小、右孩子大”。准确说法是：**左子树所有结点都小于根，右子树所有结点都大于根**。
- 遇到这类题，最快方法通常不是逐对比较，而是先写出**中序遍历序列**，因为它天然就是从小到大的顺序。
- 题目中的首项应记为 `$x_1$`；结合中序遍历序列，正确结论为 **C**。
