## 答案

**A．仅 I 和 II**

理由：I 说明了 RAM 与 ROM 的易失性差异，II 说明了二者的访问方式；III 错在 ROM 不能作 Cache，IV 错在并非 RAM 和 ROM 都需要刷新，只有 DRAM 需要刷新。

## 解析

本题考查 4 个基础概念：**易失性 / 非易失性、随机存取、Cache 的实现材料、刷新机制**。判断时要把“存储器类型”和“访问方式”分开看。

先看 I：

RAM 断电后数据会丢失，因此属于**易失性存储器**；ROM 断电后原有内容通常不会丢失，因此属于**非易失性存储器**。这一说法正确。

再看 II：

RAM 和 ROM 虽然名称不同，功能也不同，但二者在**访问方式**上都属于**随机存取**。  
这里容易混淆的是：“随机存取”说的是**按地址访问时，访问任一存储单元所需时间与其位置无关**，并不等于“名字里带有 Random Access 的才算随机存取”。因此 ROM 虽然是 Read Only Memory，仍然可以按地址随机读取，II 正确。

再看 III：

“RAM 和 ROM 都可用作 Cache”错误。Cache 对速度要求极高，通常采用 **SRAM** 实现。  
ROM 只能读，不能承担 Cache 在运行中频繁更新数据的任务；而 RAM 这一大类中，也不是所有 RAM 都能直接作为 Cache 材料，典型 Cache 实现依赖的是高速 **SRAM**，而不是笼统地说“RAM 和 ROM 都可以”。因此 III 错误。

最后看 IV：

“RAM 和 ROM 都需要刷新”错误。  
需要刷新的典型是 **DRAM**，因为它用电容存储信息，电荷会逐渐泄漏，所以必须周期性补充电荷，即“刷新”。ROM 不需要刷新；RAM 中的 **SRAM** 也不需要像 DRAM 那样刷新。因此 IV 错误。

综上，正确的是 I、II，答案为 **A**。

## 选项分析

**I．RAM 是易失性存储器，ROM 是非易失性存储器**  
正确。  
判断依据是断电后信息是否保留：RAM 断电丢失数据，ROM 断电后内容通常仍保存。

**II．RAM 和 ROM 都采用随机存取方式进行信息访问**  
正确。  
随机存取强调的是“可按地址直接访问任意单元”，RAM 和 ROM 都符合这一点。

**III．RAM 和 ROM 都可用作 Cache**  
错误。  
Cache 通常由高速 SRAM 构成。ROM 不能在运行中反复改写，不适合作 Cache；因此“RAM 和 ROM 都可以”显然不成立。

**IV．RAM 和 ROM 都需要进行刷新**  
错误。  
刷新是 DRAM 的特性要求，不是所有 RAM 的共同要求，更不是 ROM 的要求。ROM 不需要刷新。

## 易错点

**随机存取**不等于“只能是 RAM”。  
ROM 也是随机存取存储器，只是它的主要特征是“只读”。

**RAM 需要刷新**这句话本身也不严谨。  
准确说，应是**DRAM 需要刷新，SRAM 不需要刷新**。

**Cache 使用的是 SRAM，不是 ROM。**  
判断 Cache 相关选项时，要抓住两个关键词：**高速**、**可改写**。
