## 答案
B. 仅Ⅱ和Ⅲ。CPU 能直接理解并执行的是微指令和机器指令。

## 解析
题干问的是“CPU 能理解并直接执行”的对象。判断标准很简单：看它是不是 CPU 直接执行层面的指令。

- **伪指令**：用于辅助汇编和组织程序，不是 CPU 直接执行的指令。
- **汇编指令**：面向程序员书写，必须先经过汇编器转换成机器指令，CPU 不能直接执行。
- **微指令**：属于 CPU 内部控制器，尤其是微程序控制器中的控制层指令，CPU 可以理解并据此发出控制信号。
- **机器指令**：CPU 直接执行的二进制指令。

因此，能被 CPU 理解并直接执行的是 **Ⅱ 微指令** 和 **Ⅲ 机器指令**，对应 **B**。

## 选项分析
- **A. 仅Ⅰ和Ⅳ**：错。伪指令和汇编指令都不能被 CPU 直接执行。
- **B. 仅Ⅱ和Ⅲ**：对。微指令和机器指令都属于 CPU 可直接处理的层次。
- **C. 仅Ⅲ和Ⅳ**：错。Ⅳ 汇编指令必须先转成机器指令。
- **D. 仅Ⅰ、Ⅲ和Ⅳ**：错。Ⅰ 伪指令和Ⅳ 汇编指令都不是 CPU 直接执行的内容。

## 易错点
- 容易把“汇编语言方便直接操作硬件”误认为“CPU 能直接执行汇编指令”，这是不对的。
- “微指令”不是“机器指令”的同义词，但它确实属于 CPU 控制器内部可直接使用的指令层。
