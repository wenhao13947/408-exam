## 答案
选 **B. CSMA**。其余选项都属于信道划分类方法，通常不会发生冲突。

## 解析
题干问的是“**可能发生冲突**”的介质访问控制方法。判断关键在于区分两类方法：

- **信道划分协议**：把信道资源静态分给各站点使用，典型包括 **TDMA、FDMA、CDMA**，一般不会出现站点争用同一信道而导致的冲突。
- **随机访问协议**：站点按竞争方式使用信道，存在多个站点同时发送的可能，因此**可能发生冲突**。

**CSMA**（Carrier Sense Multiple Access，载波侦听多路访问）属于随机访问协议。其工作方式是发送前先侦听信道，若空闲则发送；但多个站点可能同时检测到空闲并同时发送，所以**仍可能发生冲突**。

## 选项分析
- **A. CDMA**：属于信道划分方法，通常不发生冲突。
- **B. CSMA**：随机访问方法，可能发生冲突，故为正确答案。
- **C. TDMA**：时分复用，属于信道划分方法，不发生冲突。
- **D. FDMA**：频分复用，属于信道划分方法，不发生冲突。

## 易错点
- 不要把“先侦听信道”误认为“绝不会冲突”；**CSMA 只是降低冲突概率，不能消除冲突**。
- **TDMA / FDMA / CDMA** 常被归为信道划分类，考试中一般与“不会发生冲突”对应。
