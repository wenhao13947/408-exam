## 答案

(1) 基本设计思想：使用长度为 $n$ 的辅助标记数组，记录原数组中 $1\sim n$ 是否出现。先扫描原数组，对满足 $1 \le A[i] \le n$ 的元素做标记；再扫描标记数组，返回第一个未被标记的位置对应的正整数。若 $1\sim n$ 全部出现，则返回 $n+1$。

(2) 算法可用 C 语言描述如下。

## 解析

### 解法一：暴力法

从正整数 $1$ 开始逐个尝试，每尝试一个数都完整扫描数组判断它是否出现；第一个未出现的正整数就是答案。最多检查到 $n+1$，时间复杂度为 $O(n^2)$，空间复杂度为 $O(1)$。

### 解法二：优化解法

利用答案只可能位于 $1\sim n+1$，用标记数组一次记录 $1\sim n$ 的出现情况，再扫描第一个未标记位置，时间复杂度为 $O(n)$，空间复杂度为 $O(n)$。

> **考场建议：** 先写逐个尝试的暴力法保证正确，再从“大量重复扫描”想到一次标记；若题目继续要求 $O(1)$ 空间，还可考虑在原数组上原地标记。

### (1) 基本设计思想

设数组长度为 $n$。未出现的最小正整数只可能落在 $1\sim n+1$ 中，理由是：

- 如果 $1\sim n$ 中有某个数没出现，那么答案就在 $1\sim n$ 中；
- 如果 $1\sim n$ 全都出现了，那么答案只能是 $n+1$。

因此，没有必要关心所有整数，只需关心 $1\sim n$ 是否出现。

做法是开一个长度为 $n$ 的辅助数组 `vis`：

- `vis[0]` 表示正整数 `1` 是否出现；
- `vis[1]` 表示正整数 `2` 是否出现；
- ...
- `vis[n-1]` 表示正整数 `n` 是否出现。

扫描原数组时：

- 若 `A[i]` 满足 $1 \le A[i] \le n$，则令 `vis[A[i]-1] = 1`；
- 若 `A[i] \le 0` 或 `A[i] > n`，则忽略，因为它不会影响 $1\sim n$ 中哪些数缺失。

之后从前往后扫描 `vis`，第一个值为 `0` 的位置 `i`，对应的最小未出现正整数就是 `i+1`。若所有位置都为 `1`，则返回 `n+1`。

### (2) 算法描述

处理数组元素时必须限制在 `1 <= num <= n`，否则 `num > n` 会导致访问越界。

下面给出与题意一致、且可直接复核的实现：

```c
int findMissMin(int a[], int n) {
    int vis[n];
    int i;

    /* 初始化标记数组，0表示未出现 */
    for (i = 0; i < n; i++) {
        vis[i] = 0;
    }

    /* 标记 1~n 中出现过的数 */
    for (i = 0; i < n; i++) {
        int num = a[i];
        if (num > 0 && num <= n) {
            vis[num - 1] = 1;
        }
    }

    /* 找第一个未出现的正整数 */
    for (i = 0; i < n; i++) {
        if (vis[i] == 0) {
            return i + 1;
        }
    }

    /* 若 1~n 全出现，则答案为 n+1 */
    return n + 1;
}
```

### (3) 时间复杂度和空间复杂度

该算法共有三次线性操作：

| 操作 | 复杂度 |
|---|---|
| 初始化辅助数组 `vis` | $O(n)$ |
| 扫描原数组并标记 | $O(n)$ |
| 扫描 `vis` 找答案 | $O(n)$ |

因此总时间复杂度为：

$$
O(n) + O(n) + O(n) = O(n)
$$

额外使用了一个长度为 $n$ 的辅助数组 `vis`，所以空间复杂度为：

$$
O(n)
$$

结论：

- 时间复杂度：$O(n)$
- 空间复杂度：$O(n)$
