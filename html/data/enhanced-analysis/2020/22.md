## 答案

**C**。

理由：周期挪用（Cycle Stealing）DMA 每次只占用一个总线周期完成一次字传送，DMA 传送间隙 CPU 仍可访问主存，因此“在整个数据块传送过程中，CPU 不可以访问主存储器”错误。

## 解析

题干给出的是**周期挪用 DMA**方式，并明确了两个关键条件：

- 每次 DMA 传送的数据块总大小为 **512 B**
- I/O 接口中有一个 **32 位**数据缓冲寄存器

对“数据输入过程”的理解应是：外设先把数据送入 I/O 接口的数据缓冲寄存器；当缓冲寄存器装满一个字后，DMA 控制器申请总线，把这一个字写入主存。由于缓冲寄存器是 32 位，因此每次实际搬运的数据量是：

$$
32\text{ 位} = 4\text{ B}
$$

整个 512 B 数据块需要的 DMA 传送次数为：

$$
512 \div 4 = 128
$$

这 128 次传送不是连续独占总线完成的，而是**每次只挪用一个总线周期**。也就是说：

- 当 DMA 要传一个 32 位字时，它申请并占用一次总线；
- 该次传送结束后立即释放总线；
- 在外设继续向缓冲寄存器写入下一批数据的期间，CPU 可以重新使用总线访问主存。

因此，CPU 只是**在某些被 DMA 挪用的总线周期中暂时不能访问主存**，并不是在整个 512 B 数据块传送期间都不能访问主存。C 把“局部暂停”误说成“全程禁止”，所以错误。

另外，DMA 传送完成整个数据块后，通常会向 CPU 发出一次“DMA 结束中断”，通知后续处理，这也是 DMA 方式的标准行为。

## 选项分析

**A. 每准备好 32 位数据，DMA 控制器就发出一次总线请求**

正确。

题干已给出 I/O 接口中有 **32 位数据缓冲寄存器**。对输入过程而言，外设先把数据送入该寄存器；寄存器装满一个 32 位字后，DMA 才有条件发起一次总线请求，将该字写入主存。周期挪用方式本来就是“准备好一个字，申请一次总线，传一次”。

**B. 相对于 CPU，DMA 控制器的总线使用权的优先级更高**

正确。

周期挪用 DMA 的核心就是 DMA 在需要传送时能够**挪用**CPU 原本可能使用的总线周期。若 DMA 不能在需要时优先获得总线，就无法保证及时把缓冲寄存器中的数据写入主存，可能导致高速外设数据丢失。因此在总线竞争时，DMA 的优先级通常高于 CPU。

**C. 在整个数据块的传送过程中，CPU 不可以访问主存储器**

错误。

这是本题答案。周期挪用 DMA 并不长期霸占总线，而是**传一个字，占一个总线周期**。只在这一个周期内 CPU 不能访问主存；其余周期只要 DMA 未占用总线，CPU 仍可访问主存。因此“整个数据块传送过程中都不可以访问”明显过度扩大了影响范围。

**D. 数据块传送结束时，会产生“DMA 传送结束”的中断请求**

正确。

DMA 控制器完成整个数据块传送后，通常会向 CPU 发送一次中断请求，通知本次 DMA 操作结束，以便 CPU 进行后处理。这是 DMA 方式的标准收尾机制。

## 易错点

- **把“周期挪用”误当成“DMA 独占总线”**  
  独占总线的是成组传送或突发传送思路；周期挪用的特点恰恰是“每次只占用一个总线周期”。

- **混淆“一个数据块”和“一个字”的传送粒度**  
  本题 512 B 是整块大小，但总线申请是按 **32 位（4 B）一字一次**进行，不是 512 B 一次搬完。

- **判断 CPU 是否能访问主存时，看的是“DMA 是否持续占线”**  
  周期挪用下，结论应是：**CPU 会被间歇性阻塞，而非全程阻塞**。
