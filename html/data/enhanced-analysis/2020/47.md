## 答案

### （1）
应在 `R2` 上配置 Web 服务器的 `NAT` 映射，使外部主机访问 `203.10.2.2:80` 时，能够转发到内网 Web 服务器 `192.168.1.2:80`。

可写成 `NAT` 表项：

| 外网 IP 地址 | 外网端口号 | 内网 IP 地址 | 内网端口号 |
|---|---:|---|---:|
| 203.10.2.2 | 80 | 192.168.1.2 | 80 |

### （2）
逐项计算结果如下：

- `H2` 发送 `P` 时：源 IP 地址为 `192.168.1.2`，目的 IP 地址为 `203.10.2.2`
- 经过 `R3` 转发后：源 IP 地址为 `203.10.2.6`，目的 IP 地址为 `203.10.2.2`
- 经过 `R2` 转发后：源 IP 地址为 `203.10.2.6`，目的 IP 地址为 `192.168.1.2`

## 解析

### （1）
题干中两个局域网都使用了 `192.168.1.x` 地址段。读图可知，右侧局域网中的 Web 服务器地址是 `192.168.1.2`，而外部访问它时不能直接把这个私网地址作为公网访问目标，因此需要借助 `NAT` 把公网侧地址映射到该服务器。

这里应在 `R2` 上做静态 `NAT` 映射。因为题目说明“访问 Web 服务器（使用默认端口号）”，Web 的默认端口号是 `80`，所以应把：

$$203.10.2.2:80 \rightarrow 192.168.1.2:80$$

也就是说，外部主机访问 `203.10.2.2` 的 `80` 端口时，`R2` 再把该请求转发给内网 Web 服务器 `192.168.1.2` 的 `80` 端口。

结合图中的 `NAT` 转换表结构，填出这一条表项即可。读图时注意，题目要求的是“使 H2 和 H3 能访问 Web 服务器”，因此这里只需要给出 Web 服务对应的映射，不需要再写其他主机的表项。

### （2）
这一问承接第（1）问的配置。由于 Web 服务已经通过 `R2` 的公网地址 `203.10.2.2` 对外发布，所以 `H2` 发起 HTTP 请求时，IP 数据报 `P` 在不同位置的源、目的 IP 变化如下。

先看 `H2` 发出时。`H2` 访问的不是服务器私网地址，而是对外发布的公网地址，因此目的 IP 应是 `203.10.2.2`。根据地址转换过程，`H2` 发出时：

$$\text{源 IP}=192.168.1.2,\quad \text{目的 IP}=203.10.2.2$$

接着，数据报经过 `R3` 转发。在这一步发生了源地址改写，源 IP 改为 `R3` 的外网地址 `203.10.2.6`，目的地址仍然是 `R2` 的公网地址 `203.10.2.2`，所以：

$$\text{源 IP}=203.10.2.6,\quad \text{目的 IP}=203.10.2.2$$

最后，数据报经过 `R2` 转发。由于 `R2` 上已经配置了第（1）问中的 `NAT` 映射，因此它会把目的地址从公网地址 `203.10.2.2` 改写为内网 Web 服务器地址 `192.168.1.2`，源地址保持为 `203.10.2.6`，所以：

$$\text{源 IP}=203.10.2.6,\quad \text{目的 IP}=192.168.1.2$$

## 易错点

1. 第（1）问不是普通路由配置问题，关键是配置 `NAT` 映射，把 `R2` 的公网地址与内网 Web 服务器绑定起来。
2. “使用默认端口号”必须落实到 `80` 端口，不能只写 IP 地址映射而漏掉端口号。
3. 第（2）问的 `H2` 地址应以题目采用的评分口径为准，作答时使用 `192.168.1.2`。
