## 答案

A。将高级语言源程序转换为可执行目标文件的标准过程依次是：**预处理 → 编译 → 汇编 → 链接**。

## 解析

本题考查高级语言程序从源文件到可执行文件的生成过程，关键在于分清四个阶段的**先后顺序**。

标准流程如下：

1. **预处理（Preprocessing）**  
   处理源程序中的预处理指令，如 `#include`、`#define`、条件编译等，得到展开后的源程序。

2. **编译（Compilation）**  
   将预处理后的高级语言程序翻译为汇编语言程序。  
   也就是说，这一步的输出通常还不是机器可直接执行的目标文件，而是更低一级的汇编代码。

3. **汇编（Assembly）**  
   将汇编语言程序进一步翻译为机器指令，生成目标文件（`object file`）。

4. **链接（Linking）**  
   将目标文件与所需库文件等连接起来，解析外部符号引用，最终形成**可执行目标文件**。

因此，题干所问“将高级语言源程序转换为可执行目标文件的主要过程”就是上述四步，其顺序固定为：

**预处理 → 编译 → 汇编 → 链接**

这与选项 A 完全一致，因此答案为 A。

## 选项分析

A. **预处理 → 编译 → 汇编 → 链接**  
正确。这正是从源程序生成可执行目标文件的标准流程。

B. **预处理 → 汇编 → 编译 → 链接**  
错误。汇编必须发生在编译之后，因为只有先把高级语言翻译成汇编语言，才能再进行汇编。

C. **预处理 → 编译 → 链接 → 汇编**  
错误。链接在汇编之后进行，因为链接处理的对象是一个或多个目标文件，而目标文件需要先经过汇编生成。

D. **预处理 → 汇编 → 链接 → 编译**  
错误。该顺序整体颠倒了编译、汇编、链接之间的依赖关系，不符合程序生成过程。

## 易错点

- **混淆“编译”和“汇编”**：  
  编译是把**高级语言**变成**汇编语言**；汇编是把**汇编语言**变成**目标文件**。

- **误以为链接早于汇编**：  
  链接依赖目标文件，而目标文件是汇编之后才产生的，所以链接不可能先于汇编。

- **记忆方法**：  
  可以按“文本展开 → 高级变低级 → 变成目标文件 → 合成为可执行文件”的逻辑记忆，即：  
  **预处理 → 编译 → 汇编 → 链接**。
