## 答案

D。  
删除带头结点的非空单循环链表的第一个元素，基本操作应为先保存待删结点、再让头结点越过该结点，最后释放空间；若原链表只有一个数据结点，还必须把尾指针 `p` 改回指向头结点 `h`。

## 解析

题干给出的是**带头结点的非空单循环链表**，要删除的“第一个元素”是指 `h` 后面的第一个数据结点，不是头结点 `h` 本身。

删除该结点的标准过程是：

1. 用临时指针保存待删结点：`q = h->next`
2. 修改链接关系，跳过待删结点：`h->next = q->next`
3. 释放待删结点空间：`free(q)`

仅有这三步还不够，因为本题是**单循环链表**，并且 `p` 是**尾指针**。  
当链表中原本只有一个数据结点时，`h->next` 指向该唯一结点，同时尾指针 `p` 也指向它，因此此时有：

$$
p == q
$$

删除这个唯一结点后，链表中只剩头结点 `h`，为了仍满足单循环链表结构，应使尾指针也回到头结点，即：

`if (p == q) p = h;`

因此完整正确的语句序列为：

`q = h->next; h->next = q->next; if (p == q) p = h; free(q);`

这正是 D。

## 选项分析

A. `h->next = h->next->next; q = h->next; free(q);`  
错误。先改 `h->next`，再令 `q = h->next`，此时 `q` 保存的已经是**原首元结点的后继结点**，不是待删除结点。结果释放了错误的结点，原本要删除的第一个元素反而没有被正确释放。

B. `q = h->next; h->next = h->next->next; free(q);`  
错误。前三步对一般情况是成立的，但没有处理“链表只有一个数据结点”的特殊情况。若原来唯一的数据结点被删掉，尾指针 `p` 仍指向已释放的结点，循环链表结构被破坏。

C. `q = h->next; h->next = q->next; if (p != q) p = h; free(q);`  
错误。判断条件写反了。只有当 `p == q` 时，才说明待删结点就是尾结点，也就是链表中仅有一个数据结点，此时才需要令 `p = h`。若写成 `p != q`，反而会在一般情况下错误地把尾指针改到头结点。

D. `q = h->next; h->next = q->next; if (p == q) p = h; free(q);`  
正确。既完成了普通删除操作，又覆盖了“仅一个数据结点”时尾指针需要回指头结点的特殊情况。

## 易错点

1. **“第一个元素”不是头结点**  
本题删除的是首个数据结点，即 `h->next`，头结点 `h` 不删除。

2. **单循环链表要检查尾指针是否失效**  
只要题目给了尾指针 `p`，就必须考虑删除后它是否仍然合法。尤其当链表只有一个数据结点时，删除后必须执行 `p = h`。

3. **保存待删结点必须在改链之前完成**  
应先执行 `q = h->next`，否则可能丢失待删结点地址，导致无法正确释放空间。
