## 答案
B。与结点 `a` 同层的结点是 `d`。

## 解析
后序遍历的访问顺序是“左子树 -> 右子树 -> 根结点”。

已知后序序列为 `e, a, c, b, d, g, f`，可以据此判断各结点在树中的相对位置：  
- `e` 先访问，说明它是左侧最先完成的结点；
- 随后是 `a`、`c`，表明它们处于同一侧子树的递进关系中；
- 再访问 `b`、`d`、`g`，说明它们属于另一侧子树；
- 最后访问 `f`，它是根结点。

题目问的是“与结点 `a` 同层的结点”。根据树形关系判断，`a` 所在层对应的另一个结点是 `d`，因此正确答案选 `B`。

## 选项分析
- A. `c`：`c` 不与 `a` 同层。
- B. `d`：`d` 与 `a` 同层，正确。
- C. `f`：`f` 是根结点，不与 `a` 同层。
- D. `g`：`g` 不与 `a` 同层。

## 易错点
- 不要把“后序序列中的相邻结点”误认为“同层结点”；后序遍历只反映访问顺序，不直接表示层次关系。
- 本题关键是先利用后序遍历判断树中结点的大致位置，再结合树形图确定层次。
