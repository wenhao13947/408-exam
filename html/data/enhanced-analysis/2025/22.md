## 答案

A. **DMA 传送结束**。

理由：外部中断请求通常由外设或外部硬件事件发出，DMA 控制器在传送完成后会向 CPU 发出中断请求，通知本次数据传输结束。

## 解析

判断本题的关键，是区分**外部中断**与**内部中断（异常/陷阱）**：

- **外部中断**：来自 CPU 之外的设备或硬件事件，如 I/O 完成、DMA 结束、时钟中断等。
- **内部中断**：由 CPU 执行指令过程中产生的异常或陷阱，如缺页、断点、除零等。

题目问“会触发外部中断请求的事件”，因此应优先找**由外设主动向 CPU 发出中断信号**的情形。

在四个选项中，**DMA 传送结束**最符合这一特征。DMA 工作时可由 DMA 控制器直接完成内存与设备之间的数据传送，结束后通常通过中断方式通知 CPU：“传输已完成，可以进行后续处理。”这正是典型的外部中断场景。

其余三个选项都不属于“外设发起的外部中断请求”：

- 总线事务结束属于正常的数据传输流程结束；
- 页故障处理结束是异常处理流程的收尾；
- 执行断点指令属于程序执行中触发的陷阱。

因此，正确答案是 **A**。

## 选项分析

A. **DMA 传送结束**  
正确。DMA 控制器属于外部硬件部件，传送完成后会向 CPU 发出中断请求信号，通知数据传输结束。这是教材中常见的**外部中断**实例。

B. **总线事务结束**  
错误。总线事务结束只是一次总线读写或传输操作的正常完成，属于系统正常工作流程的一部分，不是需要外设额外发起中断请求来通知 CPU 的典型事件。CPU 或相关控制逻辑本身即可感知该事务完成。

C. **页故障处理结束**  
错误。页故障本身属于**内部中断/异常**，因为它是在指令执行过程中访问页面失败而触发的。题目说的是“处理结束”，此时异常处理程序已经完成，CPU 会根据保存的现场返回原程序继续执行，并不会因此再触发一次外部中断请求。

D. **执行断点指令**  
错误。断点指令用于调试，执行到断点时会触发**陷阱（trap）**，本质上属于与指令执行直接相关的**内部中断/异常**，而不是外设引起的外部中断。

## 易错点

- 不要把“会打断 CPU 执行”都笼统看成同一种中断。题目考查的是**外部中断请求**，来源必须是 **CPU 外部的设备/硬件**。
- **缺页**和**断点**都容易因“需要进入处理程序”而被误选，但它们都属于**内部中断**。
- 判断技巧：看事件是不是“外设完成某项工作后主动通知 CPU”。如果是，通常更接近外部中断；如果是“CPU 执行指令时自己发现问题或主动陷入”，通常属于内部中断。
