## 答案

**B．$P_3 > P_2 > P_1$**

理由：要提高系统资源利用率，应尽量让 CPU 与 I/O 设备更早并行工作。I/O 占比越高的进程，越适合优先调度，从而使 I/O 设备尽早投入工作，缩短总完成时间。

## 解析

系统资源利用率可表示为：

$$
\text{资源利用率}=\frac{\text{该资源实际工作时间}}{\text{总耗时}}
$$

本题中，三个进程各自的 CPU 时间与 I/O 时间占比已经给定。无论调度顺序如何，CPU 总工作量和 I/O 总工作量本身并不会改变，因此要提高资源利用率，关键不在于改变分子，而在于**尽量减小总耗时**。

进一步看本题的资源关系：

- CPU 与 I/O 设备可以并行工作；
- 若 I/O 设备越早开始工作，则越容易与 CPU 形成重叠执行；
- 并行重叠越充分，总耗时越短，CPU 和 I/O 的利用率就越高。

因此，调度策略应当使 **I/O 尽早启动**。

题中三个进程的特征为：

- $P_1$: CPU 90%，I/O 10%
- $P_2$: CPU 50%，I/O 50%
- $P_3$: CPU 15%，I/O 85%

可见，$P_3$ 是明显的 **I/O 型进程**，$P_1$ 则明显偏 **CPU 型进程**。如果先执行 $P_3$，经过较少的 CPU 处理后，就更可能较早发出 I/O 请求，使 I/O 设备尽快工作；与此同时，CPU 还可以继续处理其他进程，从而提高并行程度。反之，如果先执行 $P_1$，CPU 会长时间忙于计算，而 I/O 设备较晚才开始工作，容易造成前期 I/O 空闲，总耗时变长。

所以优先级应按 I/O 占比从高到低设置：

$$
P_3 > P_2 > P_1
$$

这正对应选项 **B**。

## 选项分析

A．**$P_1 > P_2 > P_3$**  
错误。$P_1$ 的 CPU 占比最高、I/O 占比最低，优先执行会使 I/O 设备较晚投入工作，不利于 CPU 与 I/O 并行，资源利用率较低。

B．**$P_3 > P_2 > P_1$**  
正确。$P_3$ 的 I/O 占比最高，先调度它最有利于尽快启动 I/O，再由 CPU 与 I/O 并行执行其他任务，从而提高系统资源利用率。

C．**$P_2 > P_1 = P_3$**  
错误。$P_1$ 与 $P_3$ 的资源类型差异很大，不能视为同等优先级；其中 $P_3$ 应明显高于 $P_1$。

D．**$P_1 > P_2 = P_3$**  
错误。该选项把 CPU 型进程 $P_1$ 放在最高优先级，与“优先让 I/O 型进程先运行”这一原则相反。

## 易错点

- 不要把“提高资源利用率”误解为“让某一种资源工作时间变长”。本题中资源实际工作时间基本是确定的，真正能优化的是**总耗时**。
- 不要只看 CPU 时间长短，而应看 **CPU 与 I/O 的搭配关系**。本题考查的是让两类资源尽早并行，而不是单纯追求某个进程算得快。
- 一般情况下，**I/O 型进程优先**更有利于提高整体资源利用率；CPU 型进程优先往往会推迟 I/O 启动。
