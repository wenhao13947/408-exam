## 答案
B。至少需要访问主存 1 次。

## 解析
题目把 `x = x + 3` 转成 `add xaddr, 3`，本质上要完成三步：取出 `x` 的值、在 CPU 内部运算、把结果写回 `x`。

已知采用页式虚拟存储管理并配有 TLB，且 Cache 使用 `Write Through`。要求的是“访问主存的次数至少是多少”，因此取最优情况分析：

- 取数阶段：
  - 先访问 TLB，假设命中。
  - 再访问 Cache，假设命中。
  - 这样可以不访问主存。
- 运算阶段：
  - `x + 3` 在 CPU 内部完成，不需要访问主存。
- 写回阶段：
  - 先访问 TLB，假设命中。
  - 再访问 Cache，假设命中。
  - 但由于 Cache 采用 `Write Through`，写命中时必须同时写 Cache 和主存。
  - 因此这里至少要对主存执行 1 次写操作。

所以完成该指令功能时，访问主存的最少次数是 1 次。

## 选项分析
- A. 0：错误。写回时在 `Write Through` 下必须写主存。
- B. 1：正确。取数和运算都可在最优情况下不访问主存，只有写回阶段至少 1 次主存写入。
- C. 2：错误。题目求最少次数，不需要把 TLB 或 Cache 的访问都算作主存访问。
- D. 3：错误。同样是把非主存访问混进去了，且不符合“至少”的最小值要求。

## 易错点
- `TLB` 命中、`Cache` 命中都不等于访问主存。
- `Write Through` 的关键是写 Cache 时要同时写主存，所以写回阶段最少仍要 1 次主存访问。
- 题目问的是“至少”，必须按最优命中情况分析。
