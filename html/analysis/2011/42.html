(1) 基本思想：分别取两个等长升序序列 A、B 当前区间的中位数 a、b。若 a=b，则该值就是两个序列的中位数；若 a<b，则舍弃 A 中较小的一半、B 中较大的一半；若 a>b，则舍弃 A 中较大的一半、B 中较小的一半。每轮舍弃的元素个数保持相同，直到两个区间都只剩一个元素，取较小者。

(2) 算法实现：

int M_Search(int A[], int B[], int n) {
    int s1 = 0, d1 = n - 1, m1;
    int s2 = 0, d2 = n - 1, m2;

    while (s1 != d1 || s2 != d2) {
        m1 = (s1 + d1) / 2;
        m2 = (s2 + d2) / 2;

        if (A[m1] == B[m2]) {
            return A[m1];
        }

        if (A[m1] < B[m2]) {
            if ((s1 + d1) % 2 == 0) {
                s1 = m1;
                d2 = m2;
            } else {
                s1 = m1 + 1;
                d2 = m2;
            }
        } else {
            if ((s1 + d1) % 2 == 0) {
                d1 = m1;
                s2 = m2;
            } else {
                d1 = m1;
                s2 = m2 + 1;
            }
        }
    }

    return A[s1] < B[s2] ? A[s1] : B[s2];
}

(3) 每轮都将问题规模约减半，因此时间复杂度为 O(log n)；只使用常数个变量，空间复杂度为 O(1)。
