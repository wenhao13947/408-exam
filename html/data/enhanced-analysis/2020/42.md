## 答案

### （1）
适宜采用**二叉树**保存这种具有前缀特性的不等长二进制编码。具体地说，可用一棵编码二叉树表示：从根结点出发，规定沿左分支表示读入 `0`，沿右分支表示读入 `1``（或反之，只要约定一致即可）`，每个字符的编码对应一条从根到某个叶结点的路径，叶结点中保存该字符。

### （2）
译码过程如下：从左到右扫描输入的 `0/1` 串，从根结点开始，遇 `0` 就沿一个约定方向下移，遇 `1` 就沿另一个约定方向下移；当到达叶结点时，输出该叶结点所对应的字符，然后回到根结点，继续处理后续比特，直到整个 `0/1` 串扫描结束。

### （3）
判定某字符集的不等长编码是否具有前缀特性，可通过**边建二叉树边检查**来完成。依次读入每个编码，从根开始按位向下查找或创建结点：

1. 若在尚未处理完当前编码时就遇到一个已有叶结点，说明已有某编码是当前编码的前缀，不具有前缀特性。
2. 若当前编码所有位处理完后，整条路径上都没有新建结点，说明当前编码与已有编码完全相同，或当前编码是已有较长编码的前缀，也不具有前缀特性。
3. 若所有编码都能正常插入，且未出现上述情况，则该编码集具有前缀特性。

## 解析

### （1）
题目给出的编码有三个关键条件：

1. 编码是二进制串，只含 `0` 和 `1`；
2. 编码长度不等长；
3. 任一字符编码都不是其他字符编码的前缀。

因此，最自然的存储方式就是**二叉树**。

原因是：二进制编码每读一位只有两种选择，正好对应二叉树的两个分支。把根到某个结点路径上的边标记为 `0/1` 后，每个字符编码都能唯一对应为一条路径。又因为题目要求具有前缀特性，所以一个字符编码不能停在另一个字符编码路径的中途，这就意味着**字符应当存放在叶结点**上，而不是存放在内部结点上。

可概括为：

| 编码元素 | 二叉树中的表示 |
|---|---|
| `0` 或 `1` | 从当前结点沿左/右分支走一步 |
| 一个字符的完整编码 | 从根到某个叶结点的一条路径 |
| 编码长度 | 路径长度 |
| 字符信息 | 叶结点中存放的字符 |

所以，本问答案是：用二叉树保存前缀编码，且各字符对应根到叶的路径。

### （2）
在第（1）问的存储结构上，译码过程就是沿树逐位向下走。

具体过程如下：

1. 从输入 `0/1` 串的左端开始扫描；
2. 当前先指向二叉树根结点；
3. 读到一位：
   - 若该位为 `0`，就沿约定的一个方向下移；
   - 若该位为 `1`，就沿约定的另一个方向下移；
4. 若到达叶结点，说明刚好识别出一个完整字符，立即输出该叶结点保存的字符；
5. 输出后重新回到根结点，继续扫描后面的比特；
6. 直到整个 `0/1` 串处理完毕，译码结束。

这里之所以能“走到叶结点就立即输出”，根本原因正是前缀特性成立。因为若某个字符编码是别的编码前缀，就会出现“走到这里既可能结束，也可能继续”的歧义，无法唯一译码。题目已说明编码具有前缀特性，所以到达叶结点时就可以确定识别出一个字符。

### （3）
这一问要求判定一个给定编码集是否具有前缀特性。最直接的方法，就是把这些编码按顺序插入第（1）问中的二叉树，同时检查是否发生冲突。

初始时，二叉树只有一个根结点，左右孩子指针均为空。

对每一个编码 $C$，从左到右逐位处理：

1. 从根结点出发；
2. 当前位为 `0` 或 `1` 时，就沿对应方向查找下一结点；
3. 若该方向为空，则新建结点并继续向下；
4. 在处理过程中检查以下两类冲突。

第一类冲突：**处理中途遇到已有叶结点**。  
这说明已有某个较短编码已经结束，而当前编码还没结束，即“已有编码是当前编码的前缀”。因此不具有前缀特性。

第二类冲突：**当前编码全部处理完，但沿途没有创建任何新结点**。  
这说明整条路径原本就已经存在，会出现两种情况：

- 当前编码与某个已有编码完全相同；
- 当前编码对应的结点不是新生成的，且其下方还有后继路径，即“当前编码是已有较长编码的前缀”。

这两种情况都不满足前缀特性。

如果所有编码都处理完成，且始终没有出现上述冲突，则该字符集的编码具有前缀特性。

从判定逻辑看，本质就是检查是否存在下面两种非法关系：

- 某个已有编码是新编码的前缀；
- 新编码是某个已有编码的前缀。

而利用二叉树，可以在建树过程中一次完成存储与判定。

## 易错点

1. **不能只答“用树”**。应明确是**二叉树**，并说明 `0/1` 分别对应两条分支。
2. **字符应对应叶结点**。若把字符放在内部结点，就可能使该编码成为其他编码的前缀。
3. **第（3）问的两类冲突都要说全**：
   - 处理中途遇到叶结点；
   - 编码处理完却没有新建结点。
4. 本题问的是“前缀特性判定”，不需要扩展到哈夫曼树构造、带权路径长度等无关内容。
