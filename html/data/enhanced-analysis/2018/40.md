## 答案
D. ASCII 文本。SMTP 可直接传输的就是 ASCII 内容，无需借助 MIME 转换。

## 解析
SMTP（Simple Mail Transfer Protocol，简单邮件传输协议）最初主要用于传输 7 位 ASCII 编码的邮件内容。像 JPEG、MPEG、EXE 这类非 ASCII 内容，通常需要先通过 MIME 转换成适合邮件传输的格式，再交由 SMTP 发送。

因此，题目问“无需转换即可由 SMTP 协议直接传输”的内容，只有 ASCII 文本符合要求。

## 选项分析
A. JPEG 图形：属于二进制多媒体内容，不能被 SMTP 直接按原样传输，需 MIME 编码。  
B. MPEG 视频：同样是非 ASCII 二进制内容，需 MIME 编码后再通过 SMTP 传输。  
C. EXE 文件：可执行文件是二进制文件，SMTP 不能直接传输原始内容。  
D. ASCII 文本：SMTP 本身支持，可直接传输，正确。

## 易错点
SMTP 直接支持的是 ASCII，不是任意文本格式或任意“邮件内容”。判断时只要看到图片、视频、可执行文件等二进制数据，通常都要先经过 MIME 处理。
