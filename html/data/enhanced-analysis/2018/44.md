## 答案
（1）主存物理地址占 $28$ 位。  

（2）TLB 采用全相联映射；TLB 用 SRAM 实现。  

（3）Cache 采用 2 路组相联映射。若采用 LRU 替换算法和回写（Write Back）策略，则每行除数据（Data）、Tag 和有效位外，还应有 LRU 位和修改位（脏位）。Cache 总容量为 $558$ 字节。Cache 中有效位用于指出该行内容是否有效。  

（4）虚拟地址 `0008C040H` 对应的物理地址是 `0040040H`，Cache 不命中。虚拟地址 `0007C260H` 所在主存块映射到的 Cache 组号是 $3$。  

## 解析
### （1）主存物理地址位数
页式虚拟存储管理中，物理地址由实页号和页内地址拼接而成。题图中页内地址为 $12$ 位，实页号为 $16$ 位，因此主存物理地址长度为  
$$16+12=28\text{ 位}$$

也可由题图直接读出物理地址字段为 $20+3+5=28$ 位，结论一致。

### （2）TLB 的映射方式与实现器件
TLB 中每项都要与虚页号并行比较，查找时没有固定的地址映射位置限制，可将页表项放入任一空闲 TLB 项中，因此 TLB 采用全相联映射。

TLB 属于小容量、高速缓冲存储器，需要较高的读写速度，因此通常用 SRAM 实现。

### （3）Cache 的映射方式、附加位、容量与有效位作用
从题图可看出，Cache 每组有两行，因此采用 2 路组相联映射。

若采用 LRU 替换算法，需要记录组内两行的近期使用情况，因此还应设置 LRU 位；若采用回写策略，则每行还应设置修改位（脏位），用于标识该行数据是否被修改，替换时据此决定是否写回主存。

题图给出物理地址共 $28$ 位，其中 Tag 占 $20$ 位，组号占 $3$ 位，块内地址占 $5$ 位，所以：
- 组数为 $2^3=8$ 组；
- 每组 2 行；
- 每块大小为 $2^5=32$ B。

于是每行数据部分为
$$32\times 8=256\text{ 位}$$

每行除数据外，还有 Tag $20$ 位、有效位 $1$ 位、LRU 位 $1$ 位、修改位 $1$ 位，共 $23$ 位。  
因此 Cache 总容量为
$$8\times 2\times (256+20+1+1+1)=4464\text{ 位}=558\text{ 字节}$$

有效位用于指示该 Cache 行中的内容是否有效。若有效位为 0，则该行即使 Tag 相同，也不能判为命中。

### （4）地址转换、Cache 命中与组号
本问前半部分需要先完成地址转换，再据此判断是否在 Cache 中命中；后半部分只利用地址字段划分确定组号。

对虚拟地址 `0008C040H`：

- 虚页号为 `008CH`；
- 页内地址为 `040H`。

由题图可知，虚页号 `008CH` 在 TLB 中对应的实页号为 `0040H`，且有效位为 1，因此对应的物理地址为
$$0040H \parallel 040H = 0040040H$$

再判断 Cache 是否命中。物理地址 `0040040H` 中：
- 高 $20$ 位 `00400H` 为 Tag；
- 中间 $3$ 位为组号 `010B`，即第 2 组；
- 低 $5$ 位为块内偏移。

检查 Cache 第 2 组的两行可知：其中一行 Tag 与 `00400H` 相同，但有效位为 0；另一行有效位为 1，但 Tag 不同。因此此次访问在 Cache 中不命中。

对虚拟地址 `0007C260H`，只需求其所在主存块映射到的 Cache 组号。由于页内地址在地址转换前后保持不变，其低 $12$ 位仍为 `260H`。按题图所示物理地址格式，相关位对应的组号为 `011B`，因此该主存块映射到的 Cache 组号是
$$3$$

## 易错点
- 不要混淆 TLB 与 Cache 的映射方式。TLB 依靠并行比较查找，属于全相联映射；图中的 Cache 则是 2 路组相联。
- 判断 Cache 是否命中时，Tag 相同还不够，必须同时满足有效位为 1。
- 计算 Cache 总容量时，除数据位外，还要计入 Tag、有效位以及题设要求的附加控制位。
