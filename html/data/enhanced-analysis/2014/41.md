## 答案

采用递归遍历即可正确求出二叉树的 WPL。

基本做法是：从根结点开始遍历整棵树，并把当前结点的深度作为参数向下传递。若当前结点是叶结点，则它对 WPL 的贡献为 `$depth \times weight$`；若当前结点不是叶结点，则继续递归处理其左、右子树，子树中的结点深度都加 1。空树的 WPL 为 0。根结点深度按题意口径取 0，即路径长度按边数计算。

二叉链表结点可定义为：

```c
typedef struct BiTNode {
    int weight;
    struct BiTNode *lchild, *rchild;
} BiTNode, *BiTree;
```

对应算法可写为：

```c
int WPL(BiTree root, int depth) {
    if (root == NULL)
        return 0;

    if (root->lchild == NULL && root->rchild == NULL)
        return depth * root->weight;

    return WPL(root->lchild, depth + 1) + WPL(root->rchild, depth + 1);
}

int GetWPL(BiTree root) {
    return WPL(root, 0);
}
```

## 解析

> **考场判断：** 本题按深度优先遍历访问每个结点，遇到叶结点就累加“权值 × 深度”，这既是最直接的做法，也已经达到 $O(n)$ 的最优时间复杂度。这里没有必要为了凑两种解法再设计一个更复杂方案。

### (1) 算法的基本设计思想

WPL 的定义是二叉树中所有叶结点的带权路径长度之和，即

$$
WPL=\sum w_i l_i
$$

其中，`$w_i$` 是叶结点的权值，`$l_i$` 是根到该叶结点的路径长度。

因此，问题的关键只有两点：

1. 遍历整棵二叉树；
2. 只在访问到叶结点时累计其贡献 `$depth \times weight$`。

递归法最直接。因为二叉树本身具有递归结构，所以可以设计一个递归函数：

- 参数 1：当前结点指针；
- 参数 2：当前结点深度。

递归过程中分三种情况处理：

| 情况 | 处理方式 |
| --- | --- |
| 当前结点为空 | 返回 0 |
| 当前结点为叶结点 | 返回 `$depth \times weight$` |
| 当前结点为非叶结点 | 返回左子树 WPL 与右子树 WPL 之和 |

这样整棵树递归结束后，返回值就是所求 WPL。

### (2) 二叉树结点的数据类型定义

题目已说明采用二叉链表存储，因此结点至少应包含：

- 权值域 `weight`
- 左孩子指针 `lchild`
- 右孩子指针 `rchild`

可定义为：

```c
typedef struct BiTNode {
    int weight;
    struct BiTNode *lchild, *rchild;
} BiTNode, *BiTree;
```

这里 `weight` 用 `int` 即可，符合题目要求。

### (3) 算法描述

下面给出与上述思想一致的递归实现。

```c
typedef struct BiTNode {
    int weight;
    struct BiTNode *lchild, *rchild;
} BiTNode, *BiTree;

/* 返回以 root 为根的子树的带权路径长度，depth 为 root 所在深度 */
int WPL(BiTree root, int depth) {
    if (root == NULL)          // 空树
        return 0;

    if (root->lchild == NULL && root->rchild == NULL)
        return depth * root->weight;   // 叶结点，计入贡献

    // 非叶结点，递归计算左右子树
    return WPL(root->lchild, depth + 1) + WPL(root->rchild, depth + 1);
}

/* 求整棵二叉树的 WPL */
int GetWPL(BiTree root) {
    return WPL(root, 0);       // 根结点深度为 0
}
```

这段代码与题意完全一致：

- `GetWPL(root)` 从根结点开始；
- 根的深度取 0，表示路径长度按边数计算；
- 遇到叶结点时才累加权值乘路径长度；
- 非叶结点本身不计入 WPL，只负责向下递归。

正式作答时统一使用题目给出的 `lchild/rchild` 字段和结点类型名，避免代码无法编译；递归思想仍是从根结点遍历并累计叶结点贡献。

## 复杂度分析

设二叉树共有 `$n$` 个结点。

- 时间复杂度：`$O(n)$`  
  每个结点最多访问一次。
- 空间复杂度：`$O(h)$`  
  其中 `$h$` 为二叉树高度，递归调用栈所需空间与树高成正比。
