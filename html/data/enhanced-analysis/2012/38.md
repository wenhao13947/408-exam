## 答案

A．根据 IP 地址查询 MAC 地址。

ARP（Address Resolution Protocol，地址解析协议）的作用，是把网络层的 IP 地址解析成数据链路层使用的 MAC 地址，以便数据帧能够在局域网中实际发送。

## 解析

题干问的是“ARP 协议的功能”。判断这类题，关键是分清不同层次使用的地址类型：

- 网络层使用的是 **IP 地址**
- 数据链路层实际交付帧时使用的是 **MAC 地址**

主机在局域网内发送数据时，只有目标 IP 地址还不够，因为真正封装成以太网帧发送时，还必须填写目标 **MAC 地址**。因此，需要一种机制把“已知的 IP 地址”转换为“对应的 MAC 地址”，这就是 ARP 的作用。

所以，本题应选：

- **根据 IP 地址查询 MAC 地址**

这正对应 A 选项。

## 选项分析

A．根据 IP 地址查询 MAC 地址  
正确。ARP 的定义就是完成这一地址解析过程，即由网络层地址映射到链路层硬件地址。

B．根据 MAC 地址查询 IP 地址  
错误。这不是 ARP 的功能。早期相关概念中，反向根据 MAC 找 IP 对应的是 **RARP**（Reverse ARP）的思路，但不属于本题所问的 ARP。

C．根据域名查询 IP 地址  
错误。这属于 **DNS**（Domain Name System）的功能。DNS 负责域名与 IP 地址之间的解析，不负责 IP 与 MAC 之间的映射。

D．根据 IP 地址查询域名  
错误。这也属于 **DNS** 的反向解析范畴，仍然不是 ARP 的功能。

## 易错点

- 不要把 **ARP** 和 **DNS** 混淆。  
  - ARP：`IP -> MAC`
  - DNS：`域名 -> IP`，以及相关反向解析

- 要注意“协议所处层次”。  
  ARP 服务于网络层地址到数据链路层地址的转换，核心对象是 **IP 地址** 和 **MAC 地址**，不是域名。

- 做题时可直接抓关键词判断：  
  只要题目出现“IP 地址”和“MAC 地址”之间的对应关系，优先考虑 **ARP**；出现“域名”和“IP 地址”之间的对应关系，则优先考虑 **DNS**。
