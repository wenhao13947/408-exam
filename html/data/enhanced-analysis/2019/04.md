## 答案

**A. 仅 I**

理由：删除结点再重新插入后，AVL 树是否恢复为原树，取决于删除和插入过程中是否发生替代与旋转调整。  
I 说“可能不相同”成立；II、III 都用了“一定”，但都能举出反例，因此错误。

## 解析

题目比较的是同一棵 AVL 树在“删除结点 $v$”并“再插回 $v$”之后，原树 $T1$ 与新树 $T3$ 的关系。

需要抓住两个事实：

- AVL 树插入新结点时，插入位置一定发生在某个叶子位置。
- AVL 树删除结点后，若失衡，可能通过单旋或双旋改变整棵树的结构；即使关键字集合最终一样，树形也未必一样。

因此，本题不能只看“删掉又插回的是同一个结点”，而要看这两个操作是否引起了结构调整。

### 对 I 的判断

**图解：叶结点删除**

看删除叶结点后是否失衡，以及再插回时树形是否改变。

![叶结点删除](/data/enhanced-analysis/assets/2019/04/original-analysis-1.svg)

I：若 $v$ 是 $T1$ 的叶结点，则 $T1$ 与 $T3$ **可能不相同**。

这句话是对的，因为“可能不相同”只需要存在一种情况即可。

若删除叶结点后树仍平衡，则不会调整；再把该结点插回去，通常会回到原来的位置，此时 $T1$ 与 $T3$ 可能相同。  
但若删除该叶结点后树失衡并发生旋转，树形已经改变；之后再插回该结点时，它会按当前 $T2$ 的查找路径插入到某个叶子位置，最终形成的 $T3$ 就**可能与原树不同**。

所以 I 成立。

### 对 II、III 的判断

**图解：非叶删除一**

看非叶结点删除后用子结点替代，再插回时树形是否不同。

![非叶删除一](/data/enhanced-analysis/assets/2019/04/original-analysis-2.svg)

II：若 $v$ 不是 $T1$ 的叶结点，则 $T1$ 与 $T3$ **一定不相同**。  
III：若 $v$ 不是 $T1$ 的叶结点，则 $T1$ 与 $T3$ **一定相同**。

这两个说法都过于绝对，只要分别找到反例即可否定。

当删除的是非叶结点时，情况比删除叶结点更复杂，因为删除非叶结点通常要先用其前驱或后继替代该结点，再删除那个实际被摘除的位置结点。这样一来，原树结构很容易变化，因此 **$T1$ 与 $T3$ 可能不同**。这足以否定 III。

另一方面，删除非叶结点后，再插入该结点，如果插入导致某种旋转，也**有可能重新恢复到原来的树形**。这说明并非“一定不同”，从而否定 II。

因此，当 $v$ 不是叶结点时，正确结论是：

- $T1$ 与 $T3$ **可能相同**；
- 也 **可能不相同**。

既然 II、III 都把这种不确定性说成“一定”，两者都错。

## 选项分析

### I. 若 $v$ 是 $T1$ 的叶结点，则 $T1$ 与 $T3$ 可能不相同

**正确。**

关键在“可能”二字。  
删除叶结点后：

- 若不失衡、不调整，再插回去，树可能恢复原状；
- 若失衡并调整，再插回去，树也可能不再是原来的形状。

所以“可能不相同”成立。

### II. 若 $v$ 不是 $T1$ 的叶结点，则 $T1$ 与 $T3$ 一定不相同

**错误。**

删除非叶结点后，确实常常会改变结构；但“再插入”时如果恰好触发某种旋转，可能把树形恢复成原来的样子。  
因此只能说“可能不相同”，不能说“一定不相同”。

### III. 若 $v$ 不是 $T1$ 的叶结点，则 $T1$ 与 $T3$ 一定相同

**错误。**

删除非叶结点往往要用前驱或后继替代，之后再插入该结点时，它只会作为新插入结点出现在某个叶子位置，再加上可能发生的旋转，最终树形完全可能与原树不同。  
因此“一定相同”显然不成立。

## 易错点

### 非叶结点的“删除”不是简单拿掉

**图解：旋转恢复**

看删除与插入引发旋转后，树形是否可能恢复到原状。

![旋转恢复](/data/enhanced-analysis/assets/2019/04/original-analysis-3.svg)

删除非叶结点时，通常不是直接把该结点删空，而是先用前驱或后继替代，再删除替代结点原来的位置。这一步本身就可能改变结构，是判断 II、III 的关键。

### “关键字集合相同”不等于“树形相同”

$T1$ 和 $T3$ 中结点值最终可能完全一样，但 AVL 树经过删除、插入、旋转后，**形状**未必一致。题目比较的是树 $T1$ 与 $T3$ 的结构关系，不能只看元素是否一样。

### 看到“一定”优先考虑反例

II、III 都是绝对表述。此类题最有效的方法就是找反例：只要存在一种情况不满足，“一定”就错误。  
本题最终只有 I 的“可能”表述成立，所以答案是 **A**。
