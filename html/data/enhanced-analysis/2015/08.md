## 答案
C. $i = 5,\ j = 2$

## 解析
这题考查 KMP 匹配过程中发生失配后的指针回退。

题目给出第一次失配时 $i = j = 5$，说明当前比较的是主串第 5 位和模式串第 5 位，而且下标是从 $0$ 开始计数的。此时主串和模式串前面已经有一段公共前缀匹配成功。

KMP 的规则是：失配后，主串指针 $i$ 不回退，模式串指针 $j$ 回退到 `next[j]` 所指位置，再继续比较。  
对模式串 `abaabc`，有：

- $next[5] = 2$

因此失配后下一次开始匹配时：

- $i$ 仍为 $5$
- $j = 2$

所以答案是 **C**。

## 选项分析
A. $i = 1,\ j = 0$  
错误。KMP 失配后主串指针不会回到前面，更不会跳到 $1$。

B. $i = 5,\ j = 0$  
错误。$i$ 保持不变是对的，但 $j$ 不应直接回到 0；应回退到 `next[5] = 2`。

C. $i = 5,\ j = 2$  
正确。符合 KMP 失配回退规则。

D. $i = 6,\ j = 2$  
错误。失配后主串指针 $i$ 不前进，仍停在失配位置。

## 易错点
- 失配后只回退模式串指针 $j$，主串指针 $i$ 通常不动。
- 本题下标是从 $0$ 开始，不是从 $1$ 开始。
- 不必完整求出整个 `next` 数组，只需知道失配位置对应的 `next[5] = 2`。
