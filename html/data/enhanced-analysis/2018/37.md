## 答案
D。H1 发帧时目的 MAC 应写成路由器 R 面向 H1 的接口 MAC；R 转发给 H2 时，源 MAC 改为 R 面向 H2 的接口 MAC。

## 解析
题目考察的是以太网帧在路由转发过程中的 MAC 地址变化。

H1 和 H2 不在同一网络内，中间经过路由器 R，因此 H1 发送的帧不能直接以 H2 的 MAC 作为目的地址，而应先送到默认网关 R。

- H1 发出封装 P 的以太网帧时：
  - 源 MAC 是 H1 自己的 MAC：`00-1a-2b-3c-4d-52`
  - 目的 MAC 是路由器 R 连接 H1 所在网络的接口 MAC：`00-1a-2b-3c-4d-51`

- 路由器 R 转发给 H2 时：
  - 路由器会重新封装以太网帧
  - 源 MAC 变为 R 连接 H2 所在网络的接口 MAC：`00-a1-b2-c3-d4-61`
  - 目的 MAC 为 H2 的 MAC：`00-a1-b2-c3-d4-62`

因此，H1 发出的帧目的 MAC、H2 收到的帧源 MAC 分别是 `00-1a-2b-3c-4d-51` 和 `00-a1-b2-c3-d4-61`，选 D。

## 选项分析
- A：前半部分把目的 MAC 写成了 H2 所在网络的主机 MAC，错；H1 发帧应先交给路由器。
- B：前半部分同样错；后半部分的源 MAC 也不对。
- C：前半部分把目的 MAC 写成 H1 自身 MAC，错；发往外网时不应这么填。
- D：符合两段转发过程中的 MAC 变化，正确。

## 易错点
以太网帧的 MAC 地址是“逐跳变化”的，路由器每转发一次都会重新封装二层帧；但 IP 分组的目的 IP 不变。
