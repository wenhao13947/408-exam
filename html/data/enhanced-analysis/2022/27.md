## 答案

**C**。因为 CPU 处于**用户态**时只能执行**非特权指令**；而处于**内核态**时，既可以执行特权指令，也可以执行非特权指令。

## 解析

本题考查 CPU 的两种运行模式及其与指令权限的对应关系。

操作系统通常将 CPU 运行状态分为**用户态（User Mode）**和**内核态（Kernel Mode）**。二者的核心区别在于：是否允许执行**特权指令**。

所谓**特权指令**，就是只能由操作系统内核在内核态下执行的指令。这类指令往往涉及系统控制、硬件管理、内存保护等关键操作，因此不能交给普通用户程序直接执行。相应地，用户程序中出现的指令应当都是**非特权指令**。

据此可以直接判断：

- CPU 在**用户态**时，**只能执行非特权指令**；
- 如果在**用户态**下尝试执行特权指令，会**触发异常**，由系统接管处理；
- CPU 在**内核态**时权限更高，**既能执行特权指令，也能执行非特权指令**。

因此，四个选项中，只有“CPU 处于用户态时只能执行非特权指令”这一表述正确，答案为 **C**。

## 选项分析

A. **CPU 处于用户态时只能执行特权指令**  
错误。用户态恰恰**不能**执行特权指令，只能执行非特权指令。

B. **CPU 处于内核态时只能执行特权指令**  
错误。内核态不是“只能执行特权指令”，而是**既可以执行特权指令，也可以执行非特权指令**。

C. **CPU 处于用户态时只能执行非特权指令**  
正确。这是用户态的基本特征，也是本题的直接考点。

D. **CPU 处于内核态时只能执行非特权指令**  
错误。内核态具有更高权限，当然可以执行特权指令，因此“只能执行非特权指令”明显不对。

## 易错点

- 容易把“内核态能执行特权指令”误记成“内核态只能执行特权指令”。这里的“能”不等于“只能”。
- 判断这类题时可直接记忆对应关系：  
  **用户态 -> 只能非特权指令**  
  **内核态 -> 特权、非特权指令都能执行**
- 若题目出现“用户态执行特权指令会怎样”，标准结论是：**会触发异常**。
