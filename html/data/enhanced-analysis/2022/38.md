## 答案
选 **C**，需要 **11 RTT**。

## 解析
题目考察 TCP 拥塞控制在**超时重传**后的恢复过程。

当 `cwnd = 16KB` 时发生超时，TCP 处理为：
- `ssthresh = cwnd / 2 = 8KB`
- `cwnd = 1KB`
- 重新进入**慢开始**

之后 `cwnd` 按 RTT 指数增长：
- 第 1 个 RTT 后：`cwnd = 2KB`
- 第 2 个 RTT 后：`cwnd = 4KB`
- 第 3 个 RTT 后：`cwnd = 8KB`

当 `cwnd` 达到 `ssthresh = 8KB` 后，转入**拥塞避免**，此后每经过 1 个 RTT，`cwnd` 增加 1KB：
- 第 4 个 RTT 后：`9KB`
- 第 5 个 RTT 后：`10KB`
- 第 6 个 RTT 后：`11KB`
- 第 7 个 RTT 后：`12KB`
- 第 8 个 RTT 后：`13KB`
- 第 9 个 RTT 后：`14KB`
- 第 10 个 RTT 后：`15KB`
- 第 11 个 RTT 后：`16KB`

因此，`cwnd` 再次增长到 `16KB` 至少需要 **11 RTT**。

## 选项分析
- A. `4 RTT`：不足以从 `1KB` 增长到 `16KB`。
- B. `5 RTT`：仍达不到 `16KB`。
- C. `11 RTT`：正确，符合“慢开始 + 拥塞避免”的完整恢复过程。
- D. `16 RTT`：过大，不符合题意。

## 易错点
- 超时后不是直接把 `cwnd` 改成 `ssthresh`，而是先置为 `1KB` 再慢开始。
- 这里的“至少”是指从**超时发生后重新计时**，不是从 `cwnd = 16KB` 的上一轮开始算。
