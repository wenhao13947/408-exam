## 答案

需设置 2 个同步信号量：`SAC` 和 `SCE`，分别用于实现 `A -> C`、`C -> E` 这两组跨线程同步关系，初值都应为 `0`。

可写为：

`SAC`：表示操作 `A` 是否已经完成，供 `T2` 在执行 `C` 前等待。  
`SCE`：表示操作 `C` 是否已经完成，供 `T1` 在执行 `E` 前等待。

线程同步描述如下：

`T1`：
```c
semaphore SAC = 0;
semaphore SCE = 0;

T1() {
    A;
    signal(SAC);
    wait(SCE);
    E;
    F;
}
```

`T2`：
```c
T2() {
    B;
    wait(SAC);
    C;
    signal(SCE);
    D;
}
```

## 解析

### 同步关系分析

题目给出的约束为：

- `C` 在 `A` 和 `B` 完成后执行；
- `D` 和 `E` 在 `C` 完成后执行；
- `F` 在 `E` 完成后执行。

再结合线程内部分工：

- `T1` 执行 `A、E、F`；
- `T2` 执行 `B、C、D`。

先看同一线程内部的顺序：

- 在 `T1` 中，`A -> E -> F` 可由程序书写顺序自然保证；
- 在 `T2` 中，`B -> C -> D` 也可由程序书写顺序自然保证。

因此，不需要为 `B -> C`、`C -> D`、`E -> F` 这些同一线程内的先后关系再单独设置同步信号量。真正需要用信号量处理的是跨线程约束。

### 跨线程约束的设置

需要处理两组跨线程同步关系：

1. `A -> C`  
   因为 `A` 在 `T1` 中，`C` 在 `T2` 中，所以 `T2` 执行 `C` 前，必须等待 `T1` 完成 `A`。  
   设置同步信号量 `SAC`：
   - `T1` 执行完 `A` 后执行 `signal(SAC)`；
   - `T2` 在执行 `C` 前执行 `wait(SAC)`。

2. `C -> E`  
   因为 `C` 在 `T2` 中，`E` 在 `T1` 中，所以 `T1` 执行 `E` 前，必须等待 `T2` 完成 `C`。  
   设置同步信号量 `SCE`：
   - `T2` 执行完 `C` 后执行 `signal(SCE)`；
   - `T1` 在执行 `E` 前执行 `wait(SCE)`。

这样即可满足题目全部约束。

### 信号量初值

两个信号量初值都应设为 `0`。

原因是：

- `SAC=0` 表示在 `A` 尚未完成前，`T2` 不能通过 `wait(SAC)` 去执行 `C`；
- `SCE=0` 表示在 `C` 尚未完成前，`T1` 不能通过 `wait(SCE)` 去执行 `E`。

若初值设为 `1`，则对应线程第一次执行 `wait()` 时不会被阻塞，无法保证所要求的先后次序。

## 易错点

- 本题只需为跨线程的先后关系设置同步信号量，不必为同一线程内部已经确定的顺序重复设置。
- `C` 需在 `A` 和 `B` 之后执行，其中 `B -> C` 已由 `T2` 的程序顺序保证，因此只需额外处理 `A -> C`。
- 信号量初值应为 `0`，不能写成 `1`。初值写错会直接破坏同步约束。
