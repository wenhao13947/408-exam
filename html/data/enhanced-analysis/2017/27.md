## 答案
错误的是 **B**。时间片用完后，当前进程应由**执行态转为就绪态**，不是阻塞态。

## 解析
基于时间片的进程调度中，时间片越短，进程被抢占和切换得越频繁，操作系统需要更多时间保存、恢复 CPU 环境以及进程相关数据，因此系统开销会增大。

对本题关键判断如下：

- **时间片用完**：说明进程只是被分配的 CPU 时间结束了，并未等待某个外部事件或资源。
- 进程因此失去的是**处理机资源**，下一状态应是**就绪态**，等待再次获得 CPU。
- **阻塞态**对应的是“进程因等待某个事件或除 CPU 之外的资源而暂停”，这与时间片用尽无关。

时钟中断的作用是计时。操作系统通过周期性时钟中断更新当前进程的时间片剩余值；例如一个进程初始分配 $3\text{ ms}$，执行到 $2\text{ ms}$ 时发生一次时钟中断，就应将剩余时间更新为 $1\text{ ms}$。若不更新，进程会错误地持续占用 CPU。

时间片大小还要综合考虑响应时间、系统开销和进程数量等因素：响应时间要求高时，时间片宜短；系统开销较大时，时间片宜长；进程数量多时，也通常需要适当缩短时间片以提高响应性。

## 选项分析
- **A**：正确。时间片越短，切换次数越多，而进程切换会带来额外系统开销。
- **B**：错误。时间片用完后，进程应从**执行态变为就绪态**，不是阻塞态。
- **C**：正确。时钟中断发生后，系统需要更新当前进程在时间片内的剩余时间。
- **D**：正确。时间片大小受响应时间、系统开销、进程数量等因素影响。

## 易错点
- 把“**时间片用完**”误判成“**阻塞**”。前者是被剥夺 CPU，后者是等待事件/资源。
- 把“**执行态 -> 就绪态**”和“**执行态 -> 阻塞态**”混淆。时间片调度对应的是前者。
