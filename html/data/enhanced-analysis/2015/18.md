## 答案
D。`8000` 和 `8004` 同属同一存储体 `M0`，且再次访问间隔小于一个完整存储周期，因此会发生访存冲突。

## 解析
4 体交叉编址存储器按低位交叉理解时，可用 `mod 4` 判断地址归属：

- `4A` 对应 `M0`
- `4A + 1` 对应 `M1`
- `4A + 2` 对应 `M2`
- `4A + 3` 对应 `M3`

看各地址按 mod 4 分到 M0 到 M3，重点定位 8004 和 8000 同属 M0。

![地址与存储体对应](/data/enhanced-analysis/assets/2015/18/original-analysis-1.svg)

- `8005 -> M1`
- `8006 -> M2`
- `8007 -> M3`
- `8008 -> M0`
- `8001 -> M1`
- `8002 -> M2`
- `8003 -> M3`
- `8004 -> M0`
- `8000 -> M0`

交叉存储器中，若同一存储体再次被访问，间隔必须至少跨过一个存储周期 `T`。题目序列里，`8004` 和 `8000` 都落在 `M0`，且访问顺序上相邻出现，间隔不足一个 `T`，因此冲突发生在这两个地址之间。

## 选项分析
A. `8004` 和 `8008`：二者都在 `M0`，但在给定访问序列中它们之间还隔着其他地址，不是最终构成冲突的一对。

B. `8002` 和 `8007`：分别属于 `M2` 和 `M3`，不在同一存储体内，不会形成该类冲突。

C. `8001` 和 `8008`：分别属于 `M1` 和 `M0`，不在同一存储体内，不冲突。

D. `8000` 和 `8004`：都属于 `M0`，且再次访问间隔不足一个存储周期，正确。

## 易错点
- 4 体交叉编址的判断关键是“同一存储体 + 再次访问过早”，不是单纯看地址是否连续。
- 十进制地址不必转二进制，直接按 `mod 4` 分组即可。
