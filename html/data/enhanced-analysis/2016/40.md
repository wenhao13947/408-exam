## 答案

**C．0，4**

理由：题目问的是域名服务器 `201.1.1.1` 在完成解析过程中“可能发出”的 DNS 查询次数。若其缓存中已有结果，则最少发出 `0` 次；若无缓存且按迭代方式逐级查询，则最多发出 `4` 次。

## 解析

先抓住题眼：**统计对象是域名服务器 `201.1.1.1` 发出的查询次数**，不是主机 `H4` 发出的次数。

当 `H4` 访问 `www.abc.xyz.com` 时，主机会先向本地域名服务器 `201.1.1.1` 发起请求；但这一次是**主机对本地域名服务器**的查询，不属于题目所问“201.1.1.1 发出的查询”，因此**不能计入**。

### 最少次数

若 `201.1.1.1` 的缓存中已经有 `www.abc.xyz.com` 对应的解析结果，或者已有足够的中间解析信息可直接返回结果，则它**不需要再向其他 DNS 服务器发出任何查询**，因此最少为：

$$0$$

### 最多次数

题目已知：**所有域名服务器均采用迭代查询方式**。  
对四级域名 `www.abc.xyz.com`，在最坏情况下，本地域名服务器需要逐级询问：

1. 向**根域名服务器**查询，获得 `.com` 顶级域名服务器的信息；
2. 向 **`.com` 顶级域名服务器**查询，获得 `xyz.com` 权限域名服务器的信息；
3. 向 **`xyz.com` 权限域名服务器**查询，获得 `abc.xyz.com` 权限域名服务器的信息；
4. 向 **`abc.xyz.com` 权限域名服务器**查询，获得 `www.abc.xyz.com` 对应主机的 IP 地址。

因此最多需要发出：

$$4$$

这里的关键是：`xyz.com` 和 `abc.xyz.com` 对应的是**两个不同层次的权限域名服务器**，应分别计为一次查询，不能合并。

## 选项分析

A．`0，3`  
错误。最少 `0` 次是对的，但最多不是 `3` 次。最坏情况下需要经过根、`.com`、`xyz.com`、`abc.xyz.com` 共 `4` 次查询。

B．`1，3`  
错误。错在两个地方：  
一是最少不是 `1` 次，因为本地域名服务器可能命中缓存，从而 `0` 次即可；  
二是最多也不是 `3` 次，而是 `4` 次。

C．`0，4`  
正确。既符合缓存命中时最少 `0` 次，也符合迭代逐级解析时最多 `4` 次。

D．`1，4`  
错误。最多 `4` 次是对的，但最少不是 `1` 次。若本地域名服务器已有缓存，则无需再向外查询，所以应为 `0` 次。

## 易错点

1. **不要把 H4 向本地域名服务器的那一次请求算进去。**  
题目问的是 `201.1.1.1` 发出的查询次数，不是整个解析过程中所有通信次数。

2. **要把两级权限域名服务器分开计数。**  
`xyz.com` 和 `abc.xyz.com` 不是同一次查询对象，最坏情况下都要查，因此权限服务器阶段是 `2` 次，不是 `1` 次。

3. **“最少次数”要先考虑缓存。**  
DNS 题目出现“最少查询次数”时，优先检查是否存在缓存命中的可能；只要题目未排除缓存，最少就可能是 `0` 次。
