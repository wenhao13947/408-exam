## 答案

**A. 键盘输入。**  
理由：外部中断通常由 CPU 与内存之外的外设发出中断请求引起；键盘属于典型输入设备，其输入事件会触发外部中断。

## 解析

判断“外部中断”的关键，是看事件是否来自 **CPU 执行指令之外的外部设备**。

本题中，键盘输入属于外设事件。以 `scanf` 等输入操作为例，程序执行到需要读入字符时，用户敲击键盘，键盘控制器会向 CPU 发送中断请求，通知 CPU 处理输入数据。这类中断来源于外设，因此属于**外部中断**。

而其余几项都不是外部设备主动发起的中断：

- 除数为 0 是在执行指令过程中产生的运行错误，属于**异常**中的内中断。
- 浮点运算下溢是指运算结果的绝对值过小，接近于 0，小到超出机器可表示的非零范围。通常按机器零处理，即结果视为
  $$
  x \approx 0
  $$
  一般**不会因此产生外部中断**。
- 访存缺页发生在指令执行期间的存储管理过程中，属于**故障（fault）**，本质上仍归入**异常**，不是外部中断。

因此，只有 **A** 符合题意。

## 选项分析

**A. 键盘输入**  
正确。键盘是外部输入设备，输入字符后可通过键盘中断控制器向 CPU 发出中断请求，属于典型的外部中断来源。

**B. 除数为 0**  
错误。除零是在执行算术指令时被检测出的错误，属于异常，不是外设触发的外部中断。

**C. 浮点运算下溢**  
错误。浮点下溢表示结果太小，过于接近 0，超出机器可表示的有效非零范围，通常按机器零处理，不属于外部中断。按本题给定解析，应判为不会引起题目所问的外部中断。

**D. 访存缺页**  
错误。缺页是在访存过程中发现所需页面不在内存而触发的事件，属于故障，归入异常类，而不是外部中断。

## 易错点

- **“中断”不等于“外部中断”**：异常、故障、陷阱等虽也会打断当前程序执行，但它们通常属于内中断或异常，不能都归为外部中断。
- **判断标准看来源**：  
  - 来源于键盘、鼠标、I/O 设备等外设，通常是外部中断。  
  - 来源于指令执行过程中的错误或检测结果，如除零、缺页，通常属于异常。
- **缺页容易误判**：缺页确实会打断当前执行，但它是访存时由系统检测并处理的异常事件，不是外设直接请求造成的外部中断。
