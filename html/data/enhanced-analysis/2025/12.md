## 答案
选 **D**，`ui = 2^{32} - 2^{15} + 1`。

## 解析
`short si = -32767`，先看 `si` 的 16 位补码表示。  
因为
$$-32767 = -32768 + 1 = -2^{15} + 1$$
所以它的 16 位机器数为最高位为 `1`、其余位对应 `+1` 的形式，即：
$$1000\ 0000\ 0000\ 0001$$

接着执行 `unsigned int ui = si`。这里不是先按无符号解释再补零，而是先把 `short` 这个带符号值扩展到 32 位。由于 `short` 是有符号类型，因此应做**符号扩展**：高 16 位补 `1`，得到
$$1111\ 1111\ 1111\ 1111\ 1000\ 0000\ 0000\ 0001$$

最后 `ui` 是 `unsigned int`，按无符号数解释这个 32 位机器数。其值为：
$$2^{32} - 2^{15} + 1$$

## 选项分析
- A. $2^{15} - 1$：这是 `32767`，与本题符号和位宽转换结果不符。
- B. $2^{15} + 1$：与 `-32767` 的补码扩展结果不符。
- C. $2^{32} - 2^{15} - 1$：符号位处理错误，少了末尾的 `+1`。
- D. $2^{32} - 2^{15} + 1$：正确。

## 易错点
- 不能把 `si` 先当成无符号数再去零扩展。
- 本题的顺序是：先把 `short` 按**符号扩展**升到 32 位，再赋给 `unsigned int`，最后按无符号解释。
