## 答案

**D**。四个说法都正确，分别对应 DMA 传送的预处理、总线申请、数据传送和结束处理四个环节。

## 解析

判断这题的关键，是把 **DMA 方式的完整流程** 理清楚。DMA 传送通常可分为三个阶段：

1. **预处理阶段**  
   CPU 先执行相关程序，对 DMA 控制器进行初始化，设置传送参数，例如主存首地址、传送长度、传送方向等。实际题目表述为“由设备驱动程序设置传送参数”，这是成立的，因为设备驱动程序本身就是 CPU 执行的、用于控制具体设备的程序，用户程序不能直接去操作 DMA 控制器。

2. **数据传送阶段**  
   在真正传送数据前，DMA 控制器需要先获得总线控制权，因此会向 CPU 申请总线使用权。获得总线后，由 DMA 控制器直接控制总线，在主存和 I/O 设备之间完成数据交换。这个过程中，**CPU 不直接参与每个字节或每个字的数据搬运**，这正是 DMA 相对于程序查询和中断方式效率更高的原因。

3. **后处理阶段**  
   当 DMA 传送结束后，DMA 控制器会向 CPU 发出中断请求，CPU 响应中断后执行中断服务程序，完成传送结束后的收尾处理。

因此，题干中的四个叙述都符合 DMA 的标准工作过程，正确答案为 **D**。

## 选项分析

Ⅰ. **DMA 传送前由设备驱动程序设置传送参数**  
正确。DMA 控制器在工作前必须被初始化，而初始化工作由 CPU 执行相应的设备驱动程序来完成。这里的“设备驱动程序设置参数”本质上就是 CPU 完成预处理。

Ⅱ. **数据传送前由 DMA 控制器请求总线使用权**  
正确。DMA 要代替 CPU 进行数据传送，前提就是先取得总线控制权，因此在传送前必须发出总线请求。

Ⅲ. **数据传送由 DMA 控制器直接控制总线完成**  
正确。DMA 的核心特征就是由 DMA 控制器直接在主存和外设之间传送数据，CPU 不参与具体传送过程。

Ⅳ. **DMA 传送结束后的处理由中断服务程序完成**  
正确。DMA 结束后会通过中断通知 CPU，再由 CPU 执行中断服务程序进行结束处理，这属于 DMA 的后处理阶段。

## 易错点

- 容易把“设备驱动程序设置参数”和“CPU 初始化 DMA 控制器”看成矛盾。其实二者并不冲突：**设备驱动程序是由 CPU 执行的**。
- 容易误认为“DMA 传送时 CPU 完全无关”。准确地说，**CPU 不参与数据块的具体搬运**，但仍参与前期初始化和后期中断处理。
- 要区分“中断方式”和“DMA 方式”：DMA 也会用到中断，但**中断只用于传送结束后的通知与处理**，不是像中断 I/O 那样由 CPU 直接完成每次数据传送。
