## 答案

采用“三次逆置”的原地算法实现循环左移。

把数组按前 `p` 个元素和后 `n-p` 个元素划分为两段：前段记为 `a`，后段记为 `b`。原序列为 `ab`，目标是变为 `ba`。具体做法是：

1. 先逆置前段 `a`，得到 `a^{-1}b`
2. 再逆置后段 `b`，得到 `a^{-1}b^{-1}`
3. 最后逆置整个序列，得到  
   $$
   (a^{-1}b^{-1})^{-1}=ba
   $$

按此思想编程，时间复杂度为 `O(n)`，空间复杂度为 `O(1)`。

## 解析

### 解法一：暴力法

循环左移一次，就是保存首元素、其余元素整体左移一位，再把首元素放到末尾。重复执行 $p$ 次即可，时间复杂度为 $O(np)$，空间复杂度为 $O(1)$。思路直接，但当 $p$ 较大时会重复搬移大量元素。

### 解法二：优化解法

利用三次逆置一次完成循环左移，时间复杂度降为 $O(n)$，仍只使用 $O(1)$ 额外空间。

> **考场建议：** 先写清暴力移动过程保证算法完整，再用“重复搬移”作为优化切入点想到三次逆置。

### （1）算法的基本设计思想

设原数组为  
$$
\langle x_0,x_1,\dots,x_{n-1}\rangle
$$

将其循环左移 `p` 位后，应变为  
$$
\langle x_p,x_{p+1},\dots,x_{n-1},x_0,x_1,\dots,x_{p-1}\rangle
$$

把原序列分成两部分：

- `a = <x0, x1, ..., x(p-1)>`
- `b = <xp, x(p+1), ..., x(n-1)>`

则原序列可写成 `ab`，左移 `p` 位后的目标就是 `ba`。

可利用逆置的性质完成这一变换：

$$
ab \rightarrow a^{-1}b \rightarrow a^{-1}b^{-1} \rightarrow (a^{-1}b^{-1})^{-1}=ba
$$

也就是：

1. 逆置区间 `[0, p-1]`
2. 逆置区间 `[p, n-1]`
3. 逆置区间 `[0, n-1]`

例如序列 `abcdefgh` 左移 `3` 位：

- 原序列：`abc | defgh`
- 逆置前段后：`cba | defgh`
- 逆置后段后：`cba | hgfed`
- 整体逆置后：`defghabc`

这正是左移 `3` 位的结果。

参数范围统一记为 `0 < p < n`，反转区间的末下标统一使用 `n-1`。

### （2）算法描述

下面给出 C 语言实现。第 `(2)` 问直接承接第 `(1)` 问的“三次逆置”思想。

```c
void reverse(int R[], int from, int to) {
    int i = from, j = to;
    while (i < j) {
        int temp = R[i];
        R[i] = R[j];
        R[j] = temp;
        i++;
        j--;
    }
}

void loopMove(int R[], int n, int p) {
    /* 题干已保证 0 < p < n，这里直接按题意处理 */
    reverse(R, 0, p - 1);   // 逆置前 p 个元素
    reverse(R, p, n - 1);   // 逆置后 n-p 个元素
    reverse(R, 0, n - 1);   // 逆置整个数组
}
```

说明：

- `reverse(R, from, to)` 的功能是将数组 `R` 中下标从 `from` 到 `to` 的元素原地逆置。
- 主函数 `loopMove` 中三次调用 `reverse`，分别对应前段逆置、后段逆置、整体逆置。

还可以增加 `p = p % n` 和 `if (p < 0) return;`，以提高代码的健壮性。这些属于额外健壮性处理；但本题题干已经限定 `0 < p < n`，因此按题意直接写出核心算法即可，不影响评分主结论。

### （3）时间复杂度和空间复杂度

第 `(3)` 问依赖第 `(2)` 问中的具体实现来分析。

三次逆置分别处理的区间长度为：

1. 前段长度为 `p`，时间复杂度为 `O(p/2)`
2. 后段长度为 `n-p`，时间复杂度为 `O((n-p)/2)`
3. 整体长度为 `n`，时间复杂度为 `O(n/2)`

总时间为：

$$
O(p/2)+O((n-p)/2)+O(n/2)
$$

其数量级与 `n` 成正比，因此总时间复杂度为：

$$
O(n)
$$

空间方面，整个过程只使用了少量辅助变量，如 `i`、`j`、`temp`，没有申请与 `n` 成比例的额外存储空间，因此空间复杂度为：

$$
O(1)
$$

## 易错点

1. 不要把本题写成借助辅助数组的方案。  
辅助数组法时间复杂度也是 `O(n)`，但空间复杂度为 `O(p)`，不符合“时间和空间两方面都尽可能高效”的主方案要求。

2. 三次逆置的顺序不能错。  
必须是：

- 逆置前段 `[0, p-1]`
- 逆置后段 `[p, n-1]`
- 逆置整体 `[0, n-1]`

3. 区间右端点应写成 `n-1`，不是 `n`。  
数组下标范围是 `0` 到 `n-1`。

4. 要明确说明这是“循环左移”。  
左移 `p` 位后的结果是把前 `p` 个元素移到末尾，不是普通覆盖移动。
