## 答案
B。按题意将 `6, 9, 1, 5, 8, 4, 7` 依次插入初始为空的大根堆，最终层序结果为 `9, 8, 7, 5, 6, 1, 4`。

## 解析
这道题考查的是“依次插入到初始为空的大根堆中”的构造过程。每插入一个关键字后，都要立即进行自下而上的调整，恢复成大根堆，再插入下一个关键字。

**图解：初始堆构造过程**

图中按顺序展示各关键字插入后堆的调整结果。

![初始堆构造过程](/data/enhanced-analysis/assets/2021/11/original-analysis-1.svg)

按插入顺序分析：
- 插入 `6`，堆为 `6`
- 插入 `9`，`9 > 6`，上浮后堆为 `9, 6`
- 插入 `1`，无需调整，堆为 `9, 6, 1`
- 插入 `5`，与父结点 `6` 比较后不交换，堆为 `9, 6, 1, 5`
- 插入 `8`，先与 `6` 交换，再与 `9` 比较后上浮，堆为 `9, 8, 1, 5, 6`
- 插入 `4`，无需调整，堆为 `9, 8, 4, 5, 6, 1`
- 插入 `7`，与 `4` 交换后停止，堆为 `9, 8, 7, 5, 6, 1, 4`

因此最终大根堆 `H` 的层序遍历结果是 `9, 8, 7, 5, 6, 1, 4`，对应选项 B。

## 选项分析
- A：`9, 8, 7, 6, 5, 4, 1`，不符合按插入顺序逐步上浮后的结果。
- B：`9, 8, 7, 5, 6, 1, 4`，符合题意，正确。
- C：`9, 8, 7, 5, 6, 4, 1`，`4` 和 `1` 的位置不对。
- D：`9, 6, 7, 5, 8, 4, 1`，不满足大根堆的层序构造结果。

## 易错点
题目关键词是“依次插入到初始为空的大根堆中”，这表示每次插入都要调整；不要误认为是“先给出一个堆，再插入一个新元素后调整”。
