## 答案
D. Ⅱ、Ⅲ、Ⅳ

## 解析
单处理机系统只有一个 CPU，同一时刻只能有一个进程占用处理机，所以**进程与进程**不能并行，只能并发执行。

判断“是否可并行”的关键标准是：**两件事能否在同一时刻同时进行**。据此分析各项：

- **Ⅱ 处理机与设备**：可以并行。处理机在计算时，设备也可以同时进行 I/O 操作，例如边编辑文档边打印。
- **Ⅲ 处理机与通道**：可以并行。通道可视为独立于 CPU 的 I/O 控制部件/处理单元，与处理机互不占用同一执行资源。
- **Ⅳ 设备与设备**：可以并行。不同设备可同时工作，例如显示器显示信息时，打印机同时输出。

因此，可并行的是 **Ⅱ、Ⅲ、Ⅳ**，选 **D**。

## 选项分析
- **A. Ⅰ、Ⅱ、Ⅲ**：错在 **Ⅰ**。单处理机系统中进程不能并行。
- **B. Ⅰ、Ⅱ、Ⅳ**：错在 **Ⅰ**。同理，进程与进程不能并行。
- **C. Ⅰ、Ⅲ、Ⅳ**：错在 **Ⅰ**。同理，进程与进程不能并行。
- **D. Ⅱ、Ⅲ、Ⅳ**：正确。

## 易错点
- **并发**不等于**并行**：单处理机下进程之间通常是并发，不是并行。
- 本题问的是“**可并行**”，不是“能否同时出现执行效果”。
- **处理机与通道**容易混淆：通道不是普通进程，它与 CPU 可独立工作。
