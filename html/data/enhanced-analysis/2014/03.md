## 答案

选 `A`。

队空：`end1 == end2`  
队满：`end1 == (end2 + 1) mod M`

## 解析

循环队列放在数组 `A[0..M-1]` 中，`end1` 指向队头元素，`end2` 指向队尾元素的后一个位置。又因为最多只能容纳 `M-1` 个元素，所以要预留一个空位置来区分队空和队满。

初始为空时，队头和“队尾后一个位置”重合，因此有：
$$end1 = end2$$

队满时，`end2` 再向后走一步就会撞到 `end1`，所以队满条件是：
$$end1 = (end2 + 1) \bmod M$$

取模必须对数组长度 `M`，而不是对 `M-1`；判满后按 `M` 回绕。

## 选项分析

A. 队空：`end1 == end2`；队满：`end1 == (end2 + 1) mod M`  
符合循环队列“牺牲一个单元”的标准判定，正确。

B. 队空：`end1 == end2`；队满：`end2 == (end1 + 1) mod (M - 1)`  
队空条件对，但判满时取模基数错了。循环数组按长度 `M` 回绕，不是按 `M-1`。

C. 队空：`end1 == (end1 + 1) mod M`；队满：`end1 == (end2 + 1) mod M`  
队满条件对，但队空条件错误。`end1 == (end1 + 1) mod M` 一般不成立，不能表示空队列。

D. 队空：`end1 == (end2 + 1) mod M`；队满：`end2 == (end1 + 1) mod (M - 1)`  
前半句其实是队满的形式，和队空混淆了；后半句又错误地对 `M-1` 取模，所以不对。

## 易错点

`M-1` 是“最多能放的元素个数”，不是数组回绕的长度。判断空满时，回绕一定按数组长度 `M` 计算。
