## 答案

**D**。

错误原因是：内部异常处理后的返回位置取决于异常类型，并不是一律“返回到发生异常的指令继续执行”。

## 解析

内部异常（内中断）来源于 CPU 内部执行过程，和当前正在执行的指令直接相关。题干已经给出内部异常可分为 **fault、trap、abort** 三类，这三类异常最关键的区别之一，就是异常处理结束后的**返回断点不同**。

判断本题的核心在于区分：

- 哪些表述是内部异常的共性；
- 哪些表述只适用于某一类异常，不能推广为全部内部异常。

本题中：

- 内部异常由当前指令执行引发，因此 **A 正确**；
- 内部异常的检测由 CPU 内部逻辑完成，因此 **B 正确**；
- 内部异常是在指令执行过程中被发现并响应的，因此 **C 正确**；
- 但异常处理后的返回位置并不统一，因此 **D 错误**。

更具体地说：

- **fault**：通常返回到**引发故障的那条指令**，修正后可重新执行；
- **trap**：通常返回到**下一条指令**；
- **abort**：通常表示严重故障，**往往无法精确返回**，可认为没有正常意义上的返回断点。

因此，“内部异常处理后返回到发生异常的指令继续执行”只适用于部分 **fault** 情况，不能概括所有内部异常。

## 选项分析

**A. 内部异常的产生与当前执行指令相关**

正确。  
内部异常是由程序执行过程中出现的特殊情况引起的，例如非法操作、除零、地址异常、缺页、特权指令等，都与当前执行指令有关。  
这也是它区别于外部中断的重要特征之一：外部中断通常来自外设事件，与当前指令本身无直接关系。

**B. 内部异常的检测由 CPU 内部逻辑实现**

正确。  
既然内部异常发生在指令执行期间，其检测自然由 CPU 内部的控制逻辑、运算逻辑、存储管理等硬件机制完成，而不是由外设发起。

**C. 内部异常的响应发生在指令执行过程当中**

正确。  
内部异常是在执行当前指令时被发现的，因此其响应与该指令执行过程密切相关。  
与之对比，外部中断一般是在一条指令执行完毕后，CPU 再去检查并响应中断请求。

**D. 内部异常处理后返回到发生异常的指令继续执行**

错误。  
这句话把所有内部异常都按同一种返回方式处理了，结论过于绝对。

- 对 **fault**，常常返回到当前出错指令；
- 对 **trap**，返回点通常是下一条指令；
- 对 **abort**，一般不保证能返回到原指令继续执行。

所以该说法不能作为内部异常的一般结论，故为错误项。

## 易错点

**1. 不要把 fault 的返回方式当成所有内部异常的共同特征**  
很多题目会利用“fault 可重执行”来干扰，进而误认为所有内部异常处理后都回到原指令，这是错误的。

**2. 注意区分“内部异常”与“外部中断”**  
常考对比点有三个：

- 是否与当前指令相关；
- 检测/请求来源是 CPU 内部还是外设；
- 响应时机是在指令执行过程中还是指令结束后。

**3. 题干中出现“一律”“总是”“都”时要警惕**  
D 选项的问题就在于表述过于绝对，没有区分 **fault / trap / abort** 三类异常的差异。
