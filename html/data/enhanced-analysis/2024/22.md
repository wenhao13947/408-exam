## 答案

C．设备接口和主存之间。

理由：DMA（Direct Memory Access）方式下，数据传输由 DMA 控制器直接组织完成，传输过程不经过 CPU 寄存器，因此其控制的数据传输通路位于设备接口与主存之间。

## 解析

本题考查 DMA 方式的数据传输路径。

DMA 的核心特点是：在一次数据块传输过程中，CPU 只负责传输前的初始化和传输结束后的处理，实际的数据交换由 DMA 控制器直接在外设和主存之间完成。也就是说，CPU 不参与每一个数据字的搬运，数据也不会先进入 CPU 寄存器再写入主存。

因此，判断本题时可以抓住一个关键点：

- 只要选项中把 CPU 作为数据传输通路的一端或中间环节，通常就不符合 DMA 的工作方式。
- DMA 方式要实现的是“外设数据送主存”或“主存数据送外设”，所以完整的数据通路应当落在设备接口和主存之间。

题干问的是“DMA 控制器控制的数据传输通路位于哪里”，这里强调的是实际进行数据交换的路径，而不是控制信号的联系路径。DMA 控制器虽然需要与 CPU 协调总线使用权，但它真正控制的数据流动，是在设备接口和主存之间进行的。

所以正确选项为 C。

## 选项分析

A．CPU 和主存之间

错误。CPU 和主存之间的通路是 CPU 访存时使用的路径，不是 DMA 方式下外设与主存直接交换数据的通路。DMA 的意义之一就是减少 CPU 直接参与数据搬运。

B．CPU 和 DMA 控制器之间

错误。CPU 与 DMA 控制器之间主要是初始化、启动、状态管理等控制关系，不是题目所说的“数据传输通路”。DMA 传输的数据并不以 CPU 为中转。

C．设备接口和主存之间

正确。DMA 控制器接管总线后，直接控制设备接口与主存之间的数据交换，这正是 DMA 数据传输的本质。

D．设备接口和 DMA 控制器之间

错误。设备接口与 DMA 控制器之间可以看作传输链路中的局部连接，但题目问的是完整的数据传输通路所在位置。DMA 要完成的是设备与主存之间的数据交换，因此仅说“设备接口和 DMA 控制器之间”并不完整，也不符合题意。

## 易错点

- 容易把“控制关系”误认为“数据通路”。CPU 可以对 DMA 进行启动和管理，但不等于数据经过 CPU。
- 容易看到“DMA 控制器”就误选 D。DMA 控制器是传输的组织者，但数据传输的两端仍然是设备接口和主存。
- 判断 DMA 题目时，可直接检查一句话：数据是否经过 CPU 寄存器。若不经过，凡是含 CPU 作为数据通路核心的选项通常都可排除。
