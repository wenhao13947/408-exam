## 答案

**B．3**

理由：按拓扑排序规则，每一步只能从当前**入度为 0** 的顶点中选择。由题图可知可行分支只有 3 条，因此不同拓扑序列共有 3 个。

## 解析

拓扑排序的基本原则是：反复选择当前入度为 $0$ 的顶点输出，并删除以该顶点为起点的所有有向边。

结合题图与已知解析过程，可按分支枚举：

**图解：拓扑分支示意**

观察初始入度为0的顶点及后续分支选择。

![拓扑分支示意](/data/enhanced-analysis/assets/2010/08/original-analysis-1.svg)

首先，初始时只有顶点 **a** 的入度为 $0$，因此首项只能是 **a**。

输出 **a** 并删除从 **a** 发出的边后，当前可选顶点变为 **e** 或 **b**，于是出现两类情况。

### 情况一：第二个选 **e**
此时序列前缀为 **ae**。

继续删除 **e** 的出边后，后续只能依次得到 **b、c、d**，因此得到 1 个拓扑序列：

- **aebcd**

### 情况二：第二个选 **b**
此时序列前缀为 **ab**。

输出 **b** 后，当前可选顶点变为 **e** 或 **c**，再分两种情况：

- 若第三个选 **e**，则后续只能是 **c、d**，得到  
  **abecd**
- 若第三个选 **c**，则后续只能是 **e、d**，得到  
  **abced**

因此总共得到 3 个不同的拓扑序列：

- **aebcd**
- **abecd**
- **abced**

故答案为 **3**。

## 选项分析

A．**4**  
错误。按题图约束最多只能枚举出 3 个合法拓扑序列，没有第 4 种。

B．**3**  
正确。合法拓扑序列恰好为 **aebcd、abecd、abced** 共 3 个。

C．**2**  
错误。漏掉了其中一个合法分支。

D．**1**  
错误。该图不是唯一拓扑序，输出 **a** 后至少还存在 **e** 与 **b** 的分支选择。

## 易错点

- 不要把“当前可选顶点有多个”误认为都能任意交换位置；必须看删除前面顶点后，后续顶点是否仍保持入度为 $0$。
- 这类题最稳妥的方法是：每次只记录**当前入度为 0 的点**，按分支枚举，避免重复和遗漏。
- 题图中字母大小写不影响结论，**a,b,c,d,e** 与 **A,B,C,D,E** 仅是记号写法不同。
