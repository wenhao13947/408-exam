## 答案
C

## 解析
题干是“新接入网络的主机 H 通过 DHCP 服务器动态请求 IP 地址过程中”的 `REQUEST` 报文。此时主机还没有正式分配到 IP 地址，因此封装该报文的 `IP` 数据报：

- 源 IP 地址是 `0.0.0.0`
- 目的 IP 地址是 `255.255.255.255`

所以答案是 `255.255.255.255, 0.0.0.0`，对应 C。

## 选项分析
A. `192.168.5.1, 0.0.0.0`  
目的地址写成了 DHCP 服务器的具体地址。题目给的是新接入主机的 DHCP 请求过程，初始阶段通常采用广播方式，不应直接写成服务器单播地址。

B. `192.168.5.1, 192.168.5.9`  
源地址写成了 `192.168.5.9`，这表示主机已经有正式 IP，但题干明确是“新接入网络的主机”正在请求地址，尚未获得可用源地址。

C. `255.255.255.255, 0.0.0.0`  
符合 DHCP 初始请求阶段的典型封装方式：目的地址用广播地址，源地址用 `0.0.0.0`。

D. `255.255.255.255, 192.168.5.9`  
目的地址对了，但源地址仍然错误。尚未获取地址时，不能以 `192.168.5.9` 作为源 IP。

## 易错点
这题最容易把“REQUEST 报文”直接理解成“发给服务器的单播报文”。但在新主机刚接入、还没拿到地址时，`REQUEST` 往往仍要用广播目的地址，源地址保持 `0.0.0.0`。
