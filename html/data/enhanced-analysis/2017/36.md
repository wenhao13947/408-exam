## 答案

A．`0.0.0.0`

理由：`0.0.0.0` 表示“本主机、本网络上的未指定地址”，只能在主机尚未获得有效 IP 地址时作为源 IP 地址使用，不能作为目的 IP 地址。

## 解析

本题考查的是几种特殊 IP 地址的用途。判断关键不在于地址分类本身，而在于是否属于“特殊保留地址”。

`0.0.0.0` 是全 32 位全 0 的地址，属于未指定地址（unspecified address）。它的典型用途是：主机在尚不知道自己 IP 地址时，发送报文时可暂时把源地址写成 `0.0.0.0`。因此，它可以作为源地址出现，但不能被当作一个可达的目标主机地址，所以不能作为目的地址。

其余三个选项都不能满足“只能作源地址，不能作目的地址”这一条件：

- `127.0.0.1` 是 loopback（环回）地址，表示本机。以它作为目的地址时，数据报不会发到实际网络中，而是直接回送本机，因此它可以作为目的地址。
- `200.10.10.3` 是普通单播地址。按传统分类方法看，首字节 `200` 落在 C 类地址范围内，因此既可以作源地址，也可以作目的地址。
- `255.255.255.255` 是受限广播地址（limited broadcast address），其用途正是作为广播报文的目的地址发送给本网络内所有主机，因此显然不是“只能作源地址”。

所以，唯一符合题意的是 A。

## 选项分析

A．`0.0.0.0`  
正确。全 0 地址表示未指定地址，可作为源 IP 地址使用，但不能作为目的 IP 地址。

B．`127.0.0.1`  
错误。这是环回地址，表示本机。作为目的地址时，报文直接交给本机协议栈处理，因此它可以作为目的地址。

C．`200.10.10.3`  
错误。这是普通可用的单播地址。首字节为 `200`，按传统分类属于 C 类地址，既能作源地址，也能作目的地址。

D．`255.255.255.255`  
错误。这是全 1 地址，表示受限广播地址，典型用途就是作为目的地址进行广播发送，不能据此选它。

## 易错点

- 不要把 `0.0.0.0` 和 `127.0.0.1` 混淆。  
  `0.0.0.0` 是“未指定地址”，`127.0.0.1` 是“本机环回地址”。

- 不要把“不能在网络中正常寻址”误认为“不能作目的地址”。  
  `127.0.0.1` 虽不会真正发到网络上，但仍然可以作为目的地址。

- `255.255.255.255` 是广播地址，核心特征就是用于目的地址，而不是源地址。
