## 答案
A。`PC` 是专用寄存器，不应归入通用寄存器组。

## 解析
题干问的是“关于 CPU 中的数据通路和控制器的叙述中，错误的是”。逐项判断即可。

`PC`（Program Counter，程序计数器）用于保存下一条将要执行的指令地址，属于专用寄存器，不是通用寄存器组成员，因此 A 错误。

其余选项均成立：
- 控制器需要对指令操作码进行译码，才能生成相应控制信号。
- 单周期 CPU 把一条指令在一个周期内完成，控制逻辑通常比多周期 CPU 更简单。
- 流水线 CPU 并行执行多条指令，必须处理数据相关、控制相关等冒险问题。

## 选项分析
A. 错。`PC` 负责存放下一条指令地址，属于专用寄存器，不属于通用寄存器组。

B. 对。控制器必须包含指令操作码的译码电路，才能据此发出控制信号。

C. 对。单周期 CPU 的控制相对直接，多周期 CPU 需要按阶段控制，通常更复杂。

D. 对。流水线会引入数据冒险、控制冒险等问题，需要相应机制处理。

## 易错点
`PC` 的位置最容易混淆：它虽然和寄存器有关，但不是“通用寄存器”。本题只要抓住“专用寄存器 vs 通用寄存器组”即可。
