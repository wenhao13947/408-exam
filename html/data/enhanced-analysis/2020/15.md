## 答案

**D**。错误原因是：**TLB 和 Cache 都追求高速访问，通常由 SRAM 实现，而不是由 DRAM 组成。**

## 解析

题目要求判断“关于 TLB 和 Cache 的叙述中，错误的是哪一项”。

先明确两者的作用：

- **TLB** 用来缓存**页表项**，本质上是主存中页表的一部分副本，用于加快**虚拟地址到物理地址的转换**。
- **Cache** 用来缓存**主存中的数据副本**，用于加快CPU对数据或指令的访问。

两者虽然缓存的对象不同，但设计目标一致，都是利用“**局部性原理**”减少慢速访问次数，从而提高系统性能。因此，凡是与“局部性、高速访问、缺失后回到主存、硬件支持”相关的共性表述，通常都是成立的。

本题的关键在于区分“**存储器类型**”：

- **DRAM** 容量大、成本低，但速度相对较慢，而且需要周期性刷新，适合做**主存**。
- **SRAM** 速度快、不需要刷新，但成本高、容量较小，适合做**高速缓冲部件**，如 **Cache**，以及通常用于实现 **TLB** 的高速存储结构。

因此，“TLB 和 Cache 都由 DRAM 存储器组成”这一说法错误，故选 **D**。

## 选项分析

**A. 命中率都与程序局部性有关**

正确。  
TLB 和 Cache 之所以容量不大却能显著提升性能，根本原因都是程序具有局部性：

- **时间局部性**：刚访问过的内容，短时间内可能再次访问；
- **空间局部性**：访问某个位置后，邻近位置也可能很快被访问。

TLB 缓存的是常用页表项，Cache 缓存的是常用数据或指令，它们的命中率都依赖局部性。

**B. 缺失后都需要去访问主存**

正确。  
- **TLB miss** 时，需要到**主存中的页表**查找对应页表项；
- **Cache miss** 时，需要到**主存**中取所需数据块。

因此两者缺失后都要进一步访问主存。

**C. 缺失处理都可以由硬件实现**

正确。  
- **Cache miss** 的处理通常由**硬件**完成；
- **TLB miss** 在不同体系结构中可以有不同实现方式，既可以由**硬件**处理，也可以由**软件**参与处理。

题目说的是“**都可以由硬件实现**”，意思是二者都存在由硬件完成缺失处理的可能性，这个表述成立。

**D. 都由 DRAM 存储器组成**

错误。  
这项错在“**DRAM**”。TLB 和 Cache 都要求很高的访问速度，通常由 **SRAM** 实现，而不是 DRAM。  
尤其是 Cache 几乎是典型的 SRAM 应用；TLB 虽常说是相联存储器，但“相联访问方式”和“底层用 SRAM 实现”并不矛盾。

## 易错点

**TLB 是相联存储器**，不等于它“由 DRAM 组成”。  
“相联存储器”强调的是**按内容匹配的访问方式**，而 **SRAM/DRAM** 说的是**底层存储器件类型**，两者不是同一维度的概念。

快速判断这类题的方法是：

- 看到 **Cache / TLB / 高速缓冲**，优先联想到 **SRAM**；
- 看到 **主存**，优先联想到 **DRAM**。
