## 答案

D．SMTP

## 解析

明确结论：单纯使用浏览器访问某大学 Web 网站主页时，`SMTP` 不可能用到，因此选 `D`。

题目考查的是“访问网页这一过程中，哪些协议可能出现”，判断标准是“是否存在可能使用的场景”，而不是“是否一定使用”。因此，像 `PPP`、`ARP`、`UDP` 虽然都不是每次访问网页都必然出现，但在合理场景下都可能被使用；只有 `SMTP` 与网页访问过程无关。

浏览器访问网站主页时，通常会经历这样几个环节：

1. 先接入网络。若用户采用点对点接入方式，链路建立阶段可能使用 `PPP`。
2. 再确定链路层下一跳地址。主机向外发送分组前，若不知道默认网关或同一局域网内目标主机的 MAC 地址，就可能使用 `ARP` 完成 `$IP \rightarrow MAC$` 的解析。
3. 若本机或本地域名服务器缓存中没有该大学网站域名对应的 IP 地址，还需要进行 `DNS` 查询；常规 DNS 查询通常基于 `UDP`，因此 `UDP` 也可能出现。
4. 之后浏览器再与 Web 服务器建立连接并获取网页内容。这一过程属于 Web 访问，不涉及邮件发送。

而 `SMTP` 是简单邮件传输协议，作用是发送电子邮件，典型场景是用户代理向邮件服务器发信，或邮件服务器之间转发邮件。单纯访问 Web 网站主页，不需要发送邮件，因此不可能使用 `SMTP`。

## 选项分析

A. `PPP`  
`PPP` 是点对点协议，属于链路层协议。若用户通过 PPP 类方式接入网络，则在上网接入阶段可能用到它。题目问的是“访问主页时”整个过程中是否可能出现，因此 `PPP` 可能用到，`A` 不是答案。

B. `ARP`  
`ARP` 用于根据 IP 地址解析 MAC 地址。主机访问外部网站时，数据帧首先通常要发给默认网关；若主机尚不知道默认网关的 MAC 地址，就需要通过 `ARP` 获取。因此 `ARP` 可能用到，`B` 不是答案。

C. `UDP`  
访问网站前，如果没有该域名对应的 IP 地址缓存，就要进行 `DNS` 查询；而常规 DNS 查询通常基于 `UDP`。所以 `UDP` 可能用到，`C` 不是答案。

D. `SMTP`  
`SMTP` 用于电子邮件发送，不用于浏览器获取网页资源。题目场景只是“使用浏览器访问某大学 Web 网站主页”，不涉及发送邮件，因此 `SMTP` 不可能用到，`D` 是正确答案。

## 易错点

1. 不要把“可能用到”误判成“必须用到”。  
`PPP`、`UDP` 都不是每次访问网页都一定出现，但题目问的是“不可能使用到的协议”，所以只要存在合理场景即可排除。

2. `UDP` 的判断关键在 `DNS`。  
网页本身通常不是靠 `UDP` 传输的，但域名解析可能用到 `DNS`，而 DNS 常基于 `UDP`，所以 `UDP` 仍然属于“可能用到”。

3. 不要把邮件协议和网页访问混淆。  
`SMTP` 属于电子邮件发送协议，和浏览器访问网页不是一类业务流程，这是本题的核心区分点。
