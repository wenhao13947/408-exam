## 答案

选 **B．`+(-*`**。

## 解析

本题考查中缀表达式转换为后缀表达式时，**运算符栈**的变化过程。题目问的是：扫描到 `f` 时，栈中有哪些元素。

按规则处理：

1. 遇到操作数，直接输出，不入栈。
2. 遇到左括号 `(`，直接入栈。
3. 遇到运算符时，与栈顶运算符比较优先级：
   - 当前运算符优先级更高，则入栈；
   - 否则弹出栈顶中优先级高于或等于它的运算符，再将当前运算符入栈。

对表达式 `a/b+(c*d-e*f)/g` 逐步扫描，跟踪到 `f` 为止：

| 已扫描内容 | 当前字符 | 操作 | 栈内元素（栈底到栈顶） |
|---|---|---|---|
| `a` | `a` | 操作数，输出 | 空 |
| `a/` | `/` | 入栈 | `/` |
| `a/b` | `b` | 操作数，输出 | `/` |
| `a/b+` | `+` | `+` 优先级低于 `/`，先弹出 `/`，再将 `+` 入栈 | `+` |
| `a/b+(` | `(` | 左括号入栈 | `+(` |
| `a/b+(c` | `c` | 操作数，输出 | `+(` |
| `a/b+(c*` | `*` | 栈顶为 `(`，直接入栈 | `+(*` |
| `a/b+(c*d` | `d` | 操作数，输出 | `+(*` |
| `a/b+(c*d-` | `-` | `-` 优先级低于 `*`，先弹出 `*`，再将 `-` 入栈 | `+(-` |
| `a/b+(c*d-e` | `e` | 操作数，输出 | `+(-` |
| `a/b+(c*d-e*` | `*` | `*` 优先级高于 `-`，直接入栈 | `+(-*` |
| `a/b+(c*d-e*f` | `f` | 操作数，输出，栈不变 | `+(-*` |

因此，**当扫描到 `f` 时**，栈内元素自栈底到栈顶依次为：

$$+,\ (, \-,\ *$$

即 **`+(-*`**。

结合过程表，读图时只需抓住括号内这一段：`c*d-e*f` 在扫描到 `f` 之前，先形成 `+(-`，再因 `*` 的优先级高于 `-`，压入成为 `+(-*`。

另外，扫描到题目所问时刻时，后缀式和运算符栈应按上述过程确定。

## 选项分析

**A．`+(*-`**  
错误。扫描到 `-` 时，原来栈顶的 `*` 已经因为优先级高于 `-` 而先出栈，所以 `-` 应该在 `(` 之上；之后遇到新的 `*`，才压到 `-` 上方。因此顺序应为 `+(-*`，不可能是 `+(*-`。

**B．`+(-*`**  
正确。扫描到 `f` 时，`f` 是操作数，只输出不入栈，所以栈保持在扫描前一符号 `*` 之后的状态，即自栈底到栈顶为 `+ ( - *`。

**C．`/+(*−*`**  
错误。扫描到 `+` 时，前面的 `/` 已经被弹出，不会继续留在栈中；而且该选项中的运算符数量也与实际过程不符。

**D．`/+−*`**  
错误。左括号 `(`` 在扫描到后必须入栈，并且在遇到对应的 `)` 之前不会出栈。扫描到 `f` 时仍在括号内部，所以栈中一定包含 `(`，本项缺少这一点。

## 易错点

1. “扫描到 `f` 时”指的是 `f` 已作为操作数被扫描到，此时**还没有处理后面的 `)`**。因此栈状态仍是 `+(-*`。
2. 栈中元素的“依次”默认按**栈底到栈顶**理解，这一点要和题目答案写法保持一致。
3. `*` 与 `-` 的先后关系最容易写反：  
   在 `c*d-e*f` 中，先因 `-` 到来把前一个 `*` 弹出；再遇到后一个 `*` 时，它才压在 `-` 上面。
