## 答案

C．仅 II、III。

理由：外部中断是由 CPU 当前执行指令之外的外部事件引起的；I“访存时缺页”属于内部异常，II“定时器到时”和 III“网络数据包到达”都属于外部中断事件。

## 解析

判断这道题的关键，不是看事件是否“突然发生”，而是看它是否与当前指令执行过程直接相关。

“访存时缺页”发生在指令执行期间的内存访问过程中。CPU 在执行指令、访问某个虚拟页时，发现所需页面不在主存，这会触发缺页异常。它本质上是由当前指令执行引出的异常事件，因此属于内部异常，而不是外部中断。按照异常分类，它通常归入 fault。

“定时器到时”是由硬件定时器产生的事件。它不是某条指令执行错误或访存失败导致的，而是外设或时钟系统在某个时刻主动向 CPU 发出的中断请求，因此属于外部中断。常见地，这类中断也称为时钟中断。

“网络数据包到达”同样不是 CPU 执行某条指令时自然产生的结果，而是网卡等 I/O 设备在收到网络数据后，向 CPU 报告有数据需要处理。这类事件来自外部设备，属于典型的外部中断。

因此，属于外部中断事件的是 II、III，答案选 C。

## 选项分析

A．仅 I、II  
错误。I 错在“访存时缺页”并非外部中断，而是与指令执行相关的内部异常；II 属于外部中断。

B．仅 I、III  
错误。I 不属于外部中断；III“网络数据包到达”才属于外部中断。

C．仅 II、III  
正确。II 是时钟中断，III 是 I/O 设备相关中断，二者都与当前指令执行无直接因果关系，属于外部中断。

D．I、II、III  
错误。I 不能算外部中断，因此三项不可能全对。

## 易错点

- 不要把“异常”和“中断”混为一谈。缺页虽然也会打断当前程序执行，但它是由指令执行过程引发的，属于内部异常，不属于外部中断。
- 判断口诀可以概括为：
  - 与当前指令执行直接相关：优先考虑内部异常；
  - 来自时钟、外设、I/O、网络等外部硬件事件：属于外部中断。
- “定时器到时”容易因“定时”二字被误认为是系统内部行为，但考试分类中它对应的是硬件时钟中断，属于外部中断。
