## 答案

A。该有向图的拓扑有序序列个数为 1，因为按拓扑排序过程逐步删除入度为 0 的顶点时，每一步都只有唯一选择。

## 解析

拓扑排序适用于有向无环图，其核心规则是：

- 每次选取一个入度为 0 的顶点输出；
- 删除该顶点以及从它出发的所有有向边；
- 在剩余图中继续重复上述过程，直到所有顶点都被输出。

判断“拓扑有序”的关键，不是按字母顺序排列，而是满足边的前后约束关系。若图中有弧 $A \to B$，则在任一合法拓扑序列中，A 必须排在 B 前面；若是 $B \to A$，则 B 必须排在 A 前面。

根据题目图和已知讲解过程，可依次得到：

- 初始时，入度为 0 的顶点只有 A，所以第一个只能选 A；
- 删除 A 及其出边后，入度为 0 的顶点只有 B，所以第二个只能选 B；
- 再删除 B 相关边后，入度为 0 的顶点只有 C，所以第三个只能选 C；
- 接着唯一可选的是 D；
- 最后处理 E、F。

本题的决定性依据在于：整个排序过程中，每一轮都没有出现“两个或多个入度为 0 的顶点可任选”的情况，因此不存在分支，也就不可能产生多个不同的拓扑序列。

所以该图的拓扑有序序列只有 1 个，选 A。

## 选项分析

A：正确。题目图在拓扑排序的每一步都只有唯一的入度为 0 顶点，因此拓扑序列唯一，个数为 1。

B：错误。若拓扑序列有 2 个，说明至少在某一步出现了 2 个彼此可交换次序、且同时入度为 0 的顶点。本题不满足这一条件。

C：错误。若有 3 个拓扑序列，必须存在多次可分支选择，或者某些顶点之间不存在先后约束而可重排。本题排序过程没有出现这种情况。

D：错误。与 C 同理，4 个拓扑序列意味着图中存在更明显的并行可选顶点，而本题每一步选择都是唯一的。

## 易错点

- 不要把“拓扑有序”误认为“按字母顺序输出”。拓扑序只要求满足有向边的先后关系。
- 判断拓扑序列个数时，关键看每一步入度为 0 的顶点是否唯一；只要某一步出现多个可选顶点，通常就可能产生不止一种拓扑序列。
- 本题文字转录中“没有入座的点”应理解为“没有入度的点”，属于识别误差，不影响结论。
