## 答案

**D**。理由是符号栈容量为 3，而 D 在扫描过程中会出现 **4 个尚未匹配的左括号同时入栈** 的情况，超过栈容量，因此不能实现。

## 解析

本题考查的是**用栈实现括号匹配**。

括号匹配时，栈中保存的是**尚未匹配的左括号**。处理规则很简单：

- 遇到左括号 `(`、`[`：入栈；
- 遇到右括号 `)`、`]`：与栈顶同类型左括号匹配，匹配成功则出栈；
- 操作数、运算符都不影响括号匹配，可直接忽略。

因此，题目中“栈容量为 3”真正限制的是：

> 在扫描表达式的任意时刻，栈中未匹配左括号的个数都不能超过 3。

所以本题的核心不是看括号总数，而是看**最大嵌套深度**是否超过 3。

### 对 D 的关键判断

D 为：

`[a-(b+[c*(d+e)-f]+g+h)]`

按扫描顺序只看括号：

`[ ( [ ( ) ] ) ]`

在扫描到 `d+e` 前面的左括号 `(` 时，前面已经依次有：

- `[` 入栈
- `(` 入栈
- `[` 入栈

此时栈内已有 3 个左括号，再遇到新的 `(`，就需要第 4 次入栈，栈深变为 4：

$$
3 + 1 = 4
$$

而题设容量只有 3，因此此时无法继续入栈，D 不能实现。

也可以直接理解为：D 的最大未匹配左括号数是 4，超过了栈容量 3。

## 选项分析

### A. `(a+[b+(c+d)e]+f)+g-h`

只看括号序列，可见其最深层次为：

`(` → `[` → `(`

最多同时有 3 个未匹配左括号在栈中，最大栈深为 3，没有超过容量，因此**可以实现**。

### B. `[a*((b+c)/(d-e)+f/g)]-h`

只看括号的嵌套过程：

`[` → `(` → `(`

虽然中间还有后续匹配与出栈，但任意时刻最多也是 3 个未匹配左括号，最大栈深为 3，因此**可以实现**。

### C. `[a*(b-(c-d)*e/(f+g))-h]`

只看括号结构：

`[` → `(` → `(`` 或 `[` → `(` → `(`

其中 `(c-d)` 与 `(f+g)` 是同层的，不会同时形成 4 层嵌套；前一个内层括号匹配出栈后，后一个内层括号再入栈，所以任意时刻最大栈深仍为 3，因此**可以实现**。

### D. `[a-(b+[c*(d+e)-f]+g+h)]`

括号嵌套为：

`[` → `(` → `[` → `(`

这会形成 4 层同时未匹配的左括号，最大栈深为 4，大于容量 3，因此**不能实现**。

## 易错点

- 容量限制看的是**某一时刻栈内元素最多有多少个**，不是看表达式里一共有多少个括号。
- 栈里存放的是**左括号**，不是左右括号都存。
- 判断能否实现时，要看**最大嵌套深度**，而不是括号类型是否复杂。
- 同层括号不一定增加最大栈深，例如 C 中 `(c-d)` 和 `(f+g)` 不是同时压在更深一层，所以不会超过 3。
