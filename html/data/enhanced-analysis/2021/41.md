## 答案

EL 路径存在的判定条件是：无向连通图中度为奇数的顶点个数必须为 $0$ 或 $2$。因此，算法只需统计奇度顶点数；若 `count == 0 || count == 2`，返回 `1`，否则返回 `0`。

## 解析

### 解法一：暴力法

从每个可能的起点出发回溯枚举边序列，尝试构造一条恰好使用全部边一次的路径。该方法需要记录已使用边，最坏时间复杂度呈指数级，图稍大就不可行，但能直接对应 EL 路径的定义。

### 解法二：优化解法

题干已经给出存在性定理，因此无需真正构造路径，只需扫描邻接矩阵统计奇度顶点个数是否为 $0$ 或 $2$，时间复杂度为 $O(|V|^2)$。

> **考场建议：** 暴力回溯只用于帮助理解定义；看到题干已经给出判定条件后，应立即改写成“统计奇度顶点”的判定算法。

### （1）基本设计思想

题干已直接给出 EL 路径存在的条件：无向连通图中，度为奇数的顶点个数是“不大于 2 的偶数”。这等价于奇度顶点个数只能是 $0$ 或 $2$。

所以本题不需要构造路径，只需统计图中奇度顶点的个数并判断结果即可。

对于邻接矩阵存储的无向图，顶点 $v_i$ 的度等于其对应行中非零元素的个数，因此可以逐行扫描邻接矩阵，统计每个顶点的度。

### （2）算法实现

```c
int IsExistEL(MGraph G) {
    int i, j;
    int count = 0;   // 度为奇数的顶点个数

    for (i = 0; i < G.numVertices; i++) {
        int degree = 0;   // 当前顶点的度

        for (j = 0; j < G.numVertices; j++) {
            degree += G.Edge[i][j];
        }

        if (degree % 2 == 1) {
            count++;
        }
    }

    if (count == 0 || count == 2) {
        return 1;
    } else {
        return 0;
    }
}
```

### （3）复杂度分析

设顶点数为 $n$。

外层循环执行 $n$ 次，内层循环对每个顶点扫描一整行，也执行 $n$ 次，所以时间复杂度为 $O(n^2)$。

只使用了若干辅助变量，空间复杂度为 $O(1)$。

## 易错点

- 邻接矩阵求度时，内层循环上界应是 `G.numVertices`，不是 `G.numEdges`。
- `degree` 需要在处理每个顶点前重新置为 `0`。
- 题目中的条件是“不大于 2 的偶数”，本题只能判为 `0` 或 `2`，不能扩展成其他偶数。
- 本题只判断是否存在 EL 路径，不要求输出具体路径。
