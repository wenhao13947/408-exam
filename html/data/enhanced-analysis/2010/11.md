## 答案

A．起泡排序（冒泡排序）。

理由：题目给出的前三趟结果，恰好体现了“每一趟把当前未排序部分中的最大元素逐步交换到末尾”的特征，这正是冒泡排序的典型过程。

## 解析

初始序列为：

$$(2,\ 12,\ 16,\ 88,\ 5,\ 10)$$

题目给出的前三趟结果分别是：

- 第一趟：$$(2,\ 12,\ 16,\ 5,\ 10,\ 88)$$
- 第二趟：$$(2,\ 12,\ 5,\ 10,\ 16,\ 88)$$
- 第三趟：$$(2,\ 5,\ 10,\ 12,\ 16,\ 88)$$

观察这三个结果，可以发现一个非常明显的规律：

- 第一趟结束后，最大元素 `88` 到达最终位置；
- 第二趟结束后，次大元素 `16` 也到达最终位置，因此末尾两个元素为 `16, 88`；
- 第三趟结束后，`12` 也被放到其最终位置，序列整体有序。

这正符合冒泡排序的性质：从左到右依次比较相邻元素，若逆序则交换，于是一趟结束后，当前最大元素会“冒”到最右端。

可按过程验证：

第一趟从左到右比较相邻元素：

- `2` 与 `12`，不交换；
- `12` 与 `16`，不交换；
- `16` 与 `88`，不交换；
- `88` 与 `5`，交换；
- `88` 与 `10`，交换。

得到：

$$(2,\ 12,\ 16,\ 5,\ 10,\ 88)$$

与题目第一趟结果一致。

第二趟继续在前五个元素中冒泡：

- `2` 与 `12`，不交换；
- `12` 与 `16`，不交换；
- `16` 与 `5`，交换；
- `16` 与 `10`，交换。

得到：

$$(2,\ 12,\ 5,\ 10,\ 16,\ 88)$$

与题目第二趟结果一致。

第三趟再处理前四个元素：

- `2` 与 `12`，不交换；
- `12` 与 `5`，交换；
- `12` 与 `10`，交换。

得到：

$$(2,\ 5,\ 10,\ 12,\ 16,\ 88)$$

与题目第三趟结果一致。

因此，该排序方法可能是冒泡排序，答案为 A。

## 选项分析

A．起泡排序

正确。  
冒泡排序的核心特征是：每一趟通过相邻比较和交换，把当前最大元素放到未排序区间的末尾。题目中三趟结果完全符合这一规律。

B．希尔排序

错误。  
希尔排序是按步长 $d$ 将序列分组后分别进行插入排序，其“每一趟”的结果取决于步长划分，而不会稳定表现为“每趟只把一个当前最大值送到末尾”的形式。

结合本题可直接验证：若第一趟采用常见的步长 $d=3$，原序列会分成两组：

- $(2, 88)$
- $(12, 5)$
- $(16, 10)$

分组插入排序后应得到：

$$(2,\ 5,\ 10,\ 88,\ 12,\ 16)$$

这与题目的第一趟结果

$$(2,\ 12,\ 16,\ 5,\ 10,\ 88)$$

明显不符，因此不是希尔排序。

C．归并排序

错误。  
归并排序自底向上时，第一趟归并完成后，应当形成长度为 2 的有序子序列，即相邻两个元素分别有序。  
对原序列 $(2,12,16,88,5,10)$ 而言，第一趟后应表现为：

- $(2,12)$ 有序；
- $(16,88)$ 有序；
- $(5,10)$ 有序。

也就是说，第一趟后应仍为：

$$(2,\ 12,\ 16,\ 88,\ 5,\ 10)$$

而题目第一趟结果是：

$$(2,\ 12,\ 16,\ 5,\ 10,\ 88)$$

其中 `88` 已经跨过多个元素移动到末尾，这不是归并排序一趟归并后的形态，因此排除。

D．基数排序

错误。  
基数排序若按最低位优先（LSD）进行，第一趟结束后，序列应按个位数字稳定有序。

原序列各元素个位分别为：

- `2` 的个位是 `2`
- `12` 的个位是 `2`
- `16` 的个位是 `6`
- `88` 的个位是 `8`
- `5` 的个位是 `5`
- `10` 的个位是 `0`

按个位从小到大稳定排序后，应先出现个位为 `0` 的 `10`，再是个位为 `2` 的 `2、12`，不可能得到题目中的第一趟结果：

$$(2,\ 12,\ 16,\ 5,\ 10,\ 88)$$

此外，本题数据最多是两位数，LSD 基数排序通常至多进行两趟（个位、十位），题目却给出前三趟特征且第三趟才完全有序，也与基数排序不符。

## 易错点

- 不要只看“第一趟后更接近有序”就下结论，要看每一趟的具体结构特征。
- 本题最关键的识别点是：每一趟结束后，未排序部分中的最大元素被放到最右端，这是冒泡排序最典型的判据。
- 归并排序常见误判点在于“局部有序”的含义。归并第一趟后应是“两两有序”，不是把最大元素直接移到末尾。
- 基数排序常见误判点在于忽略“按某一位稳定分配”的特征。第一趟后应体现个位有序，而本题并没有。
