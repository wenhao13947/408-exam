## 答案

### （1）
从 10 ms 开始到所有进程结束：

- 中断次数：**22 次**
- CPU 调度次数：**7 次**

各进程首次调度时刻为：

- **P1：90 ms**
- **P2：10 ms**
- **P3：140 ms**
- **P4：20 ms**

### （2）
- 时间片由 50 ms 改为 100 ms：**CPU 调度次数减少**
- 时钟中断间隔由 10 ms 改为 1 ms：**系统开销增大**

## 解析

### （1）

题干给出的关键规则有三条：

1. 采用“优先级 + 时间片轮转”调度，且**优先级越大越高**。
2. **仅当发生时钟中断时才触发抢占 CPU 操作**，因此进程在 12 ms、14 ms 到达时，只能先进入就绪队列，不能立刻抢占。
3. 若因时间片用完返回就绪队列，则**优先级减 1**；若因被更高优先级进程抢占返回就绪队列，则**优先级不变**。

先列出初始条件：

| 进程 | 到达时间 | 初始优先级 | CPU 运行时间 |
|---|---:|---:|---:|
| P1 | 10 ms | 3 | 95 ms |
| P2 | 10 ms | 4 | 20 ms |
| P3 | 12 ms | 2 | 40 ms |
| P4 | 14 ms | 5 | 60 ms |

下面按时间线统一推导。

| 时刻 | 发生的事件 | 结论 |
|---|---|---|
| 10 ms | P1、P2 到达；此时发生时钟中断并调度 | 在 P1(3)、P2(4) 中，P2 优先级更高，先调度 **P2** |
| 10～20 ms | P2 运行 10 ms | P2 剩余 10 ms |
| 12 ms | P3 到达 | 仅入就绪队列，不立即抢占 |
| 14 ms | P4 到达 | 仅入就绪队列，不立即抢占 |
| 20 ms | 时钟中断到来，检查是否抢占 | 此时就绪队列中有 P1(3)、P3(2)、P4(5)，运行中的 P2 优先级为 4；P4 优先级更高，所以 **P2 在 20 ms 被抢占**，且优先级保持 4，调度 **P4** |
| 20～70 ms | P4 运行 50 ms | P4 首次时间片为 50 ms，运行后剩余 10 ms |
| 70 ms | 时钟中断 | P4 因时间片用完返回就绪队列，优先级由 5 降为 4。此时候选为 P1(3)、P2(4)、P3(2)、P4(4)。P2 与 P4 同优先级，但 P2 在 10 ms 进入就绪队列，P4 在 14 ms 进入，所以先调度 **P2** |
| 70～80 ms | P2 运行 10 ms | P2 完成 |
| 80 ms | 时钟中断 | P2 完成后重新调度，当前最高优先级为 P4(4)，调度 **P4** |
| 80～90 ms | P4 运行 10 ms | P4 完成 |
| 90 ms | 时钟中断 | P4 完成后，剩余 P1(3)、P3(2)，故调度 **P1** |
| 90～140 ms | P1 运行 50 ms | P1 还需 45 ms |
| 140 ms | 时钟中断 | P1 因时间片用完返回就绪队列，优先级由 3 降为 2。此时 P1(2) 与 P3(2) 同优先级，但 P3 自 12 ms 起就在就绪队列等待，P1 是 140 ms 才重新入队，因此先调度 **P3** |
| 140～180 ms | P3 运行 40 ms | P3 完成 |
| 180 ms | 时钟中断 | 仅剩 P1，调度 **P1** |
| 180～225 ms | P1 运行 45 ms | P1 完成，全部结束 |

据此可直接得到首次调度时刻：

- P2 首次调度：**10 ms**
- P4 首次调度：**20 ms**
- P1 首次调度：**90 ms**
- P3 首次调度：**140 ms**

所以：

- **P1：90 ms**
- **P2：10 ms**
- **P3：140 ms**
- **P4：20 ms**

再看 CPU 调度次数。真正发生调度的时刻是：

$$10,\ 20,\ 70,\ 80,\ 90,\ 140,\ 180\ \text{ms}$$

共 **7 次**。

再看中断次数。按本题的统计口径，从 10 ms 开始，到 220 ms 为止，相关时钟中断时刻为：

$$10,20,30,\dots,220\ \text{ms}$$

这是首项为 10、末项为 220、公差为 10 的等差数列，项数为：

$$\frac{220-10}{10}+1=22$$

因此中断次数为 **22 次**。注意 225 ms 是 P1 完成时刻，但不是时钟中断时刻，所以**不额外计一次中断**。

### （2）

这一问承接前面的调度机制分析即可，不需要重新完整枚举时间线。

时间片由 50 ms 改为 100 ms 时，进程因“时间片用完”而重新进入就绪队列的次数会减少。尤其本题中：

- P2 需要 20 ms
- P3 需要 40 ms
- P4 需要 60 ms
- P1 需要 95 ms

都不超过 100 ms，因此相较于 50 ms 时间片，因时间片到期引发的再次调度会更少，所以 **CPU 调度次数减少**。

时钟中断间隔由 10 ms 改为 1 ms 时，由于题干明确规定“仅当发生时钟中断时才触发抢占 CPU 操作”，那么系统就会更频繁地进行中断处理和调度检查。即使不一定每次都发生进程切换，中断处理本身也会带来额外代价，因此 **系统开销增大**。

## 易错点

1. **把 12 ms、14 ms 的到达误判为立即抢占。**  
   本题明确限制：只有在时钟中断时才会触发抢占，所以 P4 虽然在 14 ms 到达且优先级最高，也必须等到 **20 ms** 才能抢占 P2。

2. **忽略“同优先级时先进入就绪队列者优先”。**  
   - 70 ms 时，P2(4) 与 P4(4) 比较，应选 **P2**。  
   - 140 ms 时，P1(2) 与 P3(2) 比较，应选 **P3**。

3. **把“被抢占返回就绪队列”和“时间片用完返回就绪队列”的优先级变化混淆。**  
   - P2 在 20 ms 被 P4 抢占，优先级**不变**，仍为 4。  
   - P4 在 70 ms、P1 在 140 ms 都是时间片用完，优先级都要**减 1**。

4. **中断次数多算到 225 ms。**  
   225 ms 是进程完成时刻，不是 10 ms 周期上的时钟中断时刻，因此中断总数仍是 **22 次**。
