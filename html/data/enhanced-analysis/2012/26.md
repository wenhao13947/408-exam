## 答案

选 **A：用户级 I/O 软件、设备无关软件、设备驱动程序、中断处理程序**。

## 解析

操作系统的 I/O 子系统按抽象层次从上到下组织时，应遵循一个基本原则：**越靠上越接近用户和通用接口，越靠下越接近具体硬件和硬件细节**。

题目中的四层，合理顺序应为：

1. **用户级 I/O 软件**
2. **设备无关软件**
3. **设备驱动程序**
4. **中断处理程序**

原因如下：

- **用户级 I/O 软件** 位于最上层，直接面向用户程序，负责提供库函数、格式化输入输出等用户可见的 I/O 功能。
- **设备无关软件** 位于其下，负责提供统一的设备访问接口，屏蔽不同设备之间的差异，使上层不必关心具体硬件型号和控制细节。
- **设备驱动程序** 再向下，已经需要针对具体设备类型工作，负责把上层发出的通用 I/O 请求转换成特定设备能够识别和执行的控制操作。
- **中断处理程序** 最接近硬件。设备完成 I/O 后，会向 CPU 发出中断请求，系统首先要由中断处理程序响应和处理这个硬件中断，因此它应处在最底层。

因此，从上到下的正确排列就是：

$$
\text{用户级 I/O 软件} \rightarrow \text{设备无关软件} \rightarrow \text{设备驱动程序} \rightarrow \text{中断处理程序}
$$

这与标准答案 **A** 一致。

## 选项分析

### A. 用户级 I/O 软件、设备无关软件、设备驱动程序、中断处理程序

这是正确顺序。

前两层属于较高层的软件抽象，后两层直接面向硬件；其中中断处理程序在设备完成操作并发出中断后最先响应，因而最靠近硬件，放在最底层合理。

### B. 用户级 I/O 软件、设备无关软件、中断处理程序、设备驱动程序

错误。

该项把**中断处理程序**放在**设备驱动程序**之上。实际上，中断来自硬件，CPU 接收到中断后，首先进入中断处理程序，因此中断处理程序应比设备驱动程序更靠近硬件，位置应更低。

### C. 用户级 I/O 软件、设备驱动程序、设备无关软件、中断处理程序

错误。

该项把**设备驱动程序**放到了**设备无关软件**之上，颠倒了抽象层次。设备无关软件的作用正是向上提供统一接口、向下调用具体驱动，所以它应在设备驱动程序之上，而不是之下。

### D. 用户级 I/O 软件、中断处理程序、设备无关软件、设备驱动程序

错误。

该项把**中断处理程序**放到靠上的位置，这与它“直接响应硬件中断、最接近硬件”的性质不符。中断处理程序应位于整个 I/O 软件层次的最底层附近，不能放在用户级软件之后的高层位置。

## 易错点

1. **把设备驱动程序和中断处理程序的先后放反**  
很多人知道这两层都接近硬件，但容易分不清谁更靠下。判断关键在于：**硬件发出中断后，最先进入的是中断处理程序**，所以它最靠近硬件。

2. **把设备无关软件和设备驱动程序混淆**  
设备无关软件强调“统一接口、屏蔽差异”，属于更高层；设备驱动程序强调“面向具体设备”，属于更低层。只要抓住“通用在上，具体在下”，顺序就不难判断。
