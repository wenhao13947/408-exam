## 答案
选 **C**（仅 I、II、IV）。

## 解析
IP 路由器的核心功能包括 **路由选择** 和 **分组转发**。  
其中，路由选择通常涉及路由协议、路由表的建立与维护、以及路由选择处理机；分组转发则是根据收到的 IP 分组目的地址，把分组送往合适的输出线路。

题干四个说法中：

- **I** 正确。运行路由协议、设置路由表，属于路由器的路由选择功能。
- **II** 正确。路由器监测到拥塞时，可以合理丢弃 IP 分组，并通过 ICMP 发送源点抑制报文。
- **III** 错误。路由器只对 IP 分组首部进行差错校验，且网络层提供的是“尽最大努力交付”，不能保证 IP 分组不丢失。
- **IV** 正确。根据目的 IP 地址转发到合适输出线路，属于分组转发功能。

## 选项分析
- **A**：错误，III 错。
- **B**：错误，III 错。
- **C**：正确，I、II、IV 都成立。
- **D**：错误，III 错。

## 易错点
- “对 IP 分组头进行差错校验”是对的，但“确保 IP 分组不丢失”是错的。
- 拥塞时可丢弃分组，常伴随 ICMP 源点抑制报文。
