## 答案

本题只有同步关系，没有互斥关系。可设置 4 个同步信号量，分别对应 4 个前驱约束，且初值都为 `0`：

- `SAC = 0`：实现 `A` 完成后 `C` 才能执行
- `SBC = 0`：实现 `B` 完成后 `C` 才能执行
- `SCE = 0`：实现 `C` 完成后 `E` 才能执行
- `SDE = 0`：实现 `D` 完成后 `E` 才能执行

相应的 `P/V` 操作描述如下：

```c
semaphore SAC = 0;
semaphore SBC = 0;
semaphore SCE = 0;
semaphore SDE = 0;

A() {
    操作A;
    V(SAC);
}

B() {
    操作B;
    V(SBC);
}

C() {
    P(SAC);
    P(SBC);
    操作C;
    V(SCE);
}

D() {
    操作D;
    V(SDE);
}

E() {
    P(SCE);
    P(SDE);
    操作E;
}
```

## 解析

### 同步关系分析

题目给出两组前驱约束：

- `C` 必须在 `A` 和 `B` 完成后执行；
- `E` 必须在 `C` 和 `D` 完成后执行。

因此，本题只涉及操作之间的先后次序，不涉及对临界资源的互斥访问，所以不需要互斥信号量，只需设置同步信号量。

### 信号量设置及初值

根据题目的前驱关系，可分别设置 4 个信号量：

- `SAC`：实现 `A -> C`
- `SBC`：实现 `B -> C`
- `SCE`：实现 `C -> E`
- `SDE`：实现 `D -> E`

这些信号量的初值均为 `0`。因为在前驱操作尚未完成时，后继操作不应继续执行，所以后继操作先执行 `P` 时应当阻塞等待；待前驱操作完成后，再由前驱操作执行 `V` 发出信号。

### `C` 对 `A`、`B` 的等待关系

为保证 `C` 在 `A`、`B` 都完成后才能执行，应作如下安排：

- `A` 执行完后执行 `V(SAC)`；
- `B` 执行完后执行 `V(SBC)`；
- `C` 执行前先执行 `P(SAC)` 和 `P(SBC)`。

这样，只有当 `A` 和 `B` 都已经完成并分别发出信号后，`C` 才能通过两个 `P` 操作并开始执行。

### `E` 对 `C`、`D` 的等待关系

在前一组同步关系的基础上，`C` 完成后还要为 `E` 提供前驱条件；同时 `D` 也是 `E` 的前驱。因此应作如下安排：

- `C` 执行完后执行 `V(SCE)`；
- `D` 执行完后执行 `V(SDE)`；
- `E` 执行前先执行 `P(SCE)` 和 `P(SDE)`。

这样，只有当 `C` 和 `D` 都完成后，`E` 才能开始执行。

## 易错点

- 误将本题看成互斥问题。题目要求的是前驱关系，属于同步问题。
- 认为 `C` 只需等待 `A`、`B` 中的一个。实际上 `C` 必须在二者都完成后执行，因此需要两个 `P` 操作。
- 同理，`E` 必须等待 `C` 和 `D` 都完成，因此也需要两个 `P` 操作。
- 将同步信号量初值设为 `1`。本题中信号量用于表示“前驱是否完成”，初值应设为 `0`。
