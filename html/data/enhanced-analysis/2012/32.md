## 答案

B

## 解析

题目问的是“不能改善磁盘设备 I/O 性能”的选项。A、C、D 都属于能够减少磁盘访问开销的方法，只有 B“在一个磁盘上设置多个分区”不属于提升单个磁盘设备 I/O 性能的手段，反而主要是逻辑管理方式。

## 选项分析

A. 重排 I/O 请求次序  
可以改善。重排请求次序就是 I/O 调度，能减少磁头移动和平均等待时间，从而降低寻道开销，提高 I/O 性能。

B. 在一个磁盘上设置多个分区  
不能改善。这只是把一个物理磁盘划分成多个逻辑区域，便于管理，但不直接减少寻道时间、旋转延迟或传输时间，因此不能改善磁盘设备 I/O 性能。逻辑分区只改善管理方式，不会直接改善设备 I/O 性能。

C. 预读和滞后写  
可以改善。预读能提前把后续可能访问的数据块读入缓冲区，滞后写能推迟回写，减少不必要的立即磁盘操作，因此有助于提升 I/O 性能。

D. 优化文件物理块的分布  
可以改善。把相关物理块尽量安排得更紧凑，能减少磁头移动距离和寻道时间，从而提高磁盘性能。

## 易错点

这题的关键在于区分“逻辑管理”和“性能优化”。分区本身不是性能优化手段；真正能改善性能的是减少磁盘实际访问次数或减少磁头移动。
