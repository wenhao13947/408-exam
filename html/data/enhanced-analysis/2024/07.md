## 答案

**D. $K_3 < X < K_2$**

理由：在二叉搜索树中，某结点左子树上的关键字都小于该结点，右子树上的关键字都大于该结点。由题图中子树 $T$ 相对于 $K_3$ 和 $K_2$ 的位置，可同时得到 $T$ 中任意结点关键字既大于 $K_3$，又小于 $K_2$。

## 解析

本题直接利用二叉搜索树（Binary Search Tree, BST）的定义即可判断。

二叉搜索树的基本性质是：

- 若某结点关键字为 $K$，则其左子树中所有结点关键字都满足 $X < K$
- 其右子树中所有结点关键字都满足 $X > K$

结合题图的结构关系可知：

- 子树 $T$ 位于结点 $K_2$ 的左侧，因此 $T$ 中任一结点关键字都满足  
  $$
  X < K_2
  $$
- 同时，子树 $T$ 又位于结点 $K_3$ 的右侧，因此 $T$ 中任一结点关键字都满足  
  $$
  X > K_3
  $$

把这两个条件合并，得到：
$$
K_3 < X < K_2
$$

因此正确选项为 **D**。

另外，也可以从中序遍历角度辅助理解：二叉搜索树的中序遍历结果是按关键字递增排列的，因此题图中相关结点与子树在中序序列中的相对位置，也会支持 $K_3 < X < K_2$ 这一结论。

## 选项分析

A. $X < K_1$  
错误。题目能确定的是 $X$ 与 $K_3$、$K_2$ 的夹逼关系，即 $K_3 < X < K_2$，不能推出对所有 $X$ 都有 $X < K_1$。

B. $X > K_2$  
错误。因为 $T$ 是 $K_2$ 的左子树范围内的部分结点，所以应有 $X < K_2$，而不是 $X > K_2$。

C. $K_1 < X < K_3$  
错误。由题图位置关系可知，$T$ 中结点应在 $K_3$ 的右侧，因此应满足 $X > K_3$，不可能是 $X < K_3$。

D. $K_3 < X < K_2$  
正确。它同时准确反映了 $T$ 相对 $K_3$ 和 $K_2$ 的位置关系，符合二叉搜索树性质。

## 易错点

- 不要只看某一个结点关系就下结论。本题必须同时利用“在 $K_2$ 的左侧”和“在 $K_3$ 的右侧”这两个条件。
- 二叉搜索树题目里，子树中“任一结点”通常要用范围夹住，最终常写成  
  $$
  a < X < b
  $$
  这种双边不等式。
- 中序遍历递增是辅助判断手段，但本题用二叉搜索树的左右子树性质直接推导更稳妥。
