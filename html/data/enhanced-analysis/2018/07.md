## 答案
D。拓扑序列要求每条有向边的起点必须排在终点之前，`5, 2, 1, 6, 3, 4` 违反了顶点 `1 -> 2` 的先后关系。

## 解析
拓扑排序的基本规则是：每次只能输出当前入度为 `0` 的顶点，输出后删去该顶点发出的所有边。

对本题的判断关键在于：
- 顶点 `5` 的入度为 `0`，所以它可以作为拓扑序列的第一个顶点。
- 但在 `5` 输出并删边之后，下一步不能直接输出 `2`，因为顶点 `1` 指向顶点 `2`，说明 `2` 还有前驱 `1`，必须等 `1` 先输出后，`2` 的入度才可能变成 `0`。
- 因此，任何合法拓扑序列都必须满足 `1` 在 `2` 前面。

而 D 选项是 `5, 2, 1, 6, 3, 4`，把 `2` 放在 `1` 前面，违反了拓扑序列的约束，所以不是该有向图的拓扑序列。

## 选项分析
- A. `1, 5, 2, 3, 6, 4`：正确。`1` 和 `5` 都可以先输出，之后 `2`、`3`、`6`、`4` 的顺序也满足依赖关系。
- B. `5, 1, 2, 6, 3, 4`：正确。先输出 `5` 再输出 `1`，随后 `2` 才可变为入度 `0`，整体顺序合法。
- C. `5, 1, 2, 3, 6, 4`：正确。满足所有边的先后约束。
- D. `5, 2, 1, 6, 3, 4`：错误。`2` 不能排在 `1` 前面，因为存在有向边 `1 -> 2`。

## 易错点
- 拓扑序列不是“任意入度为 `0` 的点都能随便排”，而是必须始终满足所有前驱都已出现。
- 只要发现某个序列中存在一条边 `u -> v`，但 `v` 出现在 `u` 前面，就能直接判错。
