## 答案

B。正确顺序是 **②→③→①→④**，因为 DMA 传输时一定先由 CPU 初始化 DMA 控制器并启动磁盘，随后完成数据块传送，传送结束后 DMA 控制器才会发出中断请求，最后 CPU 执行“DMA 结束”中断服务程序。

## 解析

本题考查 **DMA 方式下磁盘到内存的数据传送流程**。

DMA 传输的核心特点是：**CPU 只负责启动和收尾，数据传送过程由 DMA 控制器直接完成**。据此可按时间顺序判断：

先看 **② 初始化 DMA 控制器并启动磁盘**。  
这是整个 DMA 传输的前提。CPU 必须先设置好 DMA 的有关参数，例如：

- 数据从哪个设备读取
- 数据写入哪个内存缓冲区
- 传送的起始地址
- 传送的数据长度或块数

同时还要启动 I/O 设备，这里题目中是 **磁盘**。如果这一步不先发生，后续的数据传送和中断都无从谈起。

接着是 **③ 从磁盘传输一块数据到内存缓冲区**。  
DMA 控制器在得到 CPU 的初始化信息后，按照指定要求控制数据传送，把磁盘中的数据块直接送入内存缓冲区。这个阶段是 DMA 的主体工作过程。

然后是 **① DMA 控制器发出中断请求**。  
只有当所要求的数据传送完成后，DMA 控制器才会向 CPU 报告“传送结束”，因此中断请求一定发生在数据传输之后，而不可能早于传输。

最后是 **④ 执行“DMA 结束”中断服务程序**。  
CPU 收到并响应中断请求后，才会进入相应的中断服务程序，对 DMA 结束进行后续处理。因此中断服务程序必然排在中断请求之后。

所以正确顺序为：

$$
② 
\rightarrow ③ 
\rightarrow ① 
\rightarrow ④
$$

对应选项 **B**。

## 选项分析

A. **③→①→②→④**  
错误。数据传输和中断请求都不可能发生在 DMA 初始化之前；必须先由 CPU 完成 DMA 控制器初始化并启动磁盘。

B. **②→③→①→④**  
正确。完全符合 DMA 的标准流程：先初始化并启动设备，再传输数据，传输结束后发中断，最后执行中断服务程序。

C. **②→①→③→④**  
错误。DMA 控制器不会在数据尚未完成传输时就先发出“结束中断请求”；中断请求应在传输结束之后。

D. **①→②→④→③**  
错误。中断请求不可能先于初始化发生；而且中断服务程序也不可能早于实际数据传输完成。

## 易错点

- 容易把 **CPU 的启动作用** 和 **DMA 控制器的传送作用** 混淆。CPU 不直接搬运这批数据，它主要负责初始化、启动和处理中断。
- 要分清 **“发出中断请求”** 与 **“执行中断服务程序”** 的先后关系：一定是先有中断请求，再有 CPU 响应并执行中断服务程序。
- 判断此类题时，可抓住 DMA 的固定流程：**初始化设备与控制器 → 数据传送 → 传送结束中断 → 中断处理**。
