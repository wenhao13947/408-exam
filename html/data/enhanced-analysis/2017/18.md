## 答案

**B**。错误原因是：主存储器（MM）按地址访问，而控制存储器（CS）也按地址访问，并不是按内容访问。

## 解析

题目考查的是主存储器与控制存储器在**位置、用途、访问方式、实现介质**上的基本区别。

主存储器是计算机用来存放**程序指令和数据**的存储器，属于 CPU 外部的存储系统。控制存储器则用于存放**微指令**，是微程序控制器的一部分，因此位于 CPU 内部的控制器中。

本题关键在于区分“按地址访问”和“按内容访问”：

- **主存储器**显然是按地址访问的，CPU 给出主存地址后读取相应单元内容。
- **控制存储器**中存放的是一条条微指令，下一条微指令也需要根据其地址取出。微程序控制中通常由 **$\mu PC$**（微地址寄存器，microprogram counter）给出下一条微指令在控制存储器中的地址，因此控制存储器本质上也是**按地址访问**的。

而“按内容访问”对应的是**相联存储器（Associative Memory / CAM）**的访问方式，即根据内容匹配来定位存储单元。典型例子是 **TLB**。因此把 CS 说成“按内容访问”是错误的。

## 选项分析

**A. MM 在 CPU 外，CS 在 CPU 内**

正确。  
主存储器属于 CPU 外部存储层次中的主存部分；控制存储器属于微程序控制器，而微程序控制器属于 CPU 的控制器部分，所以 CS 在 CPU 内。

**B. MM 按地址访问，CS 按内容访问**

错误。  
MM 按地址访问没有问题，但 CS 也不是按内容访问。CS 中微指令的读取依赖微地址，即由 **$\mu PC$** 指出下一条微指令地址，再到控制存储器中取出，因此 CS 也是按地址访问。

**C. MM 存储指令和数据，CS 存储微指令**

正确。  
主存储器用于保存程序执行所需的指令和数据；控制存储器用于保存实现指令系统控制过程所需的微指令。

**D. MM 用 RAM 和 ROM 实现，CS 用 ROM 实现**

正确。  
主存储器通常主要由 **RAM** 构成，但也可包含 **ROM** 区域，例如保存 **BIOS** 等固化程序。控制存储器要求断电后内容不丢失，传统上通常用 **ROM** 实现，因此该项表述成立。

## 易错点

- 容易把“控制存储器”误认为特殊到必须“按内容访问”。实际上，只要是根据微地址取微指令，本质就是**按地址访问**。
- 要区分：
  - **主存 / 控存**：按地址访问；
  - **相联存储器**：按内容访问。
- 看到“按内容访问”时，优先联想到 **CAM**、**TLB**，而不是控制存储器。
