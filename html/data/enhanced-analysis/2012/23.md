## 答案
C

## 解析
题目问的是“**不可能在用户态发生**”的事件。关键在“发生”的时机，不是看事件处理过程是否会进入内核态。

A“系统调用”：系统调用请求可以由用户程序在用户态发起，随后操作系统进入内核态完成处理，所以它可以在用户态发生。

B“外部中断”：外部中断信号可以在程序处于用户态时到来，之后 CPU 再转入内核态处理中断，因此也可以在用户态发生。

D“缺页”：进程在用户态访问到不在内存中的页面时，会触发缺页异常，随后进入内核态处理，所以缺页也可以在用户态发生。

C“进程切换”：这是进程管理活动，属于操作系统内核功能，只能在内核态完成，不可能在用户态发生。这一判断是正确的。

## 选项分析
A. 系统调用：可以在用户态发起，随后切换到内核态执行相关服务，所以不是“不可能在用户态发生”。

B. 外部中断：中断请求可以在用户态执行期间到来，处理时才进入内核态，所以也不是“不可能在用户态发生”。

C. 进程切换：属于内核进行的调度与上下文切换，只能在内核态完成，符合题意，选 C。

D. 缺页：用户态访问内存时可能触发缺页异常，处理过程进入内核态，但事件本身可以在用户态发生，所以不选。

## 易错点
容易把“事件发生”误看成“事件处理在用户态完成”。这道题考的是触发时机：系统调用、外部中断、缺页都可能在用户态程序运行时出现；只有进程切换不可能在用户态发生。
