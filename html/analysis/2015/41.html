1）算法的基本设计思想

使用一个大小为 n+1 的辅助数组 seen，记录绝对值 0～n 是否已经出现。顺序扫描单链表：若 seen[abs(data)] 为 0，则保留当前结点并将该位置记为 1；否则删除当前结点。这样只需扫描链表一次。

2）单链表结点的数据类型定义

typedef struct ListNode {
    int data;
    struct ListNode *next;
} ListNode;

3）算法实现

void RemoveElements(ListNode *head, int n) {
    int *seen = (int *)calloc(n + 1, sizeof(int));
    ListNode *previous = head;
    ListNode *current = head->next;

    while (current != NULL) {
        int index = abs(current->data);
        if (seen[index]) {
            ListNode *deleted = current;
            previous->next = current->next;
            current = previous->next;
            free(deleted);
        } else {
            seen[index] = 1;
            previous = current;
            current = current->next;
        }
    }
    free(seen);
}

代码中统一使用 next 作为后继指针字段。previous 始终指向 current 的前驱结点，因此删除 current 后不需要重新遍历链表。

4）复杂度分析

初始化辅助数组需要 O(n) 时间，扫描 m 个链表结点需要 O(m) 时间，因此严格计算的总时间复杂度为 O(m+n)；若按辅助数组已完成初始化的口径，只计链表扫描过程，则为 O(m)。辅助空间复杂度为 O(n)。
