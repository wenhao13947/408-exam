## 答案

选 **C**。后序遍历序列是：**e, f, d, c, b, g, a**。

## 解析

先由层序遍历确定根结点。层序序列首元素是 `a`，所以根是 `a`。

> **核心方法**：用层序序列确定当前根，再用中序序列划分左、右子树，递归恢复整棵树。

再看中序遍历 `b, e, d, f, c, a, g`，`a` 左边的 `b, e, d, f, c` 属于左子树，右边的 `g` 属于右子树。右子树只有一个结点 `g`，所以右子树后序就是 `g`。

左子树的层序可从原层序 `a, b, g, c, d, e, f` 中去掉根 `a` 和右子树结点 `g`，得到 `b, c, d, e, f`。  
左子树中序是 `b, e, d, f, c`，因此左子树根是 `b`。`b` 在中序中位于首位，说明它没有左子树，右子树继续看 `c`。

对以 `c` 为根的子树，中序为 `e, d, f, c`，所以 `c` 没有右子树，左子树根是 `d`。  
对以 `d` 为根的子树，中序为 `e, d, f`，可知 `d` 的左孩子是 `e`，右孩子是 `f`。

所以整棵树结构是：

- `a` 的左子树根为 `b`，右子树为 `g`
- `b` 只有右子树 `c`
- `c` 只有左子树 `d`
- `d` 的左孩子是 `e`，右孩子是 `f`

按后序遍历“左子树 - 右子树 - 根”：

- `d` 的后序是 `e, f, d`
- `c` 的后序是 `e, f, d, c`
- `b` 的后序是 `e, f, d, c, b`
- 整棵树后序是 `e, f, d, c, b, g, a`

## 选项分析

A. `c, e, d, f, b, g, a`  
`c` 被放到了 `b` 之前，不符合左子树 `b -> c -> d` 的后序结构，错误。

B. `c, e, f, d, b, g, a`  
同样把 `c` 放在了最前面，且 `d` 的左右子树顺序也不对，错误。

C. `e, f, d, c, b, g, a`  
与上面推得的后序遍历完全一致，正确。

D. `e, g, f, d, b, c, a`  
`g` 属于 `a` 的右子树，不应出现在左子树后序中间，错误。

## 易错点

这题的关键不是直接“猜树形”，而是先用层序定根，再用中序切左右子树，并在每个子树上继续递归恢复。按递归恢复得到的后序序列为 `e, f, d, c, b, g, a`。
