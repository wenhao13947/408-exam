## 答案
C。各顶点度都不小于 2 的无向图一定含有回路。

## 解析
先判断题干四个命题的真假。

A 说“有向图必定存在入度为 0 的顶点”是错的。只要构成有向环，环上每个顶点至少都有一个前驱顶点，图中就可能不存在入度为 0 的顶点。

B 说“有向无环图的拓扑排序有序序列存在且唯一”也是错的。DAG 的拓扑序一定存在，但不一定唯一；当有多个当前入度为 0、且彼此没有依赖关系的顶点时，它们的先后顺序可以互换，因此会得到多个拓扑序列。

C 说“各顶点的度均大于等于 2 的无向图必有回路”正确。无向图中若每个顶点度都至少为 2，从任一顶点出发沿边继续走，不可能一直不重复顶点；一旦走到已访问过的顶点，就形成回路。所以该条件能保证图中至少存在一个回路，但不能推出图一定连通。

D 说“可用 BFS 算法求出带权图中的每一对顶点的最短路径”不严谨，因此错误。BFS 本质上按层扩展，只适合无权图，或者边权完全一致、可以把“层数”直接对应为路径代价的情况。若带权图中边权不一致，BFS 不能保证得到最短路径；这类问题通常应使用 Dijkstra 或 Floyd。

## 选项分析
A. 错  
有向环图中不一定存在入度为 0 的顶点。

B. 错  
拓扑排序存在，但不唯一。

C. 对  
无向图若所有顶点度都 $\ge 2$，则必有回路。

D. 错  
BFS 不能直接处理一般带权图的最短路径问题。

## 易错点
- “有回路”不等于“连通”。
- 拓扑排序“存在”不代表“唯一”。
- BFS 只能直接用于无权图或等权图的最短路径。
