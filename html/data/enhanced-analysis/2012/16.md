## 答案

**A**。错误原因是：Flash Memory 虽然既可读也可写，但其**写入速度明显慢于读取速度**，不能认为“读、写速度一样快”。

## 解析

Flash Memory（闪存）本质上属于**非易失性半导体存储器**，可看作是 EEPROM 的进一步发展。它用 MOS 管中的浮栅是否带电来表示信息，因此断电后数据仍可保留。

本题判断关键在于区分“**可读可写**”和“**读写性能相同**”这两个概念。闪存确实支持读和写，但写入前通常需要先进行擦除，而擦除和写入过程都比读取复杂，所以**写速度通常比读速度慢得多**。因此，A 把“可读可写”错误地进一步表述成“读、写速度一样快”，这一点不符合闪存的实际工作特点。

其余几个表述都符合闪存的一般性质：

- 闪存的存储单元由 **MOS** 管构成，属于**半导体存储器**；
- 闪存断电后信息不丢失，属于**非易失性存储器**；
- 闪存可按地址进行访问，属于**随机访问**存储器件，并且已广泛用于 **SSD**、U 盘、存储卡等设备中，因此可以作为外部存储器的实现基础。

所以，错误项只能是 **A**。

## 选项分析

**A. 信息可读可写，并且读、写速度一样快**  
错误。前半句“可读可写”正确，后半句错误。闪存写入通常涉及擦除操作，写速度显著慢于读速度。

**B. 存储元由 MOS 管组成，是一种半导体存储器**  
正确。闪存采用 MOS 管存储信息，本质上属于半导体存储器。

**C. 掉电后信息不丢失，是一种非易失性存储器**  
正确。闪存断电后仍可保存数据，这是其典型特征。

**D. 采用随机访问方式，可替代计算机外部存储器**  
正确。闪存可按地址随机访问，且现实中大量用于外存设备，如 SSD、U 盘等。

## 易错点

- 容易把“**可读可写**”误认为“**读写性能相当**”。是否能写入，和写入速度是否快，是两个不同判断点。
- 容易把“闪存属于 ROM 一类的非易失存储器”与“不能写”混淆。这里的 ROM 是按**断电后是否保留数据**及传统分类来理解，不表示它完全不能改写。
- “可替代外部存储器”并不是说它一定直接等同于传统磁盘，而是说它**能够作为外存介质使用**。
