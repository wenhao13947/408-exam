## 答案

**D．仅Ⅰ、Ⅲ、Ⅳ。**

多道程序系统的核心优点是：当某个作业因等待 I/O 而不能继续运行时，CPU 可以转去执行其他作业，因此通常能提高 **CPU 利用率**、**系统吞吐量** 和 **I/O 设备利用率**；但为实现这种并发推进，系统管理开销反而会增加，所以Ⅱ错误。

## 解析

判断这题的关键，是抓住单道程序系统与多道程序系统的本质区别。

单道程序系统中，内存里通常只装入一道作业，作业之间串行执行。若当前作业发出 I/O 请求并进入等待状态，那么 CPU 往往只能空闲等待，直到该作业的 I/O 完成后再继续执行。这样会造成 CPU 和 I/O 设备在时间上难以充分重叠，资源利用率偏低。

多道程序系统中，内存中可同时驻留多道作业。一个作业等待 I/O 时，CPU 可以切换去执行另一个已就绪作业，使 CPU 与 I/O 更容易并行工作，从而带来以下结果：

- CPU 空闲时间减少，故 **CPU 利用率提高**；
- 同一段时间内完成的作业数更多，故 **系统吞吐量增大**；
- I/O 等待与其他作业的计算过程可以交错，故 **I/O 设备利用率提高**。

但另一方面，多道程序系统为了让多道作业并发推进，需要额外进行进程管理、内存管理、调度与切换等工作，因此 **系统开销不会变小，而是会增大**。

可以用题中讲解的例子直观验证：

设两个作业几乎同时到达，每个作业的执行过程都是：

$$
CPU\,5ms 
\rightarrow I/O\,5ms 
\rightarrow CPU\,5ms 
\rightarrow I/O\,5ms
$$

### 单道程序系统

先执行 A，A 全部完成后再执行 B。  
总耗时为：

$$
40ms
$$

CPU 实际工作时间为两个作业的 CPU 时间总和：

$$
20ms
$$

因此 CPU 利用率为：

$$
\frac{20}{40}=50\%
$$

I/O 设备总工作时间也是：

$$
20ms
$$

所以 I/O 设备利用率为：

$$
\frac{20}{40}=50\%
$$

### 多道程序系统

A 等待 I/O 时，CPU 可去执行 B，二者交替推进。  
总耗时缩短为：

$$
25ms
$$

CPU 工作时间仍为：

$$
20ms
$$

因此 CPU 利用率为：

$$
\frac{20}{25}=80\%
$$

I/O 设备利用率同理也提高到：

$$
80\%
$$

而吞吐量可理解为单位时间内完成的作业数。两种情况下都完成 2 个作业，但多道程序系统耗时更短，因此吞吐量更大。

## 选项分析

Ⅰ. **CPU 利用率高**  
正确。多道程序系统能在一个作业等待 I/O 时调度另一个作业运行，减少 CPU 空等时间。

Ⅱ. **系统开销小**  
错误。多道程序系统需要更多的调度、切换、内存与进程管理，系统开销通常是增大的，不是减小。

Ⅲ. **系统吞吐量大**  
正确。吞吐量表示单位时间内完成的作业数量。多道程序系统由于资源重叠使用更充分，完成同样数量作业所需时间更短，因此吞吐量更大。

Ⅳ. **I/O 设备利用率高**  
正确。多道程序系统中，多个作业的计算与 I/O 可交错进行，I/O 设备空闲时间减少，利用率提高。

## 易错点

- 容易把“多道程序系统效率高”误写成“系统开销小”。这两者不是一回事：**资源利用率和吞吐量提高**，并不意味着 **管理开销降低**。
- 要区分“利用率高”和“开销小”：
  - 利用率高：资源更少空闲；
  - 开销小：系统为管理这些资源额外付出的代价更少。  
  多道程序系统通常是前者成立、后者不成立。
