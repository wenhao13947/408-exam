## 答案

### （1）
先使两个子集的元素个数尽量接近，即令一个子集含有 $\lfloor n/2 \rfloor$ 个元素，另一个子集含有 $\lceil n/2 \rceil$ 个元素，这样可保证 $|n_1-n_2|$ 最小。

在此前提下，要使 $|S_1-S_2|$ 最大，应将较小的 $\lfloor n/2 \rfloor$ 个元素划入一个子集 $A_1$，其余较大的元素划入另一个子集 $A_2$。因为题中元素全为正整数，固定元素个数后，把小数集中在一组、大数集中在另一组，才能使两组元素和之差最大。

实现时不必对全部元素排序，只需用类似快速选择的方法，找到划分位置，使前 $\lfloor n/2 \rfloor$ 个元素恰为最小的 $\lfloor n/2 \rfloor$ 个元素即可。

### （2）
可用基于快速排序划分思想的快速选择算法实现：

```cpp
int partition(int a[], int low, int high) {
    int pivot = a[low];
    int i = low, j = high;
    while (i < j) {
        while (i < j && a[j] >= pivot) j--;
        a[i] = a[j];
        while (i < j && a[i] <= pivot) i++;
        a[j] = a[i];
    }
    a[i] = pivot;
    return i;   // 返回枢轴最终位置
}

// 在 a[low..high] 中调整，使下标 k 左边恰有 k-low 个不大于它的元素
void quickSelect(int a[], int low, int high, int k) {
    if (low < high) {
        int pivotPos = partition(a, low, high);
        if (pivotPos == k)
            return;
        else if (pivotPos > k)
            quickSelect(a, low, pivotPos - 1, k);
        else
            quickSelect(a, pivotPos + 1, high, k);
    }
}

int solve(int a[], int n) {
    int m = n / 2;   // m = floor(n/2)

    // 调整后，a[0..m-1] 为最小的 m 个元素，a[m..n-1] 为其余元素
    quickSelect(a, 0, n - 1, m - 1);

    int S1 = 0, S2 = 0;
    for (int i = 0; i < m; i++)
        S1 += a[i];
    for (int i = m; i < n; i++)
        S2 += a[i];

    return S2 - S1;
}
```

### （3）
该算法基于快速选择，不需要对全部元素进行全排序。

平均时间复杂度为 $O(n)$，空间复杂度按本题评分口径为 $O(1)$。

## 解析

### 解法一：暴力法

枚举所有满足人数差最小的划分方案，逐一计算两组元素和之差并取最大值。该方法至少需要枚举组合数 $\binom{n}{\lfloor n/2\rfloor}$，时间复杂度为指数级，只适合说明问题定义或处理极小规模数据。

### 解法二：优化解法

先确定两组人数只能分别为 $\lfloor n/2\rfloor$ 和 $\lceil n/2\rceil$，再利用“小元素放一组、大元素放另一组”使和之差最大；通过排序或选择算法确定分界。

> **考场建议：** 可以先用暴力枚举说明比较目标，但题目明确要求尽可能高效，正式答案必须进一步利用人数约束和有序分割完成优化。

### （1）
题目有两个目标，且有先后次序：

1. 先使 $|n_1-n_2|$ 最小；
2. 再在此前提下使 $|S_1-S_2|$ 最大。

先看第一个目标。由于 $n_1+n_2=n$，所以：

- 当 $n$ 为偶数时，只能取 $n_1=n_2=n/2$；
- 当 $n$ 为奇数时，只能取 $n_1=\lfloor n/2 \rfloor,\ n_2=\lceil n/2 \rceil$ 或反过来。

因此，满足第一个目标的划分方式已经确定为“两个子集元素个数尽量均分”。

再看第二个目标。设较小的一组取 $\lfloor n/2 \rfloor$ 个元素。因为所有元素都是正整数，若想让两组元素和之差尽量大，就应当：

- 让一个子集尽量由小元素组成；
- 让另一个子集尽量由大元素组成。

所以，应把最小的 $\lfloor n/2 \rfloor$ 个元素划入 $A_1$，其余元素划入 $A_2$。这样有：

- $|n_1-n_2|$ 最小；
- 且 $S_2-S_1$ 最大，从而 $|S_1-S_2|$ 最大。

这一步就是本题的核心结论。

进一步看实现方式。题目只要求完成划分，并不要求所有元素完全有序，所以没有必要做全排序。只需找到一个分界位置，使得：

- 前 $\lfloor n/2 \rfloor$ 个元素都是较小的那些数；
- 后面的元素都是较大的那些数。

这正适合用快速选择。其思路与快速排序中的一次划分类似：任选一个枢轴，完成一趟划分后，枢轴左边元素都不大于它，右边元素都不小于它。然后只在包含目标分界位置的一侧继续处理即可。若采用上述划分思路时，这里只需关注“分界位置是否已经落在 $\lfloor n/2 \rfloor$ 附近”。

### （2）
`partition` 的作用是对区间 `a[low..high]` 做一趟划分。划分完成后，返回枢轴最终位置 `pivotPos`，并满足：

- `a[low..pivotPos-1] <= a[pivotPos]`
- `a[pivotPos+1..high] >= a[pivotPos]`

然后在 `quickSelect` 中分三种情况：

- 若 `pivotPos == k`，说明目标位置已经确定，停止；
- 若 `pivotPos > k`，目标元素在左半部分，只处理左半部分；
- 若 `pivotPos < k`，目标元素在右半部分，只处理右半部分。

本题要让前 $\lfloor n/2 \rfloor$ 个元素成为最小的那一批，因此若记 $m=\lfloor n/2 \rfloor$，则应把第 $m$ 小元素之前的位置调整好。用数组下标表示，前一组的最后一个位置是 `m-1`，所以调用应统一为 `quickSelect(a, 0, n-1, m-1)`。

分组边界统一按“前 $\lfloor n/2 \rfloor$ 个元素属于较小子集”处理，选择位置和后续求和必须使用同一套下标口径。

调整完成后：

- `a[0..m-1]` 构成 $A_1$，其元素个数为 $\lfloor n/2 \rfloor$；
- `a[m..n-1]` 构成 $A_2$，其元素个数为 $\lceil n/2 \rceil$。

再分别求和即可得到 $S_1$ 和 $S_2$，最后返回 $S_2-S_1$。由于前一组全是较小元素，后一组全是较大元素，因此这里一定有 $S_2 \ge S_1$。

### （3）
该算法不做全排序，只做选择划分。

每次划分后只递归进入一侧区间，因此其平均时间复杂度为

$$
O(n)
$$

空间方面，按本题评分口径，采用原地划分，辅助空间复杂度记为

$$
O(1)
$$

## 易错点

1. 先后目标不能颠倒  
   本题不是单纯让两组和差最大，而是先要求 $|n_1-n_2|$ 最小，再在此前提下使 $|S_1-S_2|$ 最大。元素个数必须先尽量均分。

2. 不需要全排序  
   只要确定前 $\lfloor n/2 \rfloor$ 个元素是最小的那一批即可，因此用快速选择比完全排序更合适。

3. 奇数个元素时的分组规模  
   当 $n$ 为奇数时，两组元素个数应为 $\lfloor n/2 \rfloor$ 和 $\lceil n/2 \rceil$，此时 $|n_1-n_2|=1$，已经是最小值。

4. 实现时要补齐 `return` 分号、统一函数返回类型，并明确分界下标，保证代码可执行。
