## 答案
错误的是 **B**。程序的 CPI 与 Cache 缺失率有关，Cache 缺失会增加访问延迟并抬高 CPI。

## 解析
CPI（`Clock Cycle Per Instruction`）表示执行一条指令平均需要的时钟周期数。不同类型指令的复杂度不同，所需周期数可能不同，因此 CPI 不一定相同。

Cache 缺失时，需要进行缺失处理，把缺失数据从主存调入 Cache。这个过程会让指令等待更久，访存延迟增加，执行所需时钟周期随之增多，因此程序的 CPI 会受到 Cache 缺失率影响，不可能“无关”。

单周期 CPU 要求所有指令都在一个时钟周期内完成，所以时钟周期必须按最耗时、最慢的指令来定，保证最慢指令也能在一个周期内结束。

流水线 CPU 中，指令被分成多个流水段，各段耗时不同。为了保证每个流水段都能在一个周期内完成，时钟周期通常按最长流水段的耗时确定。

## 选项分析
A. 正确。不同类型指令复杂度不同，CPI 可能不同。

B. 错误。Cache 缺失率上升会增加等待主存数据返回的时间，从而增加 CPI。

C. 正确。单周期 CPU 的时钟周期以最耗时指令所用时间为准。

D. 正确。流水线 CPU 的时钟周期以最长流水段所用时间为准。

## 易错点
本题关键是区分“平均执行周期数”与“时钟周期设计基准”：
- CPI 受指令类型和 Cache 缺失等因素影响；
- 单周期 CPU 看的是最慢指令；
- 流水线 CPU 看的是最长流水段。
