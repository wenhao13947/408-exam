## 答案

需要设置 4 个信号量：

- `mutex = 1`：实现甲、乙对铁锹的互斥使用
- `pits = 3`：表示甲当前还允许再挖的坑数，用于保证“未被乙处理的坑”最多为 3 个
- `empty = 0`：表示已挖好、可供乙使用的树坑数量
- `water = 0`：表示乙已完成放树苗并填土、等待丙浇水的树苗数量

相应的 `wait()`、`signal()` 描述如下：

```c
semaphore mutex = 1;
semaphore pits = 3;
semaphore empty = 0;
semaphore water = 0;

甲() {
    while (1) {
        wait(pits);
        wait(mutex);
        挖树坑;
        signal(mutex);
        signal(empty);
    }
}

乙() {
    while (1) {
        wait(empty);
        wait(mutex);
        放树苗、填土;
        signal(mutex);
        signal(pits);
        signal(water);
    }
}

丙() {
    while (1) {
        wait(water);
        浇水;
    }
}
```

## 解析

### （1）信号量设置及初值

题目中的约束有三类：

| 约束类型 | 题目条件 | 所需信号量 |
|---|---|---|
| 前驱同步 | 甲挖坑后，乙才能放树苗并填土 | `empty` |
| 前驱同步 | 乙放树苗并填土后，丙才能浇水 | `water` |
| 互斥 | 铁锹只有 1 把，甲挖坑和乙填土都要用 | `mutex` |
| 数量约束 | 当树坑数量小于 3 时，甲才可继续挖坑 | `pits` |

因此最少需要 4 个信号量，分别如下。

1. `mutex = 1`  
   铁锹初始可用，故互斥信号量初值为 1。甲挖坑与乙填土都必须先申请它，用完后释放。

2. `empty = 0`  
   初始时没有已挖好的坑，所以乙一开始不能执行“放树苗、填土”，故初值为 0。

3. `water = 0`  
   初始时没有完成填土、等待浇水的树苗，所以丙一开始也不能浇水，故初值为 0。

4. `pits = 3`  
   这里 `pits` 表示“甲还能再挖几个坑的名额”。  
   初始时允许最多存在 3 个未被乙处理的坑，所以初值为 3。  
   甲每挖 1 个坑，就先执行一次 `wait(pits)`；乙每处理完 1 个坑，就执行一次 `signal(pits)`，把这个名额还给甲。

### （2）P、V 操作的含义与过程

#### 甲进程

甲负责挖坑，但有两个限制：

- 必须满足“未被乙处理的坑数不超过 3”，所以先执行 `wait(pits)`
- 挖坑要用铁锹，所以再执行 `wait(mutex)`

挖完后：

- `signal(mutex)`：释放铁锹
- `signal(empty)`：通知乙“现在有一个可用的坑了”

因此甲的代码为：

```c
while (1) {
    wait(pits);
    wait(mutex);
    挖树坑;
    signal(mutex);
    signal(empty);
}
```

#### 乙进程

乙执行“放树苗、填土”，也有两个前提：

- 必须先有坑，所以先执行 `wait(empty)`
- 填土要用铁锹，所以再执行 `wait(mutex)`

乙完成后：

- `signal(mutex)`：释放铁锹
- `signal(pits)`：说明这个坑已经被处理，甲又可以多挖 1 个坑
- `signal(water)`：通知丙可以对这棵树苗浇水了

因此乙的代码为：

```c
while (1) {
    wait(empty);
    wait(mutex);
    放树苗、填土;
    signal(mutex);
    signal(pits);
    signal(water);
}
```

#### 丙进程

丙只负责浇水，不与其他人竞争铁锹。题目虽然说水桶只有 1 个，但只有丙使用水桶，因此不需要额外为水桶设置互斥信号量。

丙必须等乙完成“放树苗、填土”后才能浇水，所以执行：

```c
while (1) {
    wait(water);
    浇水;
}
```

## 易错点

1. 容易漏掉 `pits`  
   `empty` 只能保证“乙必须等甲挖好坑”，但不能限制“最多只能积累 3 个未处理的坑”。  
   题目中的“当树坑数量小于 3 时，甲才可以挖树坑”必须单独用一个计数信号量控制。

2. 容易把水桶也设成互斥量  
   本题不需要。因为只有丙使用水桶，不存在多个并发进程竞争水桶的问题。

3. 容易忘记甲、乙对铁锹互斥  
   甲挖坑和乙填土都要用铁锹，所以必须设置 `mutex = 1`。

4. 同步对象不要写错  
   `water` 用于乙和丙之间的同步：乙完成“放树苗、填土”后执行 `signal(water)`，丙执行 `wait(water)` 后浇水。  
   作答时应准确写出 `mutex、pits、empty、water` 这 4 个信号量及其作用、初值和上述 PV 过程。
