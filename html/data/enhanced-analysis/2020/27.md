## 答案
选 **B**，存在安全序列 **P2 → P1 → P3**。

## 解析
这是典型的银行家算法安全性检查题。先由题表计算 `Need = Max - Allocation`，再结合当前 `Available` 判断能否找到安全序列。

题中各进程数据为：

- `P1`：`Allocation = (2,3)`，`Max = (4,4)`，所以 `Need = (2,1)`
- `P2`：`Allocation = (2,1)`，`Max = (3,1)`，所以 `Need = (1,0)`
- `P3`：`Allocation = (1,2)`，`Max = (3,4)`，所以 `Need = (2,2)`

系统中 A、B 两类资源各 6 个，当前已分配总量为：

- A：`2 + 2 + 1 = 5`，所以 `Available(A) = 6 - 5 = 1`
- B：`3 + 1 + 2 = 6`，所以 `Available(B) = 6 - 6 = 0`

因此初始 `Available = (1,0)`。

此时比较各进程的 `Need`：

- `P2` 的 `Need = (1,0)`，满足
- `P1` 的 `Need = (2,1)`，不满足
- `P3` 的 `Need = (2,2)`，不满足

所以先执行 `P2`。`P2` 完成后释放其占有资源 `(2,1)`，新的 `Available` 变为：

$$
(1,0) + (2,1) = (3,1)
$$

这时：

- `P1` 的 `Need = (2,1)`，满足
- `P3` 的 `Need = (2,2)`，仍不满足

所以再执行 `P1`。`P1` 完成后释放 `(2,3)`，新的 `Available` 变为：

$$
(3,1) + (2,3) = (5,4)
$$

此时 `P3` 的 `Need = (2,2)` 也满足，因此最后执行 `P3` 即可。

故安全序列为 **P2 → P1 → P3**，选 **B**。

## 选项分析
- A：初始时只有 `P2` 的需求能被满足，不可能直接得到 `P1 → P2 → P3`。
- B：符合实际安全序列，正确。
- C：`P2` 之后虽有更多资源，但此时能继续满足的是 `P1`，不是 `P3`。
- D：系统可以找到安全序列，不是不安全状态。

## 易错点
- 题目表格中左边两列是 `Allocation`，右边两列是 `Max`，不要看反。
- 安全性检查不是看“当前谁分得少”，而是看 `Need <= Available`。
- 每次某进程完成后，要把它已分配资源全部归还，再更新 `Available`。
