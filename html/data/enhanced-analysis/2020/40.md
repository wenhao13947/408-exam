## 答案

**D. 20ms，50ms。**  
最短情况不需要 DNS 解析，只需完成 HTTP 访问对应的 $2RTT$；最长情况需要先完成 3 次 DNS 迭代查询，再进行 HTTP 访问，共 $5RTT$。

## 解析

题干给出两个关键条件：

- 本地域名服务器只提供**递归查询**；
- 其他域名服务器只提供**迭代查询**；
- 局域网内主机访问 Internet 上各服务器的往返时间均为 $10\text{ms}$，且**忽略其他各种时延**。

这里“忽略其他时延”很关键，意味着主机 H 与本地域名服务器之间的局域网查询时间不计，只计算访问 Internet 上相关服务器产生的 RTT。

### 最短时间

最短情况对应：**主机 H 本地缓存中已经有 `www.abc.com` 到 IP 地址的映射**。

此时不需要进行 DNS 解析，主机可直接访问 Web 服务器。访问 `http://www.abc.com/index.html` 的过程包括：

- 建立 TCP 连接：$1RTT$
- 发送 HTTP 请求并收到 `index.html`：$1RTT$

因此最短时间为：

$$
2RTT = 2 \times 10\text{ms} = 20\text{ms}
$$

### 最长时间

最长情况对应：**主机 H 和本地域名服务器中都没有该域名的缓存记录**，必须完成完整的 DNS 查询过程。

由于本地域名服务器对主机 H 提供递归查询服务，所以从主机 H 的角度看，只发出一次查询请求；但本地域名服务器需要代替主机继续向其他 DNS 服务器发起迭代查询。过程如下：

- 查询根域名服务器，获得 `.com` 顶级域名服务器地址：$1RTT$
- 查询 `.com` 顶级域名服务器，获得 `abc.com` 权威域名服务器地址：$1RTT$
- 查询 `abc.com` 域名服务器，获得 `www.abc.com` 的 IP 地址：$1RTT$

DNS 解析共需：

$$
3RTT = 3 \times 10\text{ms} = 30\text{ms}
$$

得到 IP 地址后，主机 H 再访问 Web 服务器，请求页面：

- 建立 TCP 连接：$1RTT$
- 发送 HTTP 请求并接收页面：$1RTT$

HTTP 访问共需：

$$
2RTT = 20\text{ms}
$$

所以最长时间为：

$$
3RTT + 2RTT = 5RTT = 5 \times 10\text{ms} = 50\text{ms}
$$

因此答案是 **D**。

## 选项分析

**A. 10ms，40ms**  
错误。最短时间不可能是 $10\text{ms}$，因为即使已知 IP，也至少要经历建立 TCP 连接和请求/响应两个阶段，共 $2RTT=20\text{ms}$。最长时间也不是 $40\text{ms}$，完整 DNS 查询后再访问网页应为 $50\text{ms}$。

**B. 10ms，50ms**  
错误。最长时间 $50\text{ms}$ 正确，但最短时间不是 $10\text{ms}$，而是 $20\text{ms}$。

**C. 20ms，40ms**  
错误。最短时间 $20\text{ms}$ 正确，但最长时间少算了 1 个 RTT。完整过程应为 DNS 的 $3RTT$ 加 HTTP 的 $2RTT$，共 $50\text{ms}$。

**D. 20ms，50ms**  
正确。最短情况为直接访问服务器的 $2RTT$，最长情况为完整 DNS 查询 $3RTT$ 加页面访问 $2RTT$。

## 易错点

- 容易把“递归查询”误解为只需 1 次 RTT。递归查询只是对主机 H 而言查询接口简化了，但本地域名服务器仍要实际访问根、顶级域、权威域名服务器，因此这 3 次外部查询 RTT 仍需计入。
- 容易把主机 H 与本地域名服务器之间的时间也算进去。题干已说明“忽略其他各种时延”，原题解析也明确这部分不计。
- 容易把 HTTP 页面获取只算成建立 TCP 的 $1RTT$。本题中还要再加上“发送请求并收到页面”的 $1RTT$，所以访问网页总共是 $2RTT$。
