## 答案
选 **A**。该程序对数组 `a` 既有空间局部性，也有时间局部性。

## 解析
程序段是双重 `for` 循环：

```c
for (i = 0; i <= 9; i++) {
    temp = 1;
    for (j = 0; j <= i; j++) {
        temp *= a[j];
    }
    sum += temp;
}
```

对数组 `a` 的访问方式是按下标从小到大顺序访问：

- `i = 0` 时，访问 `a[0]`
- `i = 1` 时，访问 `a[0]、a[1]`
- `i = 2` 时，访问 `a[0]、a[1]、a[2]`
- 依此类推

这说明数组元素是连续、顺序地被访问的，因此有**空间局部性**。

同时，`a[0]`、`a[1]` 等元素会在不同外层循环中被重复访问，例如 `a[0]` 在 `i = 0,1,2,...,9` 中都会出现，因此有**时间局部性**。

所以正确结论是：**时间局部性和空间局部性皆有**。

## 选项分析
- **A. 时间局部性和空间局部性皆有**：正确。
- **B. 无时间局部性，有空间局部性**：错误，`a[0]` 等元素会被多次重复访问。
- **C. 有时间局部性，无空间局部性**：错误，数组是按下标顺序访问的，明显有空间局部性。
- **D. 时间局部性和空间局部性皆无**：错误。

## 易错点
时间局部性不只看“同一条语句是否重复执行”，还要落实到“是否重复访问同一数据项”；本题中 `a[j]` 既有重复访问，也有顺序访问，所以两种局部性都存在。
