## 答案

**B. 是否采用定长指令字格式。**  
因为 ISA 规定的是程序员或编译器“可见”的机器级行为与指令表示方式，而定长指令字格式属于指令格式范畴；其余选项都属于硬件实现细节，不由 ISA 直接规定。

## 解析

判断这题的关键，是区分 **ISA（Instruction Set Architecture，指令体系结构）** 与 **具体硬件实现** 的边界。

ISA 本质上规定的是硬件与软件之间的接口，也就是软件能够“看到并依赖”的内容，例如：

- 指令系统
- 指令格式
- 操作码的组织方式
- 操作数类型
- 寻址方式
- 寄存器的功能约定
- 数据表示方式等

题干问“由 ISA 规定的是哪一项”，因此应优先选择那些会直接影响指令编码、解码和机器级程序编写的内容。

“**是否采用定长指令字格式**”显然属于 **指令格式设计**。指令是定长还是变长，会直接影响：

- 指令如何编码
- CPU 如何取指和译码
- 编译器如何生成目标代码
- 程序员或汇编器如何理解机器指令边界

因此，这一项属于 ISA 规定的内容，故 **B 正确**。

而其余三项都不是“对软件可见的指令接口”，而是处理器内部“怎么实现”的问题。也就是说，即使底层硬件采用不同方案，只要对外暴露的 ISA 相同，软件通常仍可兼容运行。因此 A、C、D 都不属于 ISA 的规定范围。

## 选项分析

**A. 是否采用阵列乘法器**  
错误。阵列乘法器是运算器内部的实现方案，属于硬件结构设计问题。ISA 只会规定是否支持乘法指令、乘法结果如何表示等，不会规定乘法器必须采用哪种电路结构。

**B. 是否采用定长指令字格式**  
正确。定长或变长直接属于指令格式设计的一部分，而指令格式正是 ISA 的核心内容之一，因此该项由 ISA 规定。

**C. 是否采用微程序控制器**  
错误。微程序控制器属于控制器的实现方式。一个 ISA 可以通过微程序控制实现，也可以通过硬布线控制实现；二者都可能实现同一套指令系统，所以这不是 ISA 规定的内容。

**D. 是否采用单总线数据通路**  
错误。单总线数据通路是 CPU 内部数据通路组织方式，属于微体系结构或硬件实现细节。ISA 不会限定必须使用单总线、双总线还是其他数据通路结构。

## 易错点

- **易把“指令相关”都误认为属于 ISA。**  
  判断标准不是“是否和 CPU 有关”，而是“是否属于软件可见的接口”。  
  - 软件可见：通常属于 ISA  
  - 处理器内部怎么做：通常属于实现细节

- **“指令格式”与“硬件结构”要分清。**  
  “定长指令字格式”是对指令编码方式的规定，属于 ISA；  
  “乘法器结构”“控制器实现方式”“总线组织方式”都属于硬件实现，不属于 ISA。

- **可用一个快速判断法：**  
  若更换底层硬件实现后，机器语言程序仍可按原规则编写和运行，则该内容多半不是 ISA 的限制，而是实现层面的选择。
