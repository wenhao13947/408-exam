## 答案

错误的是 **D**。

## 解析

本题考查的是 **I/O 接口中端口的含义**，以及 **独立编址** 与 **统一编址** 两种 I/O 编址方式的区别。

先抓住核心结论：

- **统一编址**：I/O 端口与主存共用同一地址空间，I/O 端口被映射到主存地址空间中，所以 **CPU 可以直接用访存指令访问 I/O 端口**。
- **独立编址**：I/O 端口地址空间与主存地址空间彼此独立，通常需要 **专门的 I/O 指令** 来访问端口。

因此，选项 D 说“采用统一编址方式时，CPU 不能用访存指令访问 I/O 端口”，与统一编址的定义正好相反，所以 D 错误。

其余三项都符合 I/O 接口的基本概念：

- I/O 接口中可被 CPU 访问的寄存器，称为 **I/O 端口**；
- 状态端口和控制端口在实现上 **可以合用同一个寄存器**；
- 独立编址时，I/O 地址空间和主存地址空间彼此分离，所以二者的地址值 **可以相同而不冲突**。

## 选项分析

### A. 状态端口和控制端口可以合用同一个寄存器

该项 **正确**。

状态端口用于反映设备当前状态，控制端口用于接收 CPU 发出的控制命令。在具体实现中，这两个功能有时可以放在同一个寄存器中，只是读和写承担不同含义：

- **读该寄存器**：得到设备状态；
- **写该寄存器**：送入控制命令。

因此，“状态端口和控制端口可以合用同一个寄存器”是成立的。

### B. I/O 接口中 CPU 可访问的寄存器称为 I/O 端口

该项 **正确**。

I/O 接口内部往往包含若干寄存器，例如：

- 数据寄存器
- 状态寄存器
- 控制寄存器

其中，**凡是 CPU 能够访问的这些寄存器，统称为 I/O 端口**。所以该项表述就是对 I/O 端口概念的直接描述，没有问题。

### C. 采用独立编址方式时，I/O 端口地址和主存地址可能相同

该项 **正确**。

独立编址的关键在于：

- 主存有自己的地址空间；
- I/O 端口也有自己独立的地址空间。

因为这两套地址空间彼此独立，所以即使某个主存单元地址是 `1000H`，某个 I/O 端口地址也完全可以是 `1000H`，二者不会混淆。CPU 通过不同类型的指令或控制信号区分这是访存还是访 I/O。

所以，“地址可能相同”这一说法正确。

### D. 采用统一编址方式时，CPU 不能用访存指令访问 I/O 端口

该项 **错误**。

统一编址又称 **存储器映射 I/O**。其本质是把 I/O 端口映射到主存地址空间中，因此从 CPU 看来，访问这些端口和访问某些主存单元在指令形式上是一样的，使用的就是 **访存指令**。

所以正确说法应当是：

- **采用统一编址方式时，CPU 可以用访存指令访问 I/O 端口。**

题干要求选错误项，因此选 **D**。

## 易错点

1. **把“统一编址”和“独立编址”的访问指令混淆**
   - 统一编址：用访存指令访问 I/O。
   - 独立编址：通常用专门 I/O 指令访问端口。

2. **误以为地址值相同就一定冲突**
   - 只有在同一地址空间中才会冲突。
   - 独立编址下，主存地址空间和 I/O 地址空间分开，地址值重复是允许的。

3. **把 I/O 端口理解成外部插口**
   - 这里的“I/O 端口”不是物理插口，而是 **I/O 接口中可被 CPU 访问的寄存器**。
