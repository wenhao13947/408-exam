## 答案

C。按从左到右进行二路归并时，先归并 `(3,5)` 与 `(7,9)`，再将结果与 `(6)` 归并，关键字比较次数分别为 `2` 次和 `3` 次，总计 `5` 次。

## 解析

题干已经说明有三个升序序列：`(3,5)`、`(7,9)`、`(6)`，并且要求“按从左至右的次序”进行二路归并。因此归并顺序是：

先归并：
$$(3,5) \text{ 与 } (7,9)$$

再归并：
$$(3,5,7,9) \text{ 与 } (6)$$

关键点在于：二路归并时，只有当两个序列都还有元素时，才需要比较当前两个表头元素；一旦某一序列取空，另一序列剩余元素可直接复制到结果序列中，不再比较。

第一轮归并 `(3,5)` 和 `(7,9)`：

- 比较 `3` 和 `7`，因 `3 < 7`，输出 `3`
- 比较 `5` 和 `7`，因 `5 < 7`，输出 `5`
- 此时左侧序列已空，右侧剩余 `7,9` 直接接到后面

本轮比较次数为 `2` 次，归并结果为：
$$(3,5,7,9)$$

第二轮归并 `(3,5,7,9)` 和 `(6)`：

- 比较 `3` 和 `6`，因 `3 < 6`，输出 `3`
- 比较 `5` 和 `6`，因 `5 < 6`，输出 `5`
- 比较 `7` 和 `6`，因 `6 < 7`，输出 `6`
- 此时序列 `(6)` 已空，剩余 `7,9` 直接接到后面

本轮比较次数为 `3` 次。

因此总比较次数为：
$$2 + 3 = 5$$

所以正确选项是 **C**。

## 选项分析

A. `3`：错误。仅第二轮归并就需要比较 `3` 次，总次数不可能只有 `3` 次。

B. `4`：错误。第一轮比较 `2` 次，第二轮比较 `3` 次，总数应为 `5` 次，不是 `4` 次。

C. `5`：正确。按题目指定的从左到右归并顺序，比较次数为 `2 + 3 = 5`。

D. `6`：错误。归并中当某一序列耗尽后，另一序列剩余元素直接复制，不再继续比较，因此不会达到 `6` 次。

## 易错点

- 容易把“剩余元素直接复制”也算成比较次数。实际上，只有两个当前关键字之间的大小判断才计入比较次数。
- 容易忽略“按从左到右的次序”这一条件。该条件明确了归并顺序，不能随意改变为先把 `(7,9)` 和 `(6)` 归并。
- 可用检查方法快速验证：长度为 $m$ 和 $n$ 的两个有序序列做二路归并时，比较次数最多为 $m+n-1$，但实际可能更少。本题两轮分别是 `2` 与 `3`，结果与具体过程一致。
