## 答案

**结论：** 采用三个有序数组的**三指针同步扫描**。每次取当前三元组计算距离，更新最小值后，只移动当前三个数中**最小值所在数组**的指针一位，直到某个数组扫描结束。  
该算法的时间复杂度为 **$O(n)$**，空间复杂度为 **$O(1)$**，其中 $n=|S1|+|S2|+|S3|$。

## 解析

### 解法一：暴力法

枚举 $S_1,S_2,S_3$ 中所有三元组，逐个计算距离并维护最小值。时间复杂度为 $O(n_1n_2n_3)$，空间复杂度为 $O(1)$。写出三重循环即可保证算法正确，但数据稍大就会超时。

### 解法二：优化解法

利用三个数组均有序以及距离等于“最大值与最小值之差的两倍”，设置三个指针，每轮只移动当前最小值所在数组的指针，时间复杂度为 $O(n_1+n_2+n_3)$。

> **考场建议：** 先写三重枚举明确比较对象，再化简距离公式、利用有序性优化。不要一上来追三指针而漏掉距离公式的证明。

先说明关键性质。对任意三个数，设排序后为 $x\le y\le z$，则
$$
|a-b|+|b-c|+|c-a|=|x-y|+|y-z|+|z-x|=(y-x)+(z-y)+(z-x)=2(z-x).
$$
所以三元组的距离只取决于当前三数中的**最大值与最小值之差**。要让距离变小，就应尽量缩小这个跨度，因此每轮只移动当前**最小值**所在数组的指针。

### （1）基本设计思想

设三个数组分别为 $A,B,C$，长度分别为 $n1,n2,n3$，用指针 $i,j,k$ 分别扫描三个数组，初值都为 $0$。

循环过程中：
1. 取当前三元组 $(A[i],B[j],C[k])$；
2. 计算
   $$
   D=|A[i]-B[j]|+|B[j]-C[k]|+|C[k]-A[i]|
   $$
   并更新最小值；
3. 比较 $A[i],B[j],C[k]$，把**最小值对应的下标加 1**；
4. 直到某个数组扫描结束。

这样做的依据是：当前三数中最小的那个，如果不往后移，当前跨度不会有实质缩小；只有抬高最小值，才有可能减小 $max-min$，从而减小距离。

三元组距离应计算 $(A[i],B[j],C[k])$，最小值对应的下标也应在 $A[i],B[j],C[k]$ 中选择。

### （2）算法实现

```c
int solve(int S1[], int n1, int S2[], int n2, int S3[], int n3) {
    int i = 0, j = 0, k = 0;
    int res = INT32_MAX;

    while (i < n1 && j < n2 && k < n3) {
        int a = S1[i], b = S2[j], c = S3[k];
        int D = abs(a - b) + abs(b - c) + abs(c - a);
        if (D < res) res = D;

        if (a <= b && a <= c) {
            i++;
        } else if (b <= a && b <= c) {
            j++;
        } else {
            k++;
        }
    }
    return res;
}
```

函数需要返回结果，因此应声明为 `int solve(...)`，并返回 `res`。

### （3）复杂度分析

三个指针都只会单调递增，不会回退。每次循环至少有一个指针加 1，而三数组总长度为 $n$，所以循环总次数是 $O(n)$。

每轮只做常数次比较和加减绝对值运算，因此总时间复杂度为 **$O(n)$**。  
除若干辅助变量外，没有额外存储开销，因此空间复杂度为 **$O(1)$**。
