## 答案

A．建立在 TCP 之上的控制连接。

理由：题干问的是“传递 FTP 命令”使用什么连接。FTP 命令属于控制信息，应通过控制连接传送；同时 FTP 为保证文件传输的可靠性，建立在 TCP 之上，而不是 UDP。

## 解析

本题先抓两个关键词：**FTP 命令** 和 **连接类型**。

FTP 工作时并不是只用一条连接，而是使用两条功能不同的连接：

- **控制连接（control connection）**：传送登录、连接、目录操作、上传/下载请求等 FTP 命令。
- **数据连接（data connection）**：传送真正的文件内容或目录列表等数据。

因此，只要题干问的是“传递 FTP 命令”，就应先判断为 **控制连接**，而不是数据连接。

接着判断传输层协议。FTP 是文件传送协议，要求传输结果正确、完整、可靠，因此它使用 **TCP**，不使用 **UDP**。TCP 提供面向连接、可靠交付的服务，这与文件传输的需求一致。

据此可得：

- 传命令：用 **控制连接**
- 要可靠：基于 **TCP**

合并起来就是 **建立在 TCP 之上的控制连接**，选 **A**。

补充判断依据：
- FTP 服务器通常在 **21 号端口** 等待控制连接。
- 数据连接常用于实际文件传输，在文件传输时建立，传完可关闭。
- 控制连接通常在整个 FTP 会话期间保持打开，用来持续交换命令与响应。

这些特征也能反向证明：命令通道对应的是控制连接，而不是数据连接。

## 选项分析

A．建立在 TCP 之上的控制连接  
正确。FTP 命令通过控制连接传输，且 FTP 使用 TCP 保证可靠性。

B．建立在 TCP 之上的数据连接  
错误。虽然 FTP 的数据连接也建立在 TCP 之上，但它负责传送的是文件数据，不是 FTP 命令。

C．建立在 UDP 之上的控制连接  
错误。FTP 不使用 UDP 传送控制命令。UDP 不提供可靠传输，不符合 FTP 的基本要求。

D．建立在 UDP 之上的数据连接  
错误。FTP 的数据传输同样依赖 TCP，而不是 UDP。

## 易错点

- 容易把“控制连接”和“数据连接”混淆。判断方法很直接：  
  看到“命令、请求、登录、控制信息”选 **控制连接**；  
  看到“文件内容、实际传输的数据”选 **数据连接**。
- 容易被“数据连接”三个字误导，认为凡是和文件传输有关都选它。题干问的是“传递 FTP 命令”，不是“传文件”。
- 不要把 FTP 和某些可基于 UDP 的应用层协议混淆。FTP 的基础是 **TCP**。
