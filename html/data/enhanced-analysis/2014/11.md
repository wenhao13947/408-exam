## 答案

C．`3,2,5,4,7,6,9`

## 解析

本题考查快速排序在 408 语境下对“第 2 趟排序结果”的理解。

这里的“一趟”不是只做一次 `partition`，而是对当前尚未确定最终位置的元素整体再处理一轮。快速排序每做一次划分，都会确定一个枢轴元素的最终位置。  
因此，第 2 趟排序结束后，序列中至少应当有两个元素已经处在最终位置；并且这些元素满足：

- 该元素左边的元素都比它小；
- 该元素右边的元素都比它大。

也就是说，这样的元素已经不需要再参与后续排序。

判断一个选项能否作为第 2 趟结果，关键就是看：其中是否至少能找到两个可能已经处于最终位置的元素。若只能找到 1 个，则不可能是第 2 趟结果。

## 选项分析

### A．`2,3,5,4,6,7,9`

逐个看是否可能已在最终位置：

| 元素 | 判断 |
|---|---|
| `2` | 左边无元素，右边 `3,5,4,6,7,9` 都比 `2` 大，符合 |
| `3` | 左边 `2 < 3`，右边 `5,4,6,7,9` 都比 `3` 大，符合 |
| `5` | 右边有 `4 < 5`，不符合 |
| `4` | 左边有 `5 > 4`，不符合 |
| `6` | 左边 `2,3,5,4` 都比 `6` 小，右边 `7,9` 都比 `6` 大，符合 |
| `7` | 左边 `2,3,5,4,6` 都比 `7` 小，右边 `9` 比 `7` 大，符合 |
| `9` | 左边所有元素都比 `9` 小，符合 |

这里至少有 `2、3、6、7、9` 多个元素可能已在最终位置，所以完全可能是第 2 趟排序结果。

### B．`2,7,5,6,4,3,9`

逐个判断：

| 元素 | 判断 |
|---|---|
| `2` | 左边无元素，右边 `7,5,6,4,3,9` 都比 `2` 大，符合 |
| `7` | 右边有 `5,6,4,3 < 7`，不符合 |
| `5` | 左边有 `7 > 5`，右边有 `4,3 < 5`，不符合 |
| `6` | 左边有 `7 > 6`，右边有 `4,3 < 6`，不符合 |
| `4` | 左边有 `7,5,6 > 4`，右边有 `3 < 4`，不符合 |
| `3` | 左边有 `7,5,6,4 > 3`，不符合 |
| `9` | 左边所有元素都比 `9` 小，符合 |

这里至少有 `2` 和 `9` 两个元素可能已在最终位置，因此可能是第 2 趟排序结果。

### C．`3,2,5,4,7,6,9`

逐个判断：

| 元素 | 判断 |
|---|---|
| `3` | 右边有 `2 < 3`，不符合 |
| `2` | 左边有 `3 > 2`，不符合 |
| `5` | 右边有 `4 < 5`，不符合 |
| `4` | 左边有 `5 > 4`，不符合 |
| `7` | 右边有 `6 < 7`，不符合 |
| `6` | 左边有 `7 > 6`，不符合 |
| `9` | 左边所有元素都比 `9` 小，符合 |

只有 `9` 一个元素可能已经处于最终位置。  
这不满足“第 2 趟排序后至少有两个元素已确定最终位置”的要求，所以它不可能是快速排序第 2 趟的结果。

### D．`4,2,3,5,7,6,9`

逐个判断：

| 元素 | 判断 |
|---|---|
| `4` | 右边有 `2,3 < 4`，不符合 |
| `2` | 左边有 `4 > 2`，不符合 |
| `3` | 左边有 `4 > 3`，不符合 |
| `5` | 左边 `4,2,3` 都比 `5` 小，右边 `7,6,9` 都比 `5` 大，符合 |
| `7` | 右边有 `6 < 7`，不符合 |
| `6` | 左边有 `7 > 6`，不符合 |
| `9` | 左边所有元素都比 `9` 小，符合 |

这里至少有 `5` 和 `9` 两个元素可能已在最终位置，因此可能是第 2 趟排序结果。

## 易错点

1. 不要把“第 2 趟排序”误解成“恰好完成两次单独的 `partition`”。本题采用的是 408 的常见表述，即对当前未排定部分整体又进行一轮处理后的状态。
2. 判断“某元素是否已在最终位置”时，标准只有一个：左边全小于它，右边全大于它。
3. 本题问的是“不可能的是哪一个”，不是“已经完全有序的是哪一个”。

因此，不可能是快速排序第 2 趟排序结果的是 **C**。
