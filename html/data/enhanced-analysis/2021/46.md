## 答案

（1）`ROM 中的引导程序 -> 磁盘引导程序 -> 分区引导程序 -> 操作系统的初始化程序`

（2）`磁盘的物理格式化 -> 对磁盘进行分区 -> 逻辑格式化 -> 操作系统的安装`

（3）磁盘扇区的划分在`物理格式化`中完成，文件系统根目录的建立在`逻辑格式化`中完成。

## 解析

### （1）系统启动时的执行顺序

题干已经说明系统采用多阶段引导方式，且引导链条包括 `ROM` 中的引导程序、磁盘引导程序、分区引导程序和操作系统的初始化程序。

启动时，最先执行的是固化在 `ROM` 中的引导程序。它负责完成最初的引导控制，并把启动过程继续交给硬盘上的引导信息。

接着执行`磁盘引导程序`。它位于硬盘第一个扇区的主引导记录 `MBR` 中，作用是根据分区表选择要引导的分区。

然后执行`分区引导程序`。它位于所选分区的第一个扇区，用于进一步引导该分区中的操作系统。

最后才执行`操作系统的初始化程序`，即操作系统被装入内存后开始建立运行环境。

因此执行顺序为：
`ROM 中的引导程序 -> 磁盘引导程序 -> 分区引导程序 -> 操作系统的初始化程序`。

### （2）制作启动盘时的操作顺序

制作启动盘要先具备底层存储结构，再建立分区和文件系统，最后才能安装操作系统。

首先进行`磁盘的物理格式化`，也称低级格式化，其作用是为磁盘划分磁道、扇区等物理结构。

然后进行`对磁盘进行分区`，把整块硬盘划分为若干独立分区。

接着进行`逻辑格式化`，在分区上建立文件系统所需的管理信息。

最后进行`操作系统的安装`。

所以正确顺序是：
`磁盘的物理格式化 -> 对磁盘进行分区 -> 逻辑格式化 -> 操作系统的安装`。

### （3）扇区划分与根目录建立的位置

磁盘扇区的划分属于磁盘底层物理结构的建立，应在`物理格式化`中完成。

文件系统根目录的建立属于文件系统初始化内容，应在`逻辑格式化`中完成。

## 易错点

`磁盘引导程序`负责选择分区，`分区引导程序`负责引导该分区内的操作系统，二者不能混淆。`物理格式化`解决磁盘物理结构，`逻辑格式化`解决文件系统结构，根目录属于后者。
