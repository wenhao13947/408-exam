## 答案
选 `C`。在完成 `s->next = p->next` 和 `p->next = s` 后，还需要把 `s->prev` 设为 `p`，并把原后继结点的 `prev` 改为 `s`。

## 解析
这是双向链表在结点 `p` 后插入新结点 `s` 的标准操作。

已执行：
- `s->next = p->next`
- `p->next = s`

此时链表的 `next` 关系已经接好，但双向链表还要维护 `prev` 关系：
- `s` 的前驱应当是 `p`
- 原来 `p` 后面的那个结点，现在它的前驱应当改成 `s`

因为执行完前两句后，`s->next` 正好指向原来 `p` 的后继，所以可以直接通过 `s->next->prev` 访问那个结点并修改其前驱指针。

因此应补充：
- `s->prev = s->next->prev`
- `s->next->prev = s`

这正对应选项 `C`。

## 选项分析
- `A`：`s->next->prev = p` 这一步本身没有问题，但 `s->prev = p` 是在设置 `s` 的前驱，顺序和配套关系不对，不能完成正确插入。
- `B`：`p->next->prev = s` 等价于把 `s->prev` 反复指向同一个位置，不能正确修复原后继结点的前驱关系。
- `C`：先让 `s->prev` 取到原后继结点的前驱，也就是 `p`，再把原后继结点的 `prev` 改为 `s`，两条语句正好补全双向链接。
- `D`：两句都没有把 `s->prev` 正确设为 `p`，也没有正确完成插入后的前驱维护，错误。

## 易错点
- 这题的关键不是只改 `next`，而是插入双向链表时必须同时维护两边的 `prev` 和 `next`。
- 执行完 `s->next = p->next; p->next = s` 后，`s->next` 指向的就是原后继结点，可直接用 `s->next->prev` 修改它的前驱。
