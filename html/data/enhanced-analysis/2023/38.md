## 答案
A。R2 经过 NAT 后，分组源 IP 应改写为 R2 外网接口的公网地址；结合原卷给出的地址块，R2 的地址是 `195.123.0.33`。

## 解析
NAT 的作用是把内网主机发往 Internet 的分组源地址，改写成 NAT 路由器的公网地址。

本题关键在于先确定 R2 外网接口的地址。题目给出了与之同一链路上的 R1 接口地址，它属于一个 `/30` 地址块：

- `/30` 表示主机位只有 2 位
- 一个 `/30` 地址块中：
  - 主机位全 `0` 是网络地址，不可分配
  - 主机位全 `1` 是广播地址，不可分配
  - 中间两个地址可分配给接口

原卷图中 R1 的接口地址是 `195.123.0.34/30`，对应网络地址 `195.123.0.32`，广播地址 `195.123.0.35`。两个可分配地址是 `195.123.0.33` 和 `195.123.0.34`；后者已分给 R1，因此 R2 的公网接口地址为 `195.123.0.33`。

因此，主机 H 的 IP 分组经过 R2 转发后，其源 IP 地址被 NAT 改写为 `195.123.0.33`。

## 选项分析
A. `195.123.0.33`：正确，R2 经过 NAT 后应使用的公网接口地址。

B. `192.123.0.35`：错误，不属于题图给出的 `195.123.0.32/30` 网段。

C. `192.168.0.1`：错误，与题目所给 `/30` 地址块无关，不能作为该链路上的接口地址。

D. `192.168.0.3`：错误，与题目所给地址块不匹配，也不是该 NAT 转发所需的公网源地址。

## 易错点
- NAT 改写的是**源 IP 地址**，不是目的 IP 地址。
- `/30` 子网中只有 2 个可分配地址，分别位于网络地址和广播地址之间。
- 不能把广播地址误当成可分配接口地址。
