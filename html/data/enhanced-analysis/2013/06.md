## 答案
C。`v` 是叶结点时，`T1` 与 `T3` 相同；`v` 不是叶结点时，`T1` 与 `T3` 不同。

## 解析
对二叉排序树（BST）而言，删除结点后再插回去，结果是否与原树相同，取决于该结点是不是叶结点。

- 若 `v` 是叶结点：删除时只是把这个叶子直接去掉；再按 BST 插入规则插回去时，`v` 只能回到原来的位置，因为它与沿途结点比较后，最终落点不变。所以 `T3` 与 `T1` 相同。
- 若 `v` 不是叶结点：删除时不能直接删掉，而要用其左子树最大结点或右子树最小结点替换原位置，树形结构会发生改变。之后再把 `v` 插回去，按 BST 插入规则，它会落到新的位置，因此 `T3` 与 `T1` 不同。

## 选项分析
- I：错。若 `v` 是叶结点，`T1` 与 `T3` 应相同，不是不同。
- II：对。叶结点删后再插回，仍回到原位，`T1` 与 `T3` 相同。
- III：对。非叶结点删除时要做替换，之后再插回会落到新位置，`T1` 与 `T3` 不同。
- IV：错。非叶结点情况下，`T1` 与 `T3` 不相同。

## 易错点
- 叶结点删除后再插回，通常不会改变 BST 的结构。
- 非叶结点删除时，先发生“替换”，这一步已经可能改变整棵树的形态，因此再插回也不一定恢复原树。
