## 答案
不正确的是 **A. 驱动程序与 I/O 控制方式无关**。驱动程序与所采用的 I/O 控制方式、设备类型都密切相关。

## 解析
驱动程序的作用，是把抽象的 I/O 请求转换成具体的硬件操作，并把设备状态和完成情况反馈给发出请求的进程。因此，它天然依赖具体设备及其 I/O 控制方式，不可能“无关”。

本题其余选项都符合驱动程序的基本职责：

- 设备初始化通常由驱动程序完成。
- 进程在执行驱动程序、进行 I/O 操作时，可能因等待设备而进入阻塞态，这与采用的 I/O 方式有关。
- 设备的读/写操作最终也要由驱动程序控制完成，因为不同硬件的读写机制不同，必须由驱动程序将通用请求转换成设备能识别的操作。

## 选项分析
- **A. 驱动程序与 I/O 控制方式无关**  
  错。驱动程序必须适配具体的 I/O 控制方式，如程序直接控制、中断控制、DMA 等，所以二者是紧密相关的。

- **B. 初始化设备是由驱动程序控制完成的**  
  对。新设备接入后，通常需要由驱动程序完成初始化，才能正常使用。

- **C. 进程在执行驱动程序时可能进入阻塞态**  
  对。在中断控制或 DMA 方式下，等待设备数据期间，发起 I/O 的进程可能进入阻塞态。

- **D. 读/写设备的操作是由驱动程序控制完成的**  
  对。驱动程序负责把高层 I/O 请求转换为硬件可执行的具体读写操作。

## 易错点
本题最容易混淆的是：  
- “进程执行驱动程序”不等于“一定阻塞”。是否阻塞，要看采用的 I/O 控制方式。  
- “驱动程序控制读写”并不表示驱动直接做所有底层细节，而是负责把抽象操作映射为具体设备命令。
