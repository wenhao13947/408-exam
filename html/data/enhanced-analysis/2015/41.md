## 答案

(1) 利用 `|data|<=n` 这一条件，设一个长度为 `n+1` 的辅助标记数组，按链表顺序扫描。第一次遇到某个绝对值时保留并标记；再次遇到相同绝对值时删除该结点。这样只需一趟扫描。

(2) 单链表结点可定义为：
```c
typedef struct LNode {
    int data;
    struct LNode *next;
} LNode, *LinkList;
```

(3) 算法如下：
```c
void RemoveDupAbs(LinkList head, int n) {
    int hash[n + 1];
    for (int i = 0; i <= n; i++) hash[i] = 0;

    LNode *p = head;        // p 指向当前结点的前驱
    LNode *q = head->next;   // q 指向待处理结点

    while (q != NULL) {
        int k = abs(q->data);
        if (hash[k] == 1) {
            p->next = q->next;   // 删除 q
            q = p->next;
        } else {
            hash[k] = 1;         // 记录该绝对值已出现
            p = q;
            q = q->next;
        }
    }
}
```

(4) 时间复杂度为 `O(m)`，空间复杂度为 `O(n)`。

## 解析

### 解法一：暴力法

对链表中的每个保留结点，都向后扫描剩余链表，删除绝对值与它相等的结点。时间复杂度为 $O(m^2)$，空间复杂度为 $O(1)$。该方法不需要辅助数组，但会反复扫描后续结点。

### 解法二：优化解法

利用题目给出的 $|data|\le n$，开辟长度为 $n+1$ 的标记数组，一趟扫描完成判重和删除，时间复杂度为 $O(m)$，空间复杂度为 $O(n)$。

> **考场建议：** 暴力双循环最容易先写出来；看到数据范围可以直接映射到数组下标后，再用空间换时间完成优化。

(1) 题目关键条件是 `|data|<=n`，这说明每个结点的绝对值都能直接映射到 `0..n` 范围内的数组下标。  
因此可以用一个辅助数组记录“某个绝对值是否已经出现过”，再对链表做一趟从前到后的扫描：

- 第一次遇到某个绝对值：保留该结点，并把对应标记置为已出现；
- 再次遇到相同绝对值：删除该结点。

这样做的本质是“空间换时间”，应按绝对值下标标记，即 `hash[abs(data)] = 1`。

(2) 单链表结点至少包含两个部分：

- `data`：存放整数数据；
- `next`：指向后继结点。

所以结点类型定义应如答案所示。结点的指针字段可命名为 `link` 或 `next`，但定义和代码中必须保持一致。

(3) 结合带头结点的单链表，删除当前结点时应借助前驱指针完成。读图可知示例中保留的是按先后顺序第一次出现的绝对值对应结点，因此必须从头到尾顺序处理，不能乱序比较。

算法过程是：

- 初始化辅助数组 `hash`，全部置 0；
- `p` 指向当前结点的前驱，`q` 指向待判断结点；
- 若 `abs(q->data)` 已经出现过，则执行
  `p->next = q->next`，把 `q` 从链表中删除；
- 否则说明第一次出现，令 `hash[abs(q->data)] = 1`，然后 `p`、`q` 同时后移。

这样能保证保留每个绝对值第一次出现的结点，其余都删掉。

(4) 扫描链表一趟，处理每个结点都是常数时间，因此主过程是 `O(m)`。辅助数组大小为 `n+1`，所以额外空间是 `O(n)`。  
上述算法的复杂度就是这个口径。
