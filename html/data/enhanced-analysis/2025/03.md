## 答案
D。顺序存储的二叉树中，非空结点的父结点必须存在，D 中出现了“子结点存在但其父位置为空”的情况。

## 解析
二叉树采用顺序存储时，数组下标按层序对应结点位置，空结点也要保留，用 `-1` 表示。判断一个数组能否表示二叉树，关键是看：每个非 `-1` 结点（根结点除外）的父位置是否也是非空。

对 D `R[] = {17, 20, 35, -1, 18, 45, -1, -1, 19, 27}` 而言，`19` 位于下标 8（按从 0 开始计），其父结点下标应为 `⌊(8-1)/2⌋ = 3`，但 `R[3] = -1`，说明父结点不存在而子结点却存在，这不符合顺序存储二叉树的定义，因此 D 不能表示一棵二叉树。

## 选项分析
A. `R[] = {20, 15, 40, -1, -1, 35}`，各非空结点的父结点位置都成立，可以表示二叉树。  
B. `R[] = {15, 40, 10, 18, 35, -1, -1}`，结构连续，未出现“子有而父空”的情况，可以表示二叉树。  
C. `R[] = {15, 40, 10, -1, -1, -1, 12}`，`12` 的父位置存在，可以表示二叉树。  
D. `R[] = {17, 20, 35, -1, 18, 45, -1, -1, 19, 27}`，存在空父结点对应非空子结点，不能表示二叉树。

## 易错点
顺序存储不是只看数组里有没有 `-1`，而是要检查“非空结点的祖先位置是否都已存在”。只要某个结点的父位置为空，这个数组就不可能对应一棵合法二叉树。
