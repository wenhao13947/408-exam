## 答案

### （1）
R2 的最少路由表项为 3 条：

| 目的网络 | 下一跳 | 接口 |
|---|---|---|
| `153.14.5.0/24` | `153.14.3.2` | `S0` |
| `194.17.20.0/23` | `194.17.24.2` | `S1` |
| `194.17.20.128/25` | `-` | `E0` |

### （2）
通过 `E0` 接口转发。

### （3）
使用 `BGP`（或 `BGP4`）交换路由信息；其报文封装在 `TCP` 协议段中传输。

## 解析

### （1）
题目要求给出 R2 到达图中所有子网的路由，且路由项尽可能少，因此要对可由同一出口转发的子网做路由聚合。

先看 AS1 中由 R1 连接的两个子网：

`153.14.5.0/25` 和 `153.14.5.128/25`

这两个网段前 24 位相同，可聚合为：

`153.14.5.0/24`

下一跳为题图所示邻接路由器接口地址 `153.14.3.2`，从 `S0` 接口转发。

再看 AS2 中由 R3 方向可达的两个子网：

`194.17.20.0/25` 和 `194.17.21.0/25`

第二个子网应为 `/25`。  
两者第三字节分别为 `20 = 00010100`、`21 = 00010101`，前 7 位相同，所以共同前缀长度为 `16 + 7 = 23` 位，可聚合为：

`194.17.20.0/23`

下一跳为题图所示 `194.17.24.2`，从 `S1` 接口转发。

最后，`194.17.20.128/25` 是直连到 R2 的子网，直接从 `E0` 接口转发，无需下一跳。

所以 R2 的路由表为：

| 目的网络 | 下一跳 | 接口 |
|---|---|---|
| `153.14.5.0/24` | `153.14.3.2` | `S0` |
| `194.17.20.0/23` | `194.17.24.2` | `S1` |
| `194.17.20.128/25` | `-` | `E0` |

### （2）
目的 IP 为 `194.17.20.200`。

它同时匹配：

- `194.17.20.0/23`
- `194.17.20.128/25`

按最长前缀匹配原则，`/25` 比 `/23` 更长，因此选 `194.17.20.128/25`，由 `E0` 接口转发。

### （3）
R1 和 R2 分属不同自治系统，自治系统之间交换路由信息使用外部网关协议 `BGP`，常见实现为 `BGP4`。

`BGP` 是应用层协议，它的报文封装在 `TCP` 段中传输。

## 易错点

两个 `/25` 子网聚合后，最终结果为 `194.17.20.0/23`。
