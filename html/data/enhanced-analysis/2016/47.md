## 答案
（1）`dir` 目录文件中应有 `dir1 -> 48`；`dir1` 目录文件中应有 `file1 -> 100`、`file2 -> 200`。  
（2）FAT 最大长度为 `128KB`，该文件系统支持的文件最大长度为 `256MB`。  
（3）`106` 存放在 FAT 的 `100` 号表项中，`108` 存放在 FAT 的 `106` 号表项中。  
（4）需要访问 `48` 号簇和 `106` 号簇。

## 解析

### （1）
目录项只存“文件名 + 第一个簇号”，其余簇号在 FAT 中。

结合题给目录树：

**图解：目录树对应关系**

先看目录项如何给出各目录和文件的首簇号。

![目录树对应关系](/data/enhanced-analysis/assets/2016/47/original-analysis-1.svg)
- `dir` 目录文件中记录 `dir1` 的首簇号为 `48`
- `dir1` 目录文件中记录 `file1` 的首簇号为 `100`
- `dir1` 目录文件中记录 `file2` 的首簇号为 `200`

所以所有目录文件内容应写成：

| 目录文件 | 文件名 | 簇号 |
|---|---|---|
| `dir` | `dir1` | `48` |
| `dir1` | `file1` | `100` |
| `dir1` | `file2` | `200` |

### （2）
FAT 每个表项占 `2` 字节，即 `16` 位，所以最多可表示 `2^16 = 65536` 个表项，也就是最多 `65536` 个簇。

因此：

- FAT 最大长度 = `65536 × 2B = 131072B = 128KB`
- 文件最大长度 = `65536 × 4KB = 262144KB = 256MB`

上述结果是对的。

### （3）
FAT 中每个表项保存的是“当前簇的下一簇号”。

已知 `file1` 的簇链为 `100 -> 106 -> 108`，所以：
- `100` 号表项中存放 `106`
- `106` 号表项中存放 `108`

### （4）
先按目录逐级定位：

- 在 `dir` 中找到 `dir1` 的首簇号 `48`
- 读入 `48` 号簇，得到 `dir1` 目录文件
- 在 `dir1` 中找到 `file1` 的首簇号 `100`

接着根据 `file1` 的簇链和 FAT 继续定位第 `5000` 个字节所在簇。由于每簇 `4KB = 4096B`，第 `5000` 个字节已落在第二个簇中，所以要访问 `file1` 的后续簇 `106`。

因此需要访问的簇是：
- `48` 号簇
- `106` 号簇

## 易错点
`5000` 是字节序号，不是簇号。先由目录找到首簇，再按 `4KB` 的簇大小判断字节落在哪个簇里。
