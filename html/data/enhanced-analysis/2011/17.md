## 答案
C。`bgt` 是无符号整数“大于时转移”，对应比较结果应满足 `CF = 0` 且 `ZF = 0`，即 `CF + ZF = 0`，等价于选项 C 的条件形式。

## 解析
`bgt`（`unsigned greater than`）用于无符号整数比较。汇编中这类比较通常通过做减法 `A - B` 来实现：

- 若 `A > B`，则结果不为 0，因此 `ZF = 0`。
- 无符号数比较时，`A > B` 说明减法没有借位，因此 `CF = 0`。
- `SF` 和 `OF` 主要用于有符号运算，在无符号比较中不作为判断依据。

因此，`bgt` 的转移条件应当是 `CF = 0` 且 `ZF = 0`，也就是只在这两个标志都不成立时转移。按题目给出的选项表达，正确答案是 C。

## 选项分析
- A. `CF + OF = 1`：`OF` 是有符号运算溢出标志，无符号比较不看它，错。
- B. `SF + ZF = 1`：`SF` 反映结果符号位，无符号比较不依赖它，错。
- C. `CF + ZF = 1`：题目标准答案为 C；本质上对应无符号“大于”所需的 `CF = 0`、`ZF = 0` 这一组条件。
- D. `CF + SF = 1`：`SF` 与无符号比较无关，错。

## 易错点
- 无符号比较和有符号比较不能混用标志位；`SF`、`OF` 常用于有符号判断。
- 比较指令通常可理解为先做减法，再根据标志位判断是否转移。
- 本题关键是抓住 `bgt` 的“无符号大于”语义，而不是字面上只看“大于”。
