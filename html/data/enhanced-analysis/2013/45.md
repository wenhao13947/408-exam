## 答案

设两个信号量：

- `semaphore empty = 500;`：表示馆内剩余可容纳的人数，初值为 500。
- `semaphore mutex = 1;`：表示出入口的互斥信号量，初值为 1。

完整过程可写为：

```c
semaphore empty = 500;
semaphore mutex = 1;

visitor() {
    P(empty);
    P(mutex);
    进门;
    V(mutex);

    参观;

    P(mutex);
    出门;
    V(mutex);
    V(empty);
}
```

## 解析

### 信号量设置

题目中的约束有两个：

1. 博物馆最多同时容纳 500 人，需要用一个计数信号量表示剩余名额；
2. 出入口一次只允许 1 人通过，需要用一个互斥信号量保证进门、出门时对同一出入口的互斥访问。

因此设置：

- `empty = 500`：表示当前还可进入的人数；
- `mutex = 1`：表示出入口是否可被占用。

### 过程设计

参观者进入博物馆前，必须先申请一个可用名额，因此先执行 `P(empty)`。若馆内已满，则该操作阻塞，直到有人离开并归还名额。

之后参观者要通过唯一的出入口进入，因此需要执行 `P(mutex)`，完成“进门”后再执行 `V(mutex)`，释放出入口。

参观结束后，参观者离开时仍需经过同一个出入口，所以再次执行 `P(mutex)`，完成“出门”后执行 `V(mutex)`。

最后执行 `V(empty)`，归还 1 个名额，表示馆内可容纳人数增加 1。

对应完整过程为：

```c
semaphore empty = 500;
semaphore mutex = 1;

visitor() {
    P(empty);
    P(mutex);
    进门;
    V(mutex);

    参观;

    P(mutex);
    出门;
    V(mutex);
    V(empty);
}
```

## 易错点

- `empty` 是计数信号量，表示剩余名额，不能误设为 1。
- 进门和出门都要经过同一个出入口，因此两处都必须执行 `P(mutex)` 和 `V(mutex)`。
- `V(empty)` 应在离开博物馆后执行，因为只有离馆后才真正释放一个可用名额。
