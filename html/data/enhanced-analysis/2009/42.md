## 答案

### （1）
采用**双指针一趟扫描**的方法。  
设两个指针 `p`、`q` 都指向链表第一个数据结点，先让 `p` 先行 `k-1` 个结点；若途中 `p` 为空，则说明链表长度小于 `k`，查找失败。否则让 `p` 和 `q` 同步后移，直到 `p` 到达最后一个结点，此时 `q` 所指结点就是倒数第 `k` 个结点，输出其 `data` 域并返回 `1`。若失败则返回 `0`。

### （2）
详细步骤如下：

1. 令 `p = list->link`，`q = list->link`，都指向第一个数据结点。
2. 若 `k <= 0`，返回 `0`。
3. 让 `p` 先向后移动 `k-1` 次；每移动一次都检查 `p` 是否为空。
4. 若中途 `p == NULL`，说明链表中不足 `k` 个数据结点，返回 `0`。
5. 当 `p` 还未到最后一个结点时，令 `p`、`q` 同步后移。
6. 循环结束后，`q` 即为倒数第 `k` 个结点，输出 `q->data`，返回 `1`。

### （3）
```c
typedef struct Node {
    int data;
    struct Node *link;
} Node;

int FindElement(Node *list, int k) {
    Node *p, *q;
    int i;

    if (list == NULL || k <= 0) {
        return 0;
    }

    p = list->link;   // 第一个数据结点
    q = list->link;   // 第一个数据结点

    if (p == NULL) {
        return 0;
    }

    for (i = 1; i < k; i++) {
        p = p->link;
        if (p == NULL) {
            return 0;
        }
    }

    while (p->link != NULL) {
        p = p->link;
        q = q->link;
    }

    printf("%d\n", q->data);
    return 1;
}
```

## 解析

### 解法一：暴力法

先完整遍历链表得到长度 $n$，再从首元结点出发走到第 $n-k+1$ 个结点。该方法需要两趟扫描，时间复杂度为 $O(n)$，空间复杂度为 $O(1)$。它容易想到，也能拿到主要步骤分，但没有充分体现“尽可能高效”。

### 解法二：优化解法

用快慢指针把两趟扫描压缩为一趟。正式作答应写下面的双指针算法。

> **考场建议：** 如果一时想不到双指针，先写“求长度再定位”的暴力法保证基础分，再检查能否利用固定距离改成一趟扫描。

### （1）
题目要求在**不改变链表**的前提下，尽可能高效地找到倒数第 `k` 个结点，因此应避免先求表长再定位的两趟扫描。

双指针法的核心是先拉开固定距离，再同步前进：

- `p` 先走 `k-1` 步；
- `q` 保持在起点；
- 当 `p` 走到表尾时，`q` 正好落在倒数第 `k` 个结点。

这是一次遍历即可完成的做法，时间复杂度为 `O(n)`，额外空间为 `O(1)`。

### （2）
本题是**带头结点**的单链表，所以初始位置应从第一个数据结点开始，即 `list->link`，不能把头结点当作结果结点。

按步骤执行：

1. 初始化 `p = list->link`，`q = list->link`。
2. 若链表为空，直接失败。
3. 让 `p` 先走 `k-1` 步。  
   这样 `p` 与 `q` 之间就保持了 `k-1` 个结点的间隔。
4. 若在前进过程中 `p` 为空，说明链表长度不足 `k`，返回 `0`。
5. 之后让 `p` 和 `q` 同步移动，直到 `p` 到达最后一个结点。
6. 此时 `q` 正好指向倒数第 `k` 个结点，输出其 `data`，返回 `1`。

每次 `p` 前进一步时，计数器应执行 `count = count + 1`。

### （3）
代码实现与上面的思路一致：

- 先用 `p` 领先 `q` `k-1` 步；
- 再同步移动；
- 最后输出 `q->data`。

这里必须注意：初始化时不能把头结点当作目标结点，否则会混淆头结点与首个数据结点。按题意，正确做法应从第一个数据结点开始。

## 易错点

1. 这是**带头结点**单链表，起点应是 `list->link`。
2. 领先步数应是 `k-1`，不是 `k`。
3. 只要链表长度不足 `k`，就应返回 `0`。
4. 不能用两趟扫描、递归或额外大空间替代一趟双指针法。
