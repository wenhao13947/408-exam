## 答案

**B. 仅 I、IV**

## 解析

题目问的是：主机 `H` 向 Internet 发送 UDP 报文段时，NAT 路由器在转发其所封装的 IP 数据报过程中，**UDP 首部**里哪些字段会被修改。

先看 NAT 在这个场景下做什么。内网主机 `192.168.1.5/24` 对外发送数据时，NAT 要把内网地址转换成公网地址；在多个内网主机共享一个公网 IP 的常见场景下，还要借助**源端口号**区分不同会话。因此，UDP 首部中的**源端口号**可能被改写，这样外部返回的数据才能正确映射回内网主机和进程。

UDP 首部一旦被改动，或者与校验和计算相关的 IP 地址被改动，**UDP 校验和**就必须重新计算，所以**校验和字段**也会被修改。

而 **目的端口号** 表示远端接收应用的端口，普通 NAT 转发不会去改它；**UDP 总长度**表示 UDP 首部加数据部分的总长度，NAT 只是做地址/端口转换，不会改变 UDP 报文段本身的长度，因此该字段不变。

所以会被修改的是：

- I 源端口号
- IV 校验和

对应 **B**。

## 选项分析

### A. 仅 I、III

错误。

- **I 源端口号**：在 NAT 对外转发时，常需要改写，用于建立“公网 IP + 端口号”到内网主机/进程的映射，这一项应选。
- **III 总长度**：NAT 不改变 UDP 数据部分的大小，也不增减 UDP 首部长度，因此 UDP 总长度通常不变，这一项不应选。

所以 A 多选了 **III**。

### B. 仅 I、IV

正确。

- **I 源端口号**：NAT 为区分不同内网会话，可能改写源端口号。
- **IV 校验和**：源端口号或相关 IP 地址一旦变化，UDP 校验和就必须重算，因此该字段会改。

与题意一致。

### C. 仅 II、III

错误。

- **II 目的端口号**：普通 NAT 转发不需要改远端应用的端口号，通常保持不变。
- **III 总长度**：NAT 不改变 UDP 报文段长度，因此该字段也不变。

这两个字段都不应选，所以 C 错误。

### D. 仅 II、IV

错误。

- **II 目的端口号**：通常不改。
- **IV 校验和**：会因 NAT 改写相关字段而重算，这一项应选。

所以 D 错在把 **II** 选进来了，同时漏掉了 **I**。

## 易错点

1. **不要把 IP 首部字段和 UDP 首部字段混在一起。**  
题目明确问的是 **UDP 首部字段**。NAT 转发时当然会改 IP 首部中的源 IP 地址，但这不属于本题作答对象。

2. **“总长度”是 UDP 的总长度，不是 IP 总长度。**  
NAT 做的是地址转换和端口复用，不会改变 UDP 报文段自身长度，因此 UDP 总长度不变。

3. **校验和会变，不仅仅因为端口变了。**  
UDP 校验和的计算还与 IP 地址有关。NAT 改了相关内容后，校验和必须更新，所以 IV 要选。
