## 答案

### （1）
DHCP 服务器可为主机 2～主机 N 动态分配的最大地址范围是 `111.123.15.5 ~ 111.123.15.254`。

主机 2 发送 DHCP Discover 报文时，IP 分组的源 IP 地址是 `0.0.0.0`，目的 IP 地址是 `255.255.255.255`。

### （2）
主机 2 访问 Internet 时发出的第一个以太网帧的目的 MAC 地址是 `ff-ff-ff-ff-ff-ff`。

封装主机 2 发往 Internet 的 IP 分组的以太网帧目的 MAC 地址是 `00-a1-a1-a1-a1-a1`。

### （3）
主机 1 能访问 WWW 服务器，不能访问 Internet。

## 解析

### （1）
题中路由器内网接口、DHCP 服务器、WWW 服务器和主机 1 的地址分别是 `111.123.15.1/24`、`111.123.15.2/24`、`111.123.15.3/24`、`111.123.15.4/24`，它们都处于 `111.123.15.0/24` 网段。

`/24` 表示前 24 位是网络号，最后 8 位是主机号。该网段的地址范围是 `111.123.15.0 ~ 111.123.15.255`，其中：
- `111.123.15.0` 是网络地址；
- `111.123.15.255` 是广播地址；
- `111.123.15.1 ~ 111.123.15.4` 已分别被路由器接口、DHCP 服务器、WWW 服务器和主机 1 占用。

因此，DHCP 服务器能为主机 2～主机 N 分配的最大地址范围是 `111.123.15.5 ~ 111.123.15.254`。

主机 2 刚申请地址时还没有获得 IP 地址，所以发送 DHCP Discover 报文时，源 IP 地址只能写成 `0.0.0.0`；又因为它不知道 DHCP 服务器的确切位置，所以目的 IP 地址采用有限广播地址 `255.255.255.255`。

### （2）
主机 2 的 ARP 表为空，访问 Internet 前必须先获取默认网关的 MAC 地址，因此它先发 ARP 请求。ARP 请求在以太网层采用广播，目的 MAC 地址是标准广播地址 `ff-ff-ff-ff-ff-ff`。

主机 2 发往 Internet 的 IP 分组不能直接送往 Internet，而是先交给默认网关转发，所以封装该 IP 分组的以太网帧，其目的 MAC 地址应是路由器内网接口的 MAC 地址 `00-a1-a1-a1-a1-a1`。

### （3）
主机 1 的子网掩码是 `255.255.255.0`，其地址 `111.123.15.4` 与 WWW 服务器地址 `111.123.15.3` 同属 `111.123.15.0/24`，因此主机 1 可以直接访问 WWW 服务器。

但主机 1 的默认网关被配置为 `111.123.15.2`，而真正的路由器内网接口地址是 `111.123.15.1`。主机 1 访问 Internet 时，报文会交给错误的默认网关，无法被正确转发，因此不能访问 Internet。

## 易错点
- `255.255.255.255` 是 DHCP Discover 的目的 IP，不是目的 MAC。
- ARP 请求的目的 MAC 是广播地址，正确写法是 `ff-ff-ff-ff-ff-ff`。
- 是否能访问 Internet，关键看默认网关是否指向路由器接口，不是看主机和服务器是否在同一网段。
