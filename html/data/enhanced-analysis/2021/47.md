## 答案

（1）从 $t_0$ 到 $t_1$ 期间，H1 除了运行 HTTP，还运行了 `DNS`。  
该应用层协议报文从应用层到数据链路层的逐层封装为：`DNS` 报文 $\rightarrow$ `UDP` 数据报 $\rightarrow$ `IP` 数据报 $\rightarrow$ `CSMA/CD` 帧。

（2）$t_1$ 时刻交换机 $S$ 的交换表为：

| MAC 地址 | 端口 |
|---|---|
| `00-11-22-33-44-cc` | `4` |
| `00-11-22-33-44-bb` | `1` |
| `00-11-22-33-44-aa` | `2` |

（3）从 $t_0$ 到 $t_1$ 期间，H2 至少会接收到 $2$ 个与此次 Web 访问相关的帧。  
这 $2$ 个帧都是封装 `ARP` 请求报文的以太网广播帧，目的 MAC 地址均为 `FF-FF-FF-FF-FF-FF`。

## 解析

### （1）
H1 访问 `www.abc.com` 时，不能直接依据域名发送 HTTP 请求，必须先进行域名解析，获得对应的 IP 地址，因此在 HTTP 之前还要运行 `DNS` 协议。

`DNS` 使用 `UDP` 传输，因此其逐层封装过程为：

`DNS` 报文 $\rightarrow$ `UDP` 数据报 $\rightarrow$ `IP` 数据报 $\rightarrow$ 数据链路层帧

题目场景是以太网环境，所以数据链路层帧写为 `CSMA/CD` 帧。

### （2）
本问要根据从 $t_0$ 到 $t_1$ 之间实际发生的通信过程，确定交换机 $S$ 学到的表项。

$t_0$ 时，H1 的 ARP 表和 $S$ 的交换表都为空。H1 要完成本次 Web 访问，至少要先后完成两次地址解析：

1. 先访问本地域名服务器，查询 `www.abc.com` 对应的 IP 地址；
2. 获得服务器 IP 后，发现目的主机不在本局域网内，还需经路由器 $R$ 转发，因此要再解析默认网关 $R$ 的 MAC 地址。

据此分析交换机的学习过程：

1. H1 向本地域名服务器发起 `ARP` 请求。  
   该帧从端口 `4` 进入交换机，源 MAC 为 H1 的 `00-11-22-33-44-cc`，因此 $S$ 学到：
   `<00-11-22-33-44-cc, 4>`

2. 本地域名服务器向 H1 返回 `ARP` 响应。  
   该帧从端口 `1` 进入交换机，源 MAC 为 `00-11-22-33-44-bb`，因此 $S$ 学到：
   `<00-11-22-33-44-bb, 1>`

3. 随后 H1 还要解析路由器 $R$ 的 MAC 地址，再发送一次 `ARP` 请求。  
   该请求仍由 H1 发出，源 MAC 仍是 `00-11-22-33-44-cc`，对应端口仍为 `4`，不会产生新表项。

4. 路由器 $R$ 向 H1 返回 `ARP` 响应。  
   该帧从端口 `2` 进入交换机，源 MAC 为 `00-11-22-33-44-aa`，因此 $S$ 学到：
   `<00-11-22-33-44-aa, 2>`

因此，到 $t_1$ 时刻，交换机 $S$ 中共有 3 条表项：

| MAC 地址 | 端口 |
|---|---|
| `00-11-22-33-44-cc` | `4` |
| `00-11-22-33-44-bb` | `1` |
| `00-11-22-33-44-aa` | `2` |

### （3）
本问承接前一问的通信过程分析。

从 $t_0$ 到 $t_1$，与此次 Web 访问相关且会被局域网内其他主机无条件接收的，只有广播帧。题目又说明这段时间内没有其他无关通信，因此 H2 至少接收到的相关帧就是 H1 发出的两次 `ARP` 请求广播帧：

1. 为查询本地域名服务器 MAC 地址而发送的 `ARP` 请求帧；
2. 为查询路由器 $R$ MAC 地址而发送的 `ARP` 请求帧。

这两帧的目的 MAC 地址都是广播地址：

`FF-FF-FF-FF-FF-FF`

所以，H2 至少会接收到 $2$ 个相关帧，且它们都是封装 `ARP` 请求报文的以太网广播帧。

## 易错点

- 本题中 H1 在发送 HTTP 请求前，必须先进行 `DNS` 解析，不能只答 HTTP。
- `ARP` 请求是广播帧，`ARP` 响应是单播帧。
- 交换机学习的是“源 MAC 地址 + 入端口”，不是目的 MAC 地址。
- H2 不参与本次通信的主动过程，因此不会收到与此次访问相关的单播业务帧，只会收到广播帧。
