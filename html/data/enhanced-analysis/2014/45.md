## 答案

（1）`R2 = 1000`。

（2）数据 Cache 容量为 `512B`；指令 Cache 命中率为 `99.98%`。

（3）可能发生溢出异常的是加法求和那条指令；可能产生缺页异常的是访存取数组那条指令；数组 `A` 的访问至少读磁盘 `1` 次，查 `TLB` `1001` 次。

## 解析

### （1）
`R2` 对应循环变量 `i`。程序的循环条件是 `i < 1000`，循环结束时，`i` 已经自增到不满足条件，因此结束值为 `1000`。

所以，`R2 = 1000`。

### （2）
指令 Cache 共有 `16` 行，Cache 和主存交换的块大小为 `32B`，因此数据区容量为  
$$16 \times 32B = 512B$$

所以数据区容量是 `512B`。

再看指令命中率。程序段 `P` 共 `6` 条指令，占 `24B`，小于一个块的大小 `32B`；且其起始地址 `08048100H` 正好是块起始地址，因此这 `6` 条指令全部落在同一个主存块内。

程序开始时指令不在 Cache 中，第一次取指会发生缺失，把该块调入指令 Cache。此后在 1000 次循环执行中，其余取指都能命中，因此总共只有 `1` 次取指缺失。

按本题约定，程序共执行  
$$1000 \times 6 = 6000$$
次取指，所以命中率为  
$$\frac{6000-1}{6000}=99.98\%$$

### （3）
先看异常类型。

题目所对应的程序中，加法求和那条指令是 `sum += A[i]`。当数组元素值过大时，这条加法可能产生溢出异常。

访存取数组的那条指令可能产生缺页异常，因为数组 `A` 一开始不在主存中，第一次访问时会触发缺页。

所以：
- 可能发生溢出异常的是加法求和指令；
- 可能产生缺页异常的是取数组元素的访存指令。

再看磁盘和 `TLB` 访问次数。

数组 `A` 未调入主存，但所有数组元素都在同一页，而且该页存储在磁盘同一个扇区。第一次访问 `A[0]` 时会先发生缺页，然后把这一页从磁盘调入主存。由于后续访问的元素仍在同一页中，所以之后不再访盘。

因此，读磁盘至少 `1` 次。

至于 `TLB`，每次访问数组都要先做一次地址变换检查，因此 1000 次数组访问对应 1000 次 `TLB` 查询。第一次访问 `A[0]` 时，先查一次 `TLB`，发现缺页后处理中断；恢复后需要重新执行这次访问，又要再查一次 `TLB`。所以总次数为  
$$1000 + 1 = 1001$$

所以，数组 `A` 的访问至少读磁盘 `1` 次，查 `TLB` `1001` 次。

## 易错点

这题里 `TLB` 次数按本题约定是 `1001`，不是 `1000`。原因是第一次访问 `A[0]` 发生缺页后，要重做这一次访问，`TLB` 也要再查一次。
