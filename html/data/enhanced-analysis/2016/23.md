## 答案
A。仅Ⅱ、Ⅲ正确。

## 解析
Ⅰ错误。批处理系统的特点是作业成批处理，用户在作业运行过程中通常不能直接与计算机交互；“允许多个用户与计算机直接交互”是分时系统的特征。

Ⅱ正确。批处理系统按发展过程可分为单道批处理系统和多道批处理系统。

Ⅲ正确。中断技术使 CPU 在某个作业等待 I/O 时，能够转去执行其他作业；当 I/O 完成后，再由中断通知 CPU 返回处理原作业，因此多道批处理系统中 CPU 与 I/O 设备能够并行工作。

## 选项分析
- A. 仅Ⅱ、Ⅲ：正确。
- B. 仅Ⅱ：错误，Ⅲ也正确。
- C. 仅Ⅰ、Ⅱ：错误，Ⅰ错误。
- D. 仅Ⅰ、Ⅲ：错误，Ⅰ错误。

## 易错点
- 批处理系统和分时系统最容易混淆：前者强调成批、无直接交互，后者强调多用户轮流交互。
- “并行工作”这里指 CPU 与 I/O 设备可交替重叠工作，关键支撑是中断技术。
