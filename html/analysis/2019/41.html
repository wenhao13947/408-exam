1）算法的基本设计思想

目标序列需要依次取原链表的首结点、尾结点、次首结点、次尾结点。可先用快慢指针找到前半段的尾结点，将链表从中间断开；再原地逆置后半段；最后将前、后两段结点交叉合并。整个过程只使用常数个指针。

2）算法实现

void Rearrange(NODE *head) {
    if (head == NULL || head->next == NULL || head->next->next == NULL) {
        return;
    }

    NODE *slow = head->next;
    NODE *fast = head->next;
    while (fast->next != NULL && fast->next->next != NULL) {
        slow = slow->next;
        fast = fast->next->next;
    }

    NODE *second = slow->next;
    slow->next = NULL;

    NODE *previous = NULL;
    while (second != NULL) {
        NODE *next = second->next;
        second->next = previous;
        previous = second;
        second = next;
    }

    NODE *first = head->next;
    second = previous;
    while (second != NULL) {
        NODE *nextFirst = first->next;
        NODE *nextSecond = second->next;
        first->next = second;
        second->next = nextFirst;
        first = nextFirst;
        second = nextSecond;
    }
}

关键步骤是执行 slow->next = NULL，将前后两段彻底断开后再逆置后半段，否则旧的 next 指针可能形成环。

3）复杂度分析

寻找中点、逆置后半段和交叉合并均为 O(n)，因此总时间复杂度为 O(n)；只使用常数个辅助指针，空间复杂度为 O(1)。
