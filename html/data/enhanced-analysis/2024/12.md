## 答案
B，`j = -32759`。

## 解析
代码为：
```c
int i = 32777;
short si = i;
int j = si;
```

先看 `i = 32777`。  
$32777$ 接近 $2^{15}=32768$，可拆为：
$$
32777 = 2^{15} + 2^3 + 2^0 = 32768 + 8 + 1
$$

因此它在 32 位 `int` 中是一个正数，按补码表示并做符号扩展，最高位补 $0$。

接着执行 `short si = i`。  
`short` 只有 16 位，`int` 转 `short` 时应保留低 16 位，截掉高 16 位。  
所以 `si` 只保留 `32777` 的低 16 位，对应的补码是：
$$
1000\,0000\,0000\,1001
$$
这是一个 16 位有符号数，最高位为 $1$，表示负数。

再执行 `int j = si`。  
`short` 转 `int` 时要进行符号扩展。由于 `si` 的最高位是 $1$，所以扩展到 32 位时高 16 位补 $1$，得到：
$$
1111\,1111\,1111\,1111\,1000\,0000\,0000\,1001
$$

把这个补码转成真值：
$$
-2^{15} + 2^3 + 2^0 = -32768 + 8 + 1 = -32759
$$

所以 `j` 的值是 `-32759`。

## 选项分析
- A. `-32777`：不对。`int -> short` 之后发生的是截断并保留低 16 位，再经 `short -> int` 做符号扩展，结果不是原值取负。
- B. `-32759`：正确。对应低 16 位为 `1000 0000 0000 1001`，符号扩展后真值为 `-32759`。
- C. `32759`：不对。补码最高位为 `1`，说明结果是负数。
- D. `32777`：不对。`32777` 已经不能直接以 16 位 `short` 原样保存，转换后值发生改变。

## 易错点
- `int -> short` 时是“保留低位、截掉高位”。
- `short -> int` 时若是带符号数，要做符号扩展。
- 先判断最高位，再决定真值正负，比直接展开成十进制更稳。
