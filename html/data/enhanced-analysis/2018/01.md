## 答案
B. `15`。按栈操作依次执行 3 次 `F()` 后，`S1` 栈顶结果为 `15`。

## 解析
`F()` 的规则是：先从 `S1` 依次弹出两个操作数，记为 `A`、`B`；再从 `S2` 弹出一个运算符 `OP`；执行 `B OP A`；最后把结果压回 `S1`。

题干给定：
- `S1`：`5, 8, 3, 2`，其中 `2` 在栈顶
- `S2`：`×, −, +`，其中 `+` 在栈顶

依次模拟 3 次 `F()`：

第一次：
- 弹出 `A = 2`，`B = 3`
- 弹出运算符 `+`
- 计算 `3 + 2 = 5`
- 压回 `S1`，此时 `S1 = 5, 8, 5`

第二次：
- 弹出 `A = 5`，`B = 8`
- 弹出运算符 `−`
- 计算 `8 − 5 = 3`
- 压回 `S1`，此时 `S1 = 5, 3`

第三次：
- 弹出 `A = 3`，`B = 5`
- 弹出运算符 `×`
- 计算 `5 × 3 = 15`
- 压回 `S1`，此时 `S1` 只剩 `15`

所以，调用 3 次 `F()` 后，`S1` 栈顶保存的值是 `15`。

## 选项分析
- A. `-15`：与三次栈运算结果不符。
- B. `15`：正确。
- C. `-20`：与题目给定运算顺序和结果不符。
- D. `20`：与题目给定运算顺序和结果不符。

## 易错点
- 容易把运算顺序写反。这里必须按 `B OP A` 计算，不是 `A OP B`。
- 容易把栈顶元素看错。题干明确说明 `2` 在 `S1` 栈顶，`+` 在 `S2` 栈顶。
