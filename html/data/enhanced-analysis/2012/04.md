B

## 解析
题目给的是高度为 $6$ 的平衡二叉树，并且所有非叶结点的平衡因子都为 $1$。这对应的是该高度下**结点数最少**的平衡二叉树。

设高度为 $h$ 时，满足该条件的最少结点数为 $N_h$，则有递推关系：
$$N_h = N_{h-1} + N_{h-2} + 1$$

理由是：根结点的两个子树高度分别为 $h-1$ 和 $h-2$，且两棵子树都要取最少结点情形。

**图解：最少结点平衡树示意**

图中关注根的左右子树高度分别为 h-1 和 h-2 的结构。

![最少结点平衡树示意](/data/enhanced-analysis/assets/2012/04/original-analysis-1.svg)

由初值：
$$N_1 = 1,\quad N_2 = 2$$

依次计算：
$$N_3 = N_2 + N_1 + 1 = 2 + 1 + 1 = 4$$
$$N_4 = N_3 + N_2 + 1 = 4 + 2 + 1 = 7$$
$$N_5 = N_4 + N_3 + 1 = 7 + 4 + 1 = 12$$
$$N_6 = N_5 + N_4 + 1 = 12 + 7 + 1 = 20$$

所以结点总数为 **20**。

## 选项分析
A. 10：与高度为 6 时的最少结点数不符，偏小。  
B. 20：由递推 $N_6 = 12 + 7 + 1$ 得出，正确。  
C. 32：不是该最少结点情形的结果，偏大。  
D. 33：不是该最少结点情形的结果，偏大。

## 易错点
这题的关键是把“所有非叶结点的平衡因子均为 $1$”理解为**最少结点**的平衡二叉树，而不是一般平衡树。按最少结点递推可得 $C_6 = 20$。
