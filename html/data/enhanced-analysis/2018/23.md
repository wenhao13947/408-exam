## 答案

**C（仅Ⅰ、Ⅱ）**。  
多任务操作系统的核心是支持多个任务并发执行，并且必须处理共享资源保护问题；但它**不要求**必须运行在多 CPU 或多核硬件平台上。

## 解析

判断这道题，关键是先抓住“多任务操作系统”的本质：**在一个操作系统中，多个进程或多个任务可以交替推进，从而实现并发执行**。因此，只要系统能够支持多个任务并发运行，就可以称为多任务操作系统，而不是看它是否一定具备多核硬件。

题干中的 Ⅰ 说“具有并发和并行的特点”。其中，“并发”是多任务操作系统的基本特征，这一点没有问题。至于“并行”，从操作系统实际运行角度看，多任务环境下往往会体现出广义的并行性，例如一个进程占用 CPU 计算时，另一个进程可能正在等待或使用 I/O 设备，CPU 与 I/O 设备可以同时工作，因此教材和题解通常将其概括为具有并发和并行的特点，所以 Ⅰ 应判为正确。

Ⅱ 说“需要实现对共享资源的保护”，这也是多任务操作系统必须具备的能力。多个进程并发运行时，常常会竞争打印机、内存缓冲区、文件、变量等共享资源，尤其是临界资源。如果没有互斥、同步或调度协调机制，就会出现数据不一致、结果错误甚至系统混乱。因此操作系统必须对共享资源进行保护，Ⅱ 正确。

Ⅲ 说“需要运行在多 CPU 的硬件平台上”，这是错误的。**并发不等于必须多核或多 CPU**。即使只有单 CPU，操作系统也可以通过处理机调度和时间片轮转，使多个进程在宏观上“同时”向前推进，这就是单处理机上的并发。历史上，多任务操作系统早在单核 CPU 时代就已经存在，因此“必须运行在多 CPU 平台上”显然不成立。

综上，正确的是 Ⅰ、Ⅱ，错误的是 Ⅲ，答案选 **C**。

## 选项分析

**Ⅰ. 具有并发和并行的特点：正确**  
多任务操作系统首先必然具有并发性；在系统运行中，CPU 与 I/O 设备、不同功能部件之间又可能同时工作，因此通常也认为其体现出并行特征。

**Ⅱ. 需要实现对共享资源的保护：正确**  
多个任务并发执行时会竞争共享资源。为防止冲突，操作系统必须提供资源保护、互斥和协调机制。

**Ⅲ. 需要运行在多 CPU 的硬件平台上：错误**  
多任务操作系统不以多 CPU 为前提。单 CPU 系统同样可以通过调度实现多任务并发运行。

**A. 仅Ⅰ：错误**  
遗漏了Ⅱ。共享资源保护是多任务操作系统的重要要求。

**B. 仅Ⅱ：错误**  
遗漏了Ⅰ。多任务操作系统首先要支持并发运行。

**C. 仅Ⅰ、Ⅱ：正确**  
与题意和操作系统基本原理一致。

**D. Ⅰ、Ⅱ、Ⅲ：错误**  
错在Ⅲ，“多 CPU 硬件平台”不是多任务操作系统的必要条件。

## 易错点

**并发**与**并行**不要混淆：  
并发强调“多个任务在一段时间内交替推进”，单 CPU 也能实现；并行强调“同一时刻确有多个执行活动同时进行”，通常需要多个执行部件参与。考试中若题目把多任务系统概括为具有并发和并行特点，一般按教材表述判 Ⅰ 正确。

看到“多任务”不要直接联想到“多核”或“多 CPU”。  
多任务是操作系统调度与管理能力的问题，不是必须依赖多处理器硬件。
