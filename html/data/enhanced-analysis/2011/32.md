## 答案
选 `C`，`x` 可能为 `0、1、2`。

## 解析
本题考查并发进程对共享变量 `x` 的访问结果。`P1` 执行 `x+1`，`P2` 执行 `x-1`，但两者都不是原子操作，因此最终结果取决于取数与存数的先后顺序。

先把两进程中的指令编号。设 `P1` 的三条指令依次为 `1,2,3`，`P2` 的三条指令依次为 `4,5,6`。分析时只需判断两类情况：

- **一方的取数发生在另一方存数之后**  
  这时后一方会读到前一方修改后的结果，属于“基于对方结果”的执行。  
  无论是 `P2` 基于 `P1`，还是 `P1` 基于 `P2`，最终都可得到 `x=1`。

- **双方的取数都发生在对方存数之前**  
  这时两边读到的都是初值 `1`，即都按原值计算。  
  最终写回时，谁最后执行“存数”那条指令，结果就由谁决定：
  - 若最后执行的是 `P1` 的加法写回，则 `x=2`
  - 若最后执行的是 `P2` 的减法写回，则 `x=0`

因此，所有可能结果只有 `0、1、2`。

## 选项分析
- `A`：`-1` 或 `3` 不可能出现。`x` 的初值是 `1`，并发冲突下只会出现一次加或减的覆盖结果，或者按同一初值计算后的最终写回，不会跳到这两个值。
- `B`：错误。除 `1` 外，还可能出现 `0` 或 `2`。
- `C`：正确。最终结果只能是 `0、1、2`。
- `D`：错误。`-1` 不成立，本题并发交错下不会得到该值。

## 易错点
- 把 `x=x+1`、`x=x-1` 误当成原子操作，会漏掉 `0` 和 `2`。
- 只盯着“加 1 / 减 1”的表面结果，忽略了“先取数、后存数”的交错竞争。
