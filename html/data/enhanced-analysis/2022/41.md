## 答案

二叉搜索树的充要条件是：对二叉树做中序遍历，得到的非空结点值序列严格递增。  
因此，本题采用“递归中序遍历 + 记录已访问结点最大值”的方法判断：若遍历过程中出现当前结点值不大于前一个访问值，则返回 `false`；否则遍历结束返回 `true`。

## 解析

### （1）基本设计思想

题目采用顺序存储方式，根结点存放在 `SqBiTNode[0]` 中。若结点下标为 `i`，则其左孩子、右孩子、双亲结点下标分别为：

- 左孩子：`2i+1`
- 右孩子：`2i+2`
- 双亲：`(i-1)/2`

判断二叉搜索树最直接的方法是利用其性质：**BST 的中序遍历序列严格递增**。  
因此，设计递归中序遍历过程，按“左子树 - 根结点 - 右子树”的顺序访问结点，并用整型变量 `val` 记录当前已经访问过的最大值。

具体做法是：

1. 先递归遍历左子树。
2. 再访问当前结点，若当前结点值 `cur_val` 大于 `val`，则更新 `val = cur_val`；否则说明中序序列不递增，直接判定不是 BST。
3. 最后递归遍历右子树。
4. 若整棵树遍历过程中始终满足严格递增，则该树是 BST。

### （2）算法实现

```c
// val 存储中序遍历过程中访问到的最大值
// 返回值：以 k 为根的子树是否为 BST
bool solve(SqBiTree *tree, int k, int *val) {
    // 越界，视为空结点
    if (k >= tree->ElemNum) {
        return true;
    }

    // 先判断左子树
    if (!solve(tree, 2 * k + 1, val)) {
        return false;
    }

    // 当前结点为空结点
    if (tree->SqBiTNode[k] == -1) {
        return true;
    }

    // 判断中序序列是否严格递增
    if (tree->SqBiTNode[k] > *val) {
        *val = tree->SqBiTNode[k];
    } else {
        return false;
    }

    // 再判断右子树
    return solve(tree, 2 * k + 2, val);
}
```

## 易错点

`-1` 表示空结点，不能参与 BST 的大小比较；实际比较时只针对非空结点。  
另外，BST 要求中序遍历结果是**严格递增**，因此相等也应判为 `false`。
