## 答案

**C，命中 Cache 3 次。**  
理由是：本题按标准答案所采用的 **2 路组相联映射规则** 进行地址分组后，访问序列 `0,4,8,2,0,6,8,6,4,8` 在按 **LRU** 替换时共命中 3 次。

## 解析

题干给出：

- Cache 共 4 行；
- 采用 **2 路组相联**，因此可分为 **2 组**，每组 **2 行**；
- 块大小为 1 个字，且按字编址，因此“主存块号”可直接看作题中的访问地址；
- 初始 Cache 为空；
- 替换策略为 **LRU**。

本题的关键不在 LRU 本身，而在于 **组相联映射时主存块到 Cache 组的对应规则**。按照本题标准答案采用的规则：

- 第 0 组可装入的块号为：`0,1,4,5,8,9,...`
- 第 1 组可装入的块号为：`2,3,6,7,...`

也可以概括为：

- 地址 `0,4,8` 都映射到 **第 0 组**
- 地址 `2,6` 都映射到 **第 1 组**

因此，可把整个访问序列拆成两组分别考虑：

- 第 0 组访问子序列：`0,4,8,0,8,4,8`
- 第 1 组访问子序列：`2,6,6`

每组都有 2 个 Cache 行，组内按 LRU 替换。

### 第 0 组的变化过程

第 0 组容量为 2，访问序列为 `0,4,8,0,8,4,8`：

1. 访问 `0`：未命中，装入  
   组内状态可记为 `{0}`

2. 访问 `4`：未命中，装入  
   组内状态 `{0,4}`

3. 访问 `8`：未命中，组已满，按 LRU 淘汰最久未使用的 `0`  
   组内状态 `{4,8}`

4. 访问 `0`：未命中，淘汰最久未使用的 `4`  
   组内状态 `{8,0}`

5. 访问 `8`：**命中**  
   组内状态仍为 `{8,0}`，但 `8` 变为最近使用

6. 访问 `4`：未命中，淘汰最久未使用的 `0`  
   组内状态 `{8,4}`

7. 访问 `8`：**命中**

所以，第 0 组共命中 **2 次**。

### 第 1 组的变化过程

第 1 组访问序列为 `2,6,6`：

1. 访问 `2`：未命中，装入  
   组内状态 `{2}`

2. 访问 `6`：未命中，装入  
   组内状态 `{2,6}`

3. 访问 `6`：**命中**

所以，第 1 组共命中 **1 次**。

### 总命中次数

总命中次数为：

$$
2 + 1 = 3
$$

因此正确答案为 **C**。

## 选项分析

A. **1**  
错误。这个结果来自另一种常见的组相联映射讲法：先把 4 个 Cache 行分成两组，每组对应连续主存分区，再在组内做全相联替换。按那种规则模拟，这道题确实可能得到 1 次命中；但**本题标准答案并未采用该规则**，因此不能选 A。

B. **2**  
错误。按本题标准答案采用的映射规则与 LRU 过程推导，总命中次数是 3 次，不是 2 次。

C. **3**  
正确。第 0 组命中 2 次，第 1 组命中 1 次，共 3 次。

D. **4**  
错误。第 0 组中块 `0、4、8` 反复竞争两个位置，发生了多次替换，不可能达到 4 次命中。

## 易错点

- **易错点 1：混淆不同教材中的组相联映射规则。**  
  本题最容易错在这里。若按另一套常见规则推导，会得到 **A**；但题目标准答案采用的是另一种映射方式，所以考试中应以题目答案及其对应规则为准。

- **易错点 2：没有先分组，再在组内做 LRU。**  
  2 路组相联不是“4 行一起做 LRU”，而是应先确定块属于哪一组，再在该组的 2 行中判断命中与替换。

- **易错点 3：块大小为 1 个字时，地址就是块号。**  
  因为按字编址且块大小正好是 1 个字，所以不需要再做块内地址划分，题中的 `0,4,8,2,...` 可直接作为主存块号处理。

- **检查方法**  
  先把访问序列按组拆开：
  - 第 0 组：`0,4,8,0,8,4,8`
  - 第 1 组：`2,6,6`  
  然后分别按“2 个位置的 LRU”独立计算，结果最稳妥。
