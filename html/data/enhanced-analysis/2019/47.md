## 答案

### （1）
- 设备 1：路由器
- 设备 2：以太网交换机
- 设备 3：以太网交换机

### （2）
需要配置 IP 地址的只有设备 1 的接口，配置为：
- `IF1 = 192.168.1.254/30`
- `IF2 = 192.168.1.1/26`
- `IF3 = 192.168.1.65/26`

设备 2、设备 3 为无 VLAN 功能的以太网交换机，其接口不需要按题意配置 IP 地址。

### （3）
R 需要提供 `NAT`（网络地址转换）服务。

### （4）
会接收该数据报的主机只有 `H4`。

## 解析

### （1）
先按主机地址和掩码划分子网：

- H1：`192.168.1.2/26`
- H2：`192.168.1.3/26`

这两台主机同属子网 `192.168.1.0/26`。

- H3：`192.168.1.66/26`
- H4：`192.168.1.67/26`

这两台主机同属子网 `192.168.1.64/26`。

因此，题图中实际有两个不同的局域网。结合题图可见，设备 2 连接 H1、H2，设备 3 连接 H3、H4，它们都只承担同一子网内部的互连，选用以太网交换机即可；而设备 1 位于两个不同子网之间，还要与上方的 R 相连，必须具备三层转发能力，所以应为路由器。

结论为：
- 设备 1 选路由器；
- 设备 2、设备 3 选以太网交换机。

### （2）
这一问承接第（1）问。既然设备 1 是路由器，而设备 2、设备 3 是二层交换机，那么需要配置 IP 地址的只有设备 1 的各个三层接口。

先看与 R 直连的 `IF1`。

题图已给出，R 的对应接口地址是 `192.168.1.253/30`。  
`/30` 子网掩码表示每段有 4 个地址，因此包含 `192.168.1.253` 的这个子网为：

- 网络地址：`192.168.1.252`
- 可用主机地址：`192.168.1.253`、`192.168.1.254`
- 广播地址：`192.168.1.255`

其中 `192.168.1.253` 已被 R 占用，所以设备 1 的 `IF1` 应配置为：

- `IF1 = 192.168.1.254/30`

再看连接 H1、H2 所在 LAN 的接口。题图中 H1 和 H2 的默认网关都配置为 `192.168.1.1`，默认网关就是本子网所连路由器接口的地址，因此设备 1 接入该子网的接口地址应为：

- `IF2 = 192.168.1.1/26`

同理，H3 和 H4 的默认网关都为 `192.168.1.65`，所以设备 1 接入该子网的接口地址应为：

- `IF3 = 192.168.1.65/26`

整理如下：

| 设备 | 接口 | IP 地址 |
|---|---|---|
| 设备 1 | IF1 | `192.168.1.254/30` |
| 设备 1 | IF2 | `192.168.1.1/26` |
| 设备 1 | IF3 | `192.168.1.65/26` |

因此，只有设备 1 的接口需要配置 IP 地址；设备 2、设备 3 不需要。

### （3）
H1～H4 的地址分别是 `192.168.1.x`，属于 `192.168.0.0/16` 私有地址空间。私有地址不能直接作为公网可路由地址在 Internet 上通信。

题图中从 R 往上连接 Internet，且出现公网地址环境，因此要让这些内网主机访问 Internet，R 必须把内网私有地址转换成可用于外网通信的地址。为此，R 需要提供的服务是：

- `NAT`（网络地址转换）

### （4）
这一问与前几问的设备选型无关，直接根据 H3 所在子网和目的地址判断即可。

H3 的地址是 `192.168.1.66/26`，所以它所在子网为 `192.168.1.64/26`。  
`/26` 表示每个子网有 64 个地址，因此该子网范围为：

- 网络地址：`192.168.1.64`
- 主机地址：`192.168.1.65` ～ `192.168.1.126`
- 广播地址：`192.168.1.127`

可见，`192.168.1.127` 正是 H3 所在子网的广播地址。读图时可以注意，H3、H4 与设备 1 的一个接口处在同一局域网，而路由器不会把广播转发到另一个广播域。

因此：
- H1、H2 不会接收该数据报；
- 同一子网中的另一台主机 H4 会接收该数据报。

题目问的是“哪几个主机会接收”，所以答案只写：

- `H4`

## 易错点

1. 不要把 H1～H4 误判为同一网段。  
`/26` 的地址块大小是 64，`192.168.1.2` 与 `192.168.1.66` 分别属于 `192.168.1.0/26` 和 `192.168.1.64/26`，不是同一子网。

2. 不要给交换机接口配置题设所需的三层地址。  
本题明确可选的是“无 VLAN 功能”的以太网交换机，它只负责二层转发；按题意需要配置 IP 的是承担路由功能的设备 1。

3. 第（4）问只问“主机”。  
广播报文在该子网内也会到达设备 1 连接 LAN2 的接口，但该接口不属于“主机”，因此按评分口径只答 `H4`。
