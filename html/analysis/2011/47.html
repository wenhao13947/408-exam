1）以太网帧的数据部分是 IP 数据报，只要数出相应字段所在的字节即可。由图可知，以太网帧头部有 6+6+2=14 字节，IP 数据报首部的目的 IP 地址字段前有 4×4=16 字节。从帧的第 1 字节开始数 14+16=30 字节，得到目的 IP 地址 40.aa.62.20（十六进制），转换成十进制为 64.170.98.32。以太网帧的前 6 字节 00-21-27-21-51-ee 是目的 MAC 地址，即主机默认网关 10.2.128.1 所对应接口的 MAC 地址。

2）ARP 协议用于解决 IP 地址到 MAC 地址的映射问题。主机的 ARP 进程在本以太网内以广播形式发送 ARP 请求分组，广播帧的目的 MAC 地址为全 1，即 FF-FF-FF-FF-FF-FF。

3）HTTP/1.1 协议以持续的非流水线方式工作时，服务器发送响应后仍会在一段时间内保持连接，客户机收到前一个请求的响应后才能发出下一个请求。第一个 RTT 用于请求 Web 页面；客户机收到页面后还有 5 个对象需要依次请求，每个对象需要 1 个 RTT。因此共需 1+5=6 个 RTT，浏览器才能收到全部内容。

4）源 IP 地址由 0a.02.80.64 改为 65.0c.7b.0f，生存时间（TTL）减 1，首部校验和重新计算。私有地址主机与 Internet 主机通信时，NAT 路由器将 IP 数据报的源 IP 地址 10.2.128.100 转换为全球 IP 地址 101.12.123.15，因此源 IP 地址字段由 0a 02 80 64 变为 65 0c 7b 0f。IP 数据报每经过一个路由器，TTL 都要减 1，并重新计算首部校验和。若 IP 分组长度超过输出链路的 MTU，总长度字段、标志字段和片偏移字段也会发生变化。

注意：题 47-b 图中每行前 4 bit 是数据帧的字节计数，不属于以太网数据帧的内容。

【评分说明】若考生解答时将所有 IP 首部字段全部罗列而未指出实际发生变化的字段，不给分；其他合理情况酌情给分。
