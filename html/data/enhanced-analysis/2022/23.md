## 答案
D。多道程序系统强调并发与共享，但“进程数越多，CPU 利用率越高”不成立。

## 解析
多道程序系统的核心目的是让多个作业/进程在一段时间内并发执行，借此提高系统资源利用率。其运行过程中，作业先进入外存形成后备队列，再由作业调度调入内存，进入执行阶段后共享 CPU 和其他资源。

题干问的是“下列关于多道程序系统的叙述中，不正确的是”。逐项判断：
- 并发执行是多道程序系统的基本特征之一，因此支持进程并发执行是对的。
- 多道程序系统并不要求一定具备虚拟存储管理，早期系统也可以在不支持虚拟存储的情况下运行，因此这项不构成错误。
- 由于多个进程可能同时访问共享资源，所以必须进行共享资源管理，这项正确。
- CPU 利用率不是由进程数量单独决定的。若进程大多处于等待资源状态，或者资源竞争严重，增加进程数并不会提高 CPU 利用率，甚至可能降低利用率。因此 D 错。

## 选项分析
A. 支持进程的并发执行：正确。多道程序系统的本质就是让多个进程并发推进。  
B. 不必支持虚拟存储管理：正确。多道程序系统可以在不依赖虚拟存储的条件下实现。  
C. 需要实现对共享资源的管理：正确。并发执行必然带来共享资源竞争。  
D. 进程数越多 CPU 利用率越高：错误。进程过多可能带来等待、竞争甚至死锁，不能保证 CPU 利用率上升。

## 易错点
- “多进程”不等于“高 CPU 利用率”，关键还要看进程是否频繁等待 I/O 或资源。
- “并发执行”是多道程序系统的核心特征，但并发本身也要求共享资源管理到位。
