## 答案

选 **D. Ⅰ、Ⅱ、Ⅲ**。

## 解析

本题考查 `I/O 总线` 各类线路上传输信息的类型区分。

`I/O 总线` 一般包括 `数据线、地址线、控制线`：

- `地址线`：用于传送 `I/O 端口地址` 或被访问对象的地址信息；
- `控制线`：用于传送 `读/写、中断请求、总线请求、响应、时序` 等控制信号；
- `数据线`：用于传送具有实际内容的多位信息，如 `数据、命令字、状态字、中断类型号` 等。

因此，题干中的三项都应通过 `I/O 总线的数据线` 传输：

| 项目 | 是否经数据线传输 | 原因 |
|---|---|---|
| `Ⅰ. I/O 接口中的命令字` | 是 | 命令字用于指出设备执行何种具体操作，属于多位编码信息，不是简单控制信号 |
| `Ⅱ. I/O 接口中的状态字` | 是 | 状态字用于反映接口或设备状态，通常由若干位组成，属于数据线传送内容 |
| `Ⅲ. 中断类型号` | 是 | 中断类型号用于标识中断类别，供 CPU 进一步确定中断服务程序，属于数据线传送的信息 |

所以应选 `D`。

命令字由 CPU 送往 I/O 接口，状态字和中断类型号由接口侧提供给 CPU；本题问的是哪些信息在数据线上传输，因此三者都经过数据线。

结合视频内容也能印证这一点：控制线更适合传送“是否读、是否写、是否请求中断”这类简单控制信号；而命令字、状态字、中断类型号都不是简单的二值控制信息，应走数据线。

## 选项分析

**A. 仅Ⅰ、Ⅱ**  
错误。`Ⅲ. 中断类型号` 也在 `I/O 总线的数据线` 上传输，因此不能排除 `Ⅲ`。

**B. 仅Ⅰ、Ⅲ**  
错误。`Ⅱ. I/O 接口中的状态字` 同样属于数据线传输的信息，因此不能排除 `Ⅱ`。

**C. 仅Ⅱ、Ⅲ**  
错误。`Ⅰ. I/O 接口中的命令字` 也是通过数据线传输的，因此不能排除 `Ⅰ`。

**D. Ⅰ、Ⅱ、Ⅲ**  
正确。`命令字、状态字、中断类型号` 都属于应在 `I/O 总线的数据线` 上传输的信息。

## 易错点

1. 容易把“控制信息”都误判为走控制线。  
要注意：`控制线` 上传的是 `读/写、中断请求、时序、响应` 这类控制信号；而 `命令字` 虽然名字里有“命令”，本质上仍是一个多位编码字，应走 `数据线`。

2. 容易混淆 `中断请求信号` 和 `中断类型号`。  
- `中断请求信号`：属于控制线上的信号；  
- `中断类型号`：属于数据线上传输的内容。  
本题考的是后者。

3. 不要被传输方向的直觉带偏。  
本题只判断“是否在数据线上传输”，不判断“由谁发给谁”。即使方向不同，也不影响本题结论。
