这是生产者-消费者问题的变形。缓冲区容量为 1000，初始为空；同时要求一个消费者连续取出 10 件产品期间，其他消费者不能取产品。

设置信号量如下：

  • consumer_mutex：控制消费者以 10 次取产品为一个周期互斥，初值为 1。
  • buffer_mutex：控制进程互斥访问环形缓冲区，初值为 1。
  • empty：缓冲区空位数，初值为 1000。
  • full：缓冲区已有产品数，初值为 0。
semaphore consumer_mutex = 1;
semaphore buffer_mutex = 1;
semaphore empty = 1000;
semaphore full = 0;

Producer() {
    while (1) {
        生产产品;
        P(empty);
        P(buffer_mutex);
        将产品放入缓冲区;
        V(buffer_mutex);
        V(full);
    }
}

Consumer() {
    while (1) {
        P(consumer_mutex);
        for (int i = 0; i < 10; i++) {
            P(full);
            P(buffer_mutex);
            从缓冲区取出产品;
            V(buffer_mutex);
            V(empty);
            消费产品;
        }
        V(consumer_mutex);
    }
}

说明：生产产品本身不访问共享缓冲区，可以放在 P(empty) 之前；真正需要等待空位的是“放入缓冲区”这一步。
