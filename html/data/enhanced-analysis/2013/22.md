## 答案

**D 错误。**  
因为中断 I/O 方式并不适用于所有外部设备，DMA 方式也并非仅适用于快速外部设备，D 的两句话都说得过于绝对。

## 解析

判断这道题的关键，是分清 **中断 I/O** 和 **DMA** 在“请求对象、响应时机、数据传送者、适用场景”上的区别。

中断 I/O 方式下，外设准备好一个数据后，通过中断请求 CPU 进行处理。CPU 在一条指令执行结束后响应中断，再由中断服务程序完成数据传送，因此它本质上请求的是 **CPU 处理时间**，数据传送是在 **软件控制** 下完成的。

DMA 方式下，数据传送由 **DMA 控制器** 直接完成，CPU 只需在传送开始前后进行少量干预。DMA 控制器为了在内存和外设之间传送数据，需要申请 **总线使用权**；DMA 的响应通常发生在 **一个总线事务完成之后**，而不是像中断那样等一条指令执行完。因此 DMA 的数据传送属于 **硬件完成**。

据此可知：

- A 说中断 I/O 请求 CPU 处理时间，DMA 请求总线使用权，正确。
- B 说中断响应在一条指令结束后，DMA 响应在一个总线事务完成后，正确。
- C 说中断 I/O 的数据传送通过软件完成，DMA 的数据传送由硬件完成，正确。
- D 错在两个地方：
  - “中断 I/O 方式适用于所有外部设备”错误。若外设速度很高，而 CPU 执行中断服务程序的速度跟不上，可能在前一次数据尚未处理完时，后续数据又到达，造成数据寄存器被覆盖，发生传输错误，因此中断方式并不适合所有外设，尤其不适合过快的设备。
  - “DMA 方式仅适用于快速外部设备”也错误。DMA 的确 **更适合** 高速、大批量数据传送设备，但并不表示慢速设备绝对不能使用 DMA。只是 DMA 需要额外硬件支持，成本更高，在低速设备场景下往往没有必要。

因此，错误选项为 **D**。

## 选项分析

### A. 中断 I/O 方式请求的是 CPU 处理时间，DMA 方式请求的是总线使用权

**正确。**

- 中断方式中，外设通过中断让 CPU 来处理数据，因此核心是请求 CPU 的服务时间。
- DMA 方式中，DMA 控制器要在主存和外设之间直接传送数据，关键是获得总线控制权。

### B. 中断响应发生在一条指令执行结束后，DMA 响应发生在一个总线事务完成后

**正确。**

- 中断响应具有“指令执行完再响应”的特征。
- DMA 为了不破坏当前总线操作，通常在当前总线事务结束后再响应 DMA 请求。

### C. 中断 I/O 方式下数据传送通过软件完成，DMA 方式下数据传送由硬件完成

**正确。**

- 中断 I/O 中，数据传送依赖 CPU 执行中断服务程序，因此是软件完成。
- DMA 中，真正的数据搬运由 DMA 控制器完成，因此是硬件完成。

### D. 中断 I/O 方式适用于所有外部设备，DMA 方式仅适用于快速外部设备

**错误。**

- 前半句错误：中断 I/O 并非适用于所有外设。对于高速设备，CPU 可能来不及处理频繁中断，容易丢失数据。
- 后半句错误：DMA 并非“仅”适用于快速设备。它是更适合高速、大批量传输，但不是对慢速设备绝对不可用。

## 易错点

- 容易把“**更适合**”误判成“**只能用于**”。题目中出现“仅适用于”“所有设备”这类绝对化表述时，要特别警惕。
- 不要混淆“谁完成数据传送”：
  - 中断 I/O：CPU 执行中断服务程序，属于**软件传送**。
  - DMA：DMA 控制器直接搬运数据，属于**硬件传送**。
- 不要混淆“响应时机”：
  - 中断：一条**指令**结束后响应。
  - DMA：一个**总线事务**结束后响应。
