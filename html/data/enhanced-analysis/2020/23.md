## 答案

**B**。因为同一个已打开文件在**系统打开文件表**中只有一个表项保存其文件属性，多个进程共享的是这一系统级表项，而不是各自复制一份文件属性。

## 解析

本题考查“系统打开文件表”和“用户打开文件表（进程打开文件表）”的区别。

当多个进程共享同一个文件 `F` 时，操作系统通常分两层管理：

- **系统打开文件表**：系统范围内唯一，用来记录打开文件的公共信息，如文件属性、外存位置、打开计数等。
- **用户打开文件表**：每个进程各自拥有，用来记录该进程与文件相关的信息，如访问方式、当前读写位置，以及指向系统打开文件表对应表项的索引。

据此可判断：

- 同一个文件 `F` 被多个进程打开时，系统层面不会为每个进程都复制一份文件属性，而是由**一个系统级表项**统一记录，因此 **B 正确**。
- 进程级表项并不完全相同，因为不同进程对同一文件的**访问权限**可能不同，**读写指针**也往往不同，所以 **C 错误**。
- 进程关闭文件时，系统打开文件表中的对应表项不会立刻删除，而是先将**打开计数（引用计数）减 1**；只有当计数减为 0 时，才删除该系统级表项，所以 **D 错误**。
- 多个进程并不只能以只读方式打开同一文件；它们也可能同时以写方式打开，只是若要保证互斥写入，通常需要借助加锁机制，因此 **A 错误**。

## 选项分析

**A. 各进程只能用“读”方式打开文件 F**

错误。多个进程可以同时打开同一文件，并不限定只能读打开。它们也可以以写方式打开；至于是否允许并发写、如何避免写冲突，是由文件共享控制或加锁机制解决，不是“只能读”的问题。

**B. 在系统打开文件表中仅有一个表项包含 F 的属性**

正确。系统打开文件表是全系统共享的；对于同一个正在打开的文件，系统中通常只有一个对应表项保存该文件的公共属性和状态信息，多个进程通过各自的用户打开文件表去引用它。

**C. 各进程的用户打开文件表中关于 F 的表项内容相同**

错误。用户打开文件表是进程私有的。即使都指向同一个文件 `F`，各进程中的表项内容也可能不同，至少包括：

- 打开方式可能不同，如只读、只写、读写；
- 当前读写位置可能不同，即文件读写指针不同。

因此“内容相同”不成立。

**D. 进程关闭 F 时，系统删除 F 在系统打开文件表中的表项**

错误。关闭文件时，只是把该文件在系统打开文件表中的打开计数减 1；只有当没有任何进程再打开该文件，即计数变为 0 时，系统才会删除该表项。

## 易错点

- 不要把**系统打开文件表**和**用户打开文件表**混为一谈。前者是系统级、共享的；后者是进程级、私有的。
- “共享同一文件”不等于“各进程对该文件的打开状态完全相同”。共享的是文件本身及其系统级记录，不是进程级的读写位置和访问方式。
- 判断关闭文件是否删除表项时，关键看**打开计数是否为 0**，而不是“是否有某一个进程执行了关闭操作”。
