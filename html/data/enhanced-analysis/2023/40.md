## 答案
选 **D**，即 **仅 III、IV 正确**。

## 解析
先判断题干四个断言：

- **I 错误**。IPv4 地址长度是 $32$ 位，IPv6 地址长度是 $128$ 位，地址空间大小分别是 $2^{32}$ 和 $2^{128}$。二者之比为  
  $$\frac{2^{128}}{2^{32}}=2^{96}$$  
  不是“96倍”，而是“$2^{96}$ 倍”。

- **II 错误**。IPv4 首部长度可变，最小 $20$ 字节，最大 $60$ 字节。IPv6 的**基本首部**长度固定为 $40$ 字节，扩展首部属于有效载荷的一部分，不计入基本首部长度，所以“基本首部长度均可变”不对。

- **III 正确**。IPv4 向 IPv6 过渡时，可以采用 **双协议栈（Dual Stack）** 和 **隧道技术（Tunnel）**。

- **IV 正确**。IPv6 的 **Hop-Limit** 与 IPv4 的 **TTL** 作用等价，都是为了防止数据报在网络中无限转发；路由器每转发一次就减 1，减到 0 则丢弃。

因此，正确选项是 **D**。

## 选项分析
- **A**：包含 I、II，均错。
- **B**：I 错，IV 对。
- **C**：II 错，III 对。
- **D**：III、IV 都正确。

## 易错点
- “地址空间相差 $2^{96}$ 倍”不能误写成“96 倍”。
- IPv6 的 **基本首部** 固定 40 字节；扩展首部不算在基本首部里。
- **Hop-Limit** 本质上就是 IPv4 的 **TTL** 的对应字段。
