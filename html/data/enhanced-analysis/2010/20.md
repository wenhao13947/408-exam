## 答案

**D**。因为 `ISA`、`EISA`、`PCI`、`PCI-Express` 均属于总线标准；其余选项都混入了非总线标准术语。

## 解析

本题考查的是对常见英文缩写所代表概念的辨别，关键是判断它们是否都属于“总线标准”。

总线标准是计算机中用于规范设备互连、数据传输方式和接口形式的一类标准。常见的总线标准包括：

- `ISA`
- `EISA`
- `VESA`
- `PCI`
- `PCI-Express`
- `AGP`
- `USB`
- `RS-232C`

据此检查各选项，只要其中有一个不是总线标准，该项就不能选。

题目给出的标准答案是 **D**，这一点与可验证的常识一致：

- `ISA`：工业标准体系结构（Industry Standard Architecture），属于总线标准。
- `EISA`：扩展工业标准体系结构（Extended ISA），属于总线标准。
- `PCI`：外设部件互连（Peripheral Component Interconnect），属于总线标准。
- `PCI-Express`：高速串行扩展总线标准，属于总线标准。

因此，只有 **D** 中四项全部满足题意。

## 选项分析

**A. PCI、CRT、USB、EISA**

错误。`PCI`、`USB`、`EISA` 都可视为总线或接口标准，但 `CRT` 不是总线标准。`CRT` 指阴极射线管显示器（Cathode Ray Tube），是显示设备相关术语。

**B. ISA、CPI、VESA、EISA**

错误。`ISA`、`VESA`、`EISA` 都属于总线标准，但 `CPI` 不是。`CPI` 表示每条指令平均时钟周期数（Cycles Per Instruction），是 CPU 性能指标。

**C. ISA、SCSI、RAM、MIPS**

错误。`ISA` 是总线标准；`SCSI` 常作为接口/总线相关标准看待，但本项中的 `RAM` 和 `MIPS` 明显不是总线标准，因此整项错误。  
- `RAM`：随机存取存储器（Random Access Memory），是存储器类型。  
- `MIPS`：每秒执行百万条指令数（Million Instructions Per Second），是性能指标。

**D. ISA、EISA、PCI、PCI-Express**

正确。四者均为总线标准，完全符合题意。

## 易错点

- 不要把“显示器术语”“性能指标”“存储器类型”误判为总线标准，例如 `CRT`、`CPI`、`RAM`、`MIPS`。
- 这类题通常不是考定义细节，而是考“缩写分类”。做题时可先排除明显不属于总线标准的术语，速度更快。
- `USB` 虽常被当作外部总线标准，但本题不需要比较边界概念，只需判断“整项是否全对”。A 项因为 `CRT` 已经必错。
