## 答案

### （1）基本设计思想

对固定的 `i`，需要在后缀子数组 `A[i..n-1]` 中选一个 `A[j]`，使 `A[i] * A[j]` 最大。

关键在于：最优的 `A[j]` 只可能是当前后缀中的最大值或最小值。

- 若 `A[i] > 0`，乘积随另一因子增大而增大，因此应选后缀最大值；
- 若 `A[i] < 0`，乘积随另一因子增大而减小，因此应选后缀最小值；
- 若 `A[i] = 0`，则结果一定为 `0`。

因此可从右向左扫描数组，在扫描过程中维护当前后缀 `A[i..n-1]` 的：

- 最大值 `maxValue`
- 最小值 `minValue`

扫描到位置 `i` 时，先用 `A[i]` 更新这两个后缀极值，再根据 `A[i]` 的符号计算 `res[i]`。这样只需一次扫描即可求出全部结果。

### （2）算法描述

```cpp
void calMulMax(int A[], int res[], int n) {
    int minValue = INT_MAX;   // 当前后缀最小值
    int maxValue = INT_MIN;   // 当前后缀最大值

    for (int i = n - 1; i >= 0; --i) {
        // 先把 A[i] 纳入当前后缀 A[i..n-1]
        if (A[i] < minValue) {
            minValue = A[i];
        }
        if (A[i] > maxValue) {
            maxValue = A[i];
        }

        // 根据 A[i] 的符号选择最优乘数
        if (A[i] > 0) {
            res[i] = A[i] * maxValue;
        } else if (A[i] < 0) {
            res[i] = A[i] * minValue;
        } else {
            res[i] = 0;
        }
    }
}
```

### （3）时间复杂度和空间复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`

## 解析

### 解法一：暴力法

对每个位置 $i$，枚举所有 $j\in[i,n-1]$，计算 $A[i]\times A[j]$ 并维护最大值。两层循环即可完成，时间复杂度为 $O(n^2)$，空间复杂度为 $O(1)$。

### 解法二：优化解法

从右向左维护后缀最大值和最小值。对固定的 $A[i]$，最大乘积只可能来自后缀最大值或后缀最小值，因此每个位置只需常数次比较，总时间复杂度为 $O(n)$。

> **考场建议：** 先写双层循环保证每个 `res[i]` 都有定义，再观察内层循环反复寻找后缀极值，从而想到一次逆序预处理。

### （1）为什么只需要关心后缀最大值和最小值

题目要求对每个 `A[i]`，在所有满足 `i <= j <= n-1` 的 `A[j]` 中，找到使 `A[i] * A[j]` 最大的那个值。

也就是说，对每个位置 `i`，可选范围是后缀 `A[i..n-1]`。

设这个后缀中的最大值为 `maxValue`，最小值为 `minValue`。则：

- 当 `A[i] > 0` 时，乘以越大的数结果越大，所以最优值是  
  $$
  res[i] = A[i] \times maxValue
  $$
- 当 `A[i] < 0` 时，乘以越小的数结果越大，所以最优值是  
  $$
  res[i] = A[i] \times minValue
  $$
- 当 `A[i] = 0` 时，任意乘积都为 `0`，所以  
  $$
  res[i] = 0
  $$

因此，每个位置并不需要枚举所有 `j`，只需要知道当前后缀的最大值和最小值即可。

---

### （2）为什么要从右向左扫描

因为 `res[i]` 只依赖后缀 `A[i..n-1]`，所以从右向左处理最自然。

当扫描到 `i` 时：

- `A[i+1..n-1]` 的最大值和最小值已经在前一步维护好了；
- 再把当前元素 `A[i]` 纳入进去，就能得到 `A[i..n-1]` 的最大值和最小值；
- 随后即可立刻算出 `res[i]`。

这就形成了明显的承接关系：

| 扫描到的位置 | 已维护的信息 |
|---|---|
| `i+1` | 后缀 `A[i+1..n-1]` 的最大值、最小值 |
| `i` | 将 `A[i]` 合并后，得到后缀 `A[i..n-1]` 的最大值、最小值 |

所以只需一趟从右向左的扫描。

---

### （3）样例验证

题目样例：`A = {1, 4, -9, 6}`

从右向左计算：

| `i` | `A[i]` | 当前后缀 `A[i..n-1]` | 后缀最小值 | 后缀最大值 | `res[i]` |
|---|---:|---|---:|---:|---:|
| 3 | 6 | `{6}` | 6 | 6 | `6*6=36` |
| 2 | -9 | `{-9, 6}` | -9 | 6 | `(-9)*(-9)=81` |
| 1 | 4 | `{4, -9, 6}` | -9 | 6 | `4*6=24` |
| 0 | 1 | `{1, 4, -9, 6}` | -9 | 6 | `1*6=6` |

得到：

$$
res = \{6, 24, 81, 36\}
$$

与题目给出的结果一致。

---

### （4）代码要点说明

代码中有两个关键点。

第一，必须先更新后缀极值，再计算 `res[i]`。  
因为题目允许 `j=i`，所以 `A[i]` 自己也属于可选范围 `A[i..n-1]`。如果先算结果、后更新极值，就会漏掉 `A[i]` 自乘的情况。

第二，`A[i]==0` 时结果应为 `0`。  
实现代码中把 `A[i]==0` 放进了 `else` 分支，计算成 `0 * minValue`，数值上仍然正确；但单独写出这一分支更清晰，也更便于核验。

---

### （5）复杂度分析

算法只有一重循环，从 `n-1` 到 `0` 共扫描一次数组。每次循环仅进行常数次比较、赋值和乘法运算，因此时间复杂度为：

$$
O(n)
$$

除结果数组 `res` 外，算法只额外使用了 `minValue`、`maxValue` 和循环变量等常数个辅助变量，因此额外空间复杂度为：

$$
O(1)
$$

---

本题的标准做法就是维护后缀最大值和最小值并从右向左一次扫描。还需单独说明 `A[i]=0` 的情况，以便逻辑更清晰、结果更容易核验。
