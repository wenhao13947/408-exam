## 答案

设 6 个信号量，其含义及初值如下：

- `A_full = x`：A 信箱中现有邮件数
- `A_empty = M - x`：A 信箱中的空位数
- `B_full = y`：B 信箱中现有邮件数
- `B_empty = N - y`：B 信箱中的空位数
- `A_mutex = 1`：对 A 信箱的互斥访问
- `B_mutex = 1`：对 B 信箱的互斥访问

完整过程可写为：

A 进程：

```text
A() {
    while (1) {
        P(A_full);
        P(A_mutex);
        从A信箱中取出一个邮件;
        V(A_mutex);
        V(A_empty);

        回答问题并提出新问题;

        P(B_empty);
        P(B_mutex);
        将新邮件放入B信箱;
        V(B_mutex);
        V(B_full);
    }
}
```

B 进程：

```text
B() {
    while (1) {
        P(B_full);
        P(B_mutex);
        从B信箱中取出一个邮件;
        V(B_mutex);
        V(B_empty);

        回答问题并提出新问题;

        P(A_empty);
        P(A_mutex);
        将新邮件放入A信箱;
        V(A_mutex);
        V(A_full);
    }
}
```

## 解析

### 信号量设置

本题本质上是两个缓冲区上的同步与互斥问题。

- A 从自己的信箱中取邮件，属于对 A 信箱的“取出”操作；
- A 处理后再向 B 的信箱放入新邮件，属于对 B 信箱的“放入”操作；
- B 的过程与之对称。

因此，A、B 两个信箱都应分别设置：

- 表示当前邮件数的信号量 `full`
- 表示当前空位数的信号量 `empty`
- 表示互斥访问该信箱的信号量 `mutex`

由题意可得：

$$
A\_full = x,\quad A\_empty = M-x
$$

$$
B\_full = y,\quad B\_empty = N-y
$$

又因为两个信箱都是临界资源，所以：

$$
A\_mutex = 1,\quad B\_mutex = 1
$$

### A 进程

A 进程的操作分为两步：先从 A 信箱取邮件，再向 B 信箱放邮件。

1. 从 A 信箱取邮件时，必须先保证 A 信箱非空，因此先执行 `P(A_full)`。
2. 取邮件要访问 A 信箱这一临界资源，所以再执行 `P(A_mutex)`。
3. 取出邮件后，先释放互斥 `V(A_mutex)`。
4. 由于取走了 1 个邮件，A 信箱空位数增加 1，因此执行 `V(A_empty)`。

之后，A 回答问题并形成发给 B 的新邮件。

5. 向 B 信箱放邮件前，必须保证 B 信箱未满，因此执行 `P(B_empty)`。
6. 放邮件需要互斥访问 B 信箱，所以执行 `P(B_mutex)`。
7. 放入完成后，先释放互斥 `V(B_mutex)`。
8. 由于 B 信箱中邮件数增加 1，因此执行 `V(B_full)`。

### B 进程

B 进程与 A 进程完全对称。

1. B 从 B 信箱取邮件，因此先执行 `P(B_full)`，再执行 `P(B_mutex)`。
2. 取出邮件后，执行 `V(B_mutex)` 和 `V(B_empty)`。
3. 回答问题并形成新邮件后，准备向 A 信箱投递。
4. 向 A 信箱放邮件前，先执行 `P(A_empty)`，再执行 `P(A_mutex)`。
5. 放入完成后，执行 `V(A_mutex)` 和 `V(A_full)`。

### 说明

本题只有一个整体任务，不再拆分小问。其关键在于同时满足两类约束：

- 取邮件前必须保证“本信箱非空”；
- 放邮件前必须保证“对方信箱未满”。

同时，A 信箱和 B 信箱是两个独立的共享资源，因此应分别设置 `A_mutex` 和 `B_mutex`，分别保证对各自信箱的互斥访问。

## 易错点

- 容易只写“非空”和“不满”的同步关系，而漏写对信箱的互斥访问。
- 容易把放邮件时使用的互斥量写错。向 B 信箱放邮件，应使用 `B_mutex`；向 A 信箱放邮件，应使用 `A_mutex`。
- 容易将 `full` 与 `empty` 的初值写反。应由题目给定的初始邮件数直接确定：
  $$
  A\_full=x,\ A\_empty=M-x,\ B\_full=y,\ B\_empty=N-y
  $$
- 容易把 `V(empty)` 与 `V(full)` 的位置写错。取出邮件后增加空位，应执行 `V(empty)`；放入邮件后增加邮件数，应执行 `V(full)`。
