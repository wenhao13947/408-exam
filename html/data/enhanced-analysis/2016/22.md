## 答案

A

“访存时缺页”发生在指令执行的访存过程中，属于**异常**而不是**中断**，因此 A 的说法错误。

## 解析

本题的关键是区分**中断**与**异常**的判定依据：

- **异常（Exception）**：在**CPU 执行指令过程中**，由处理器内部检测到的特殊事件。
- **中断（Interrupt）**：来自**处理器外部**的请求事件，通常与当前正在执行的那条指令本身没有直接因果关系。

因此，做题时可以直接用一个判断标准：

- **与当前指令执行过程直接相关**，一般判为**异常**
- **由外设或外部事件发起请求**，一般判为**中断**

据此分析各项：

- “访存时缺页”只有在程序执行某条指令、并且该指令需要访问内存时才会发生。缺页是虚拟存储管理中在访存阶段发现目标页不在内存而引发的事件，显然属于**指令执行过程中的内部事件**，因此它是**异常**，不是中断。
- “整数除以 0”是在执行除法指令时由处理器检测出来的算术错误，属于**异常**。
- “DMA 传送结束”是 DMA 控制器或相关外设在数据传送完成后，向 CPU 发出的完成通知，请求 CPU 处理后续工作，属于**外部请求事件**，因此是**中断**。
- “存储保护错”是程序访问了无权访问的受保护内存区域，通常在执行访存相关指令时被硬件检测出来，因此属于**异常**。

所以，错误选项只能是 **A**。

## 选项分析

A. “访存时缺页”属于中断  
**错误。** 缺页发生在执行指令的访存过程中，是由处理器在执行过程中发现的内部异常情况，属于**异常**。

B. “整数除以 0”属于异常  
**正确。** 这是执行算术指令时产生的运行错误，属于**异常**。

C. “DMA 传送结束”属于中断  
**正确。** DMA 传送结束后，由外设/DMA 控制器向 CPU 发出请求信号，属于**中断**。

D. “存储保护错”属于异常  
**正确。** 程序非法访问受保护内存区域时，通常由处理器在执行访存指令时检测到，属于**异常**。

## 易错点

- **不要把“与 I/O、存储器有关”机械地都看成中断。** 关键不在于对象是内存还是外设，而在于事件是否**由当前指令执行直接引发**。
- **缺页属于异常**是常考点。虽然缺页处理要靠操作系统介入，但它的触发源头仍然是**执行指令时的访存失败**。
- **DMA 结束属于中断**也容易和异常混淆。判断依据是：DMA 完成是**外设/控制器向 CPU 发请求**，不是 CPU 在执行某条指令时内部检测出的错误。
