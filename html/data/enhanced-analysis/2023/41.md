## 答案

### （1）
采用按顶点逐个统计入度和出度的方法。对于邻接矩阵存储的有向图，顶点 $v$ 对应的第 $v$ 行元素之和为该顶点的出度，第 $v$ 列元素之和为该顶点的入度。依次考察每个顶点，若满足

$$
outdegree > indegree
$$

则该顶点为 K 顶点，输出该顶点，并将计数器加 1。全部顶点处理完后，返回 K 顶点的个数。

### （2）
```c
int printVertices(MGraph G) {
    int count = 0;  // K顶点个数

    for (int v = 0; v < G.numVertices; v++) {
        int indegree = 0;   // 当前顶点的入度
        int outdegree = 0;  // 当前顶点的出度

        // 统计顶点v的出度，即第v行元素之和
        for (int i = 0; i < G.numVertices; i++) {
            outdegree += G.Edge[v][i];
        }

        // 统计顶点v的入度，即第v列元素之和
        for (int i = 0; i < G.numVertices; i++) {
            indegree += G.Edge[i][v];
        }

        // 若出度大于入度，则为K顶点
        if (outdegree > indegree) {
            printf("%c ", G.VerticesList[v]);
            count++;
        }
    }

    return count;
}
```

## 解析

> **考场判断：** 题目采用邻接矩阵，判断每个顶点都必须查看对应的入边和出边信息。逐行、逐列统计就是最直接的算法，同时其 $O(n^2)$ 时间复杂度已经与矩阵输入规模一致，不必再强行区分暴力法和最优法。

### （1）
题目要求输出所有 K 顶点，并返回其个数。这里的关键是利用邻接矩阵求有向图顶点的入度和出度。

对邻接矩阵 `Edge` 而言：

- 第 $v$ 行中各元素之和，表示从顶点 $v$ 出发的边数，即顶点 $v$ 的出度。
- 第 $v$ 列中各元素之和，表示指向顶点 $v$ 的边数，即顶点 $v$ 的入度。

因此，可按如下思路处理：

1. 设置计数器 `count`，初值为 0。
2. 依次枚举每个顶点 $v$。
3. 扫描第 $v$ 行，求出 `outdegree`。
4. 扫描第 $v$ 列，求出 `indegree`。
5. 若 `outdegree > indegree`，则输出该顶点，并令 `count++`。
6. 所有顶点处理结束后，返回 `count`。

该问给出的设计思想，正是第（2）问代码实现的依据；第（2）问直接按这一统计过程展开即可。

### （2）
按照第（1）问的思路，外层循环用于枚举每个顶点，内层两次循环分别统计当前顶点的出度和入度。

实现时要注意以下几点：

- 顶点个数应写为 `G.numVertices`，因为它是结构体 `MGraph` 的成员。
- `indegree` 和 `outdegree` 是针对当前顶点的统计量，因此每处理一个新顶点时都必须重新置 0。
- 只有在当前顶点的入度和出度都统计完成后，才能判断其是否为 K 顶点。
- `VerticesList[v]` 是单个字符，输出时应使用 `%c`。

代码如下：

```c
int printVertices(MGraph G) {
    int count = 0;  // K顶点个数

    for (int v = 0; v < G.numVertices; v++) {
        int indegree = 0;   // 当前顶点的入度
        int outdegree = 0;  // 当前顶点的出度

        // 统计顶点v的出度，即第v行元素之和
        for (int i = 0; i < G.numVertices; i++) {
            outdegree += G.Edge[v][i];
        }

        // 统计顶点v的入度，即第v列元素之和
        for (int i = 0; i < G.numVertices; i++) {
            indegree += G.Edge[i][v];
        }

        // 若出度大于入度，则为K顶点
        if (outdegree > indegree) {
            printf("%c ", G.VerticesList[v]);
            count++;
        }
    }

    return count;
}
```

## 复杂度分析

设图中顶点数为 $n$。

对每个顶点，都要扫描一整行和一整列，各需 $O(n)$ 时间；共有 $n$ 个顶点，因此总时间复杂度为

$$
O(n^2)
$$

算法只使用了 `count`、`indegree`、`outdegree` 等常数个辅助变量，空间复杂度为

$$
O(1)
$$

## 易错点

- 不要将 `numVertices` 直接写成独立变量，应写成 `G.numVertices`。
- `VerticesList[v]` 表示一个字符，输出格式应为 `%c`。
- `indegree` 和 `outdegree` 必须在每轮处理新顶点时重新初始化为 0。
- 判断条件是 `outdegree > indegree`，不是 `>=`，也不是只比较两者之差是否非负。
