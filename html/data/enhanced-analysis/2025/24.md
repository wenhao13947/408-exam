## 答案
错误的是 **C**。VMM 的特权级不可能与操作系统相同。

## 解析
题目考查虚拟化技术的基本概念。判断关键在于区分 VMM（Virtual Machine Monitor，虚拟机监控器）与操作系统在不同虚拟化模式下的层级关系。

A 说“操作系统可以在虚拟机上运行”，这是对的。VMM 向上提供虚拟硬件环境，客观上就是让完整操作系统误以为自己运行在真实机器上，因此 Linux、Windows 等都可以安装并运行在虚拟机中。

B 说“一台主机可以支持多个虚拟机”，也是对的。虚拟化的重要能力之一就是在同一台物理主机上同时运行多个虚拟机，并由 VMM 负责资源调度与隔离。

C 说“VMM 与操作系统特权级相同”，这是错误的。无论从哪类虚拟机分析，都不成立：
- 第一类虚拟机中，VMM 位于更高控制层，客户机操作系统运行在其上，客户机 OS 的特权级低于 VMM。
- 第二类虚拟机中，VMM 依赖宿主机操作系统分配资源，若讨论宿主机 OS，则宿主机 OS 的特权级高于 VMM；若讨论客户机 OS，则客户机 OS 仍运行在 VMM 之上，特权级也低于 VMM。

因此，不管把“操作系统”理解为宿主机 OS 还是客户机 OS，VMM 都不可能与其处于相同特权级。

D 说“通过虚拟机技术，可以用一台主机上模拟多种 ISA”，结论是对的。ISA 是由 CPU 架构决定的，不同架构的指令集不同；而虚拟化/仿真技术可以通过翻译模拟出另一种 CPU 环境，使主机能够运行不同 ISA 的系统或程序。

## 选项分析
A. 正确。虚拟机可以承载操作系统运行。  
B. 正确。一台主机可同时运行多个虚拟机。  
C. 错误。VMM 与操作系统不处于相同特权级。  
D. 正确。借助模拟/翻译机制，可以在一台主机上运行不同 ISA 的环境。

## 易错点
本题最容易混淆的是 C 项中的“操作系统”指代：题目语境下无论指宿主机 OS 还是客户机 OS，结论都是否定的。另一个容易混淆点是 D 项把“虚拟化”和“仿真”混在一起，但就题目结论而言，只要能实现不同 ISA 的运行环境，这项就应判为正确。
