## 答案

**C**。中断 I/O 方式下，外设准备数据的速度不能快于 CPU 通过中断服务程序处理数据的速度，否则可能因缓冲区来不及清空而发生数据覆盖或数据丢失。

## 解析

本题考查中断 I/O 方式的适用场景与工作机制。题目要求选出“不正确”的说法。

中断 I/O 的核心特点是：外设在准备好数据后向 CPU 发出中断请求，CPU 暂停当前执行流，转去执行中断服务程序，由软件完成本次数据传送。与程序直接控制方式相比，它避免了 CPU 持续轮询设备状态，因此更适合字符型设备这类传输频率不算高、但需要及时响应的场景。

判断 C 的关键在于比较两个时间：

- 外设准备一个数据所需时间
- CPU 完成一次中断处理所需时间

如果“外设准备数据时间小于中断处理时间”，说明新数据到来的速度快于 CPU 处理旧数据的速度。此时设备控制器缓冲区中的旧数据可能还没被取走，新数据就已经到达；而缓冲区容量通常有限，就可能出现后到数据覆盖先到数据的情况，最终导致数据丢失。因此，C 的表述错误。

相反，只有当外设准备数据的时间不小于中断处理时间时，CPU 才更有可能在下一批数据到来前完成本次中断处理，系统才能稳定工作。这也是本题的判断依据。

## 选项分析

**A. 适用于键盘、针式打印机等字符型设备**

正确。  
中断 I/O 常用于字符型设备。此类设备通常按字符或字为单位传输数据，传输速率相对较低，但要求及时响应。采用中断方式可在设备就绪时再通知 CPU，避免反复查询设备状态。

**B. 外设和主机之间的数据传送通过软件完成**

正确。  
在中断 I/O 方式下，数据传送通常由 CPU 执行中断服务程序完成，因此本质上是“通过软件完成”。这也是它与 DMA 方式的重要区别之一：DMA 可由 DMA 控制器直接在设备与内存之间传送数据，CPU 不必逐次参与数据搬运。

**C. 外设准备数据的时间应小于中断处理时间**

错误。  
这是本题答案。若外设准备数据更快，而中断处理更慢，则 CPU 还在处理中断时，新数据已继续到达，有限缓冲区可能被写满并覆盖原有数据，导致丢失。正确的理解应是：外设准备数据的时间一般不应小于中断处理时间。

**D. 外设为某进程准备数据时 CPU 可运行其他进程**

正确。  
中断 I/O 的优势之一就是 CPU 与外设可并行工作。某进程因等待 I/O 而阻塞时，CPU 可以切换去运行其他进程；等外设准备好数据后，再通过中断通知 CPU 处理。这有利于提高 CPU 利用率。

## 易错点

- 不要把“中断 I/O”与“DMA”混淆。中断 I/O 的数据传送仍需 CPU 执行中断服务程序参与，DMA 则强调设备与内存直接交换数据。
- C 项容易凭直觉误判为“准备越快越好”。但在 I/O 系统中，关键不是绝对快，而是“生产速度”不能超过“处理速度”，否则就会出现缓冲区溢出、数据覆盖等问题。
- 看到“通过软件完成”时，不要误以为一定错误。中断 I/O 下，这一说法恰恰是正确的。
